# op1 白日梦 · 20秒双段拼接 · 生产提示词

> 目标节点：`EP01 / op1`
> 产物：`op1.v2.mp4`（20s，两段 10s 拼接）
> 工具链：`tools/make_videos`（kling-3-pro / ark-seedance）+ `tools/process_video/compose`
> 参考基准：Yoroll VOW PV 逐帧
> **本文档已移除"三层遮盖"约束。基准对齐 VOW：真丝吊带、露肩锁骨、蕾丝透纱、湿发湿肤。**

---

## 一、为什么必须拆成两段

逐帧看 VOW 才发现的关键点：**它没有任何一个 10 秒长镜头**。整条 54 秒 PV 是 5 个独立片段拼的，每段内部只做 1 个连续运镜。

我上一版把「贴地推轨 + 自下而上 tilt + 手部特写 + 唇部大特写 + 后仰失焦」五个动作塞进一个 10 秒提示词——**这是错的**。可灵/Seedance 在单次生成里做超过 2 次景别切换必崩：人物会变脸、手指会畸形、镜头会乱飘。

正确做法：**一段 = 一个连续运镜**，两段之间靠首尾帧接力保证同一个人。

```
段A (0-10s)  远 → 近，自下而上，收在她抬眼看镜头
   ↓ 末帧 = 段B 首帧（同人同景同光，保证连贯）
段B (10-20s) 近 → 特写，唇/睫毛/锁骨，收在失焦转场
```

## 二、角色一致性锚点（两段必须逐字复用）

```
鹅蛋脸，大眼双眼皮，肤色暖白，鼻梁秀挺，唇形饱满，
黑色长发披肩微卷，戴细金属框眼镜，
米白色真丝吊带睡裙，肩带细，锁骨与肩线裸露，
```

> **设计意图**：这张脸 = 沈婉儿的脸，只是现代造型。
> 古装的「发髻木簪」→ 现代的「长发微卷」，古装的「米白棉布衣」→ 现代的「米白真丝吊带」。
> 玩家穿越后第一眼见到婉儿，会认出「是梦里那张脸」，白日梦从废镜头变成伏笔。

## 三、段 A · 可灵 kling-3-pro

**参数**
```json
{
  "model": "kling-3-pro",
  "aspectRatio": "9:16",
  "resolution": "720p",
  "durationSec": 10,
  "generateAudio": true
}
```

**提示词**
```
深夜的写字楼，整层只剩一盏工位台灯亮着，四周办公桌陷在黑暗里。一位年轻东方女性独自加班：鹅蛋脸，大眼双眼皮，肤色暖白，鼻梁秀挺，唇形饱满，黑色长发披肩微卷，戴细金属框眼镜，穿米白色真丝吊带睡裙，肩带细，锁骨与肩线裸露，赤脚踩在办公椅横杠上。

镜头运动：摄影机贴近地板高度起幅，从办公桌下方缓缓向前推进，前景是虚化的桌腿与散落文件；接着镜头沿她的小腿自下而上匀速摇起，掠过赤足、膝盖、真丝裙摆的褶皱、腰侧、锁骨，最后停在她低头看屏幕的侧脸。她察觉到什么，缓缓转头看向镜头，唇角微微上扬。

摄影：机位全程低于人物视线形成仰角。浅景深 f/1.8，背景光斑虚化。台灯暖黄侧光为主光，勾出锁骨与肩线的高光边缘；窗外城市夜景冷蓝色作为轮廓光，冷暖对比强烈。皮肤有细腻高光与绒毛质感，真丝面料有柔和反光和垂坠感。轻微手持晃动，35mm 电影镜头，写实电影质感，电影颗粒。

音频：安静的空调低频嗡鸣，远处键盘敲击声，她轻轻呼出一口气。

负面：不要俯拍，不要多余人物，不要文字水印，不要变形手指，不要塑料感皮肤，不要过曝，不要卡通风格。
```

**为什么这么写**
| 写法 | 学自 VOW 哪一帧 |
|---|---|
| 贴地机位起幅 | 桌下爬行组 —— 全片最低机位 |
| 沿小腿自下而上摇 | 沙滩组：赤足→小腿→裙摆→上身→抬眼 |
| 侧光勾锁骨肩线 | 沙发睡裙组：暖光把肩线打出高光边 |
| 真丝垂坠反光 | 沙发组的睡裙质感，是画面高级感来源 |
| 收在「转头看镜头」 | VOW 每段都以「她看向你」收尾 |

## 四、段 B · 可灵 kling-3-pro（首帧接力）

**参数** —— 用段 A 末帧做首帧，这是保证同一张脸的唯一可靠手段
```json
{
  "model": "kling-3-pro",
  "aspectRatio": "9:16",
  "resolution": "720p",
  "durationSec": 10,
  "generateAudio": true,
  "firstFrame": "<段A末帧绝对路径>"
}
```

**提示词**
```
承接上一镜，同一位女性，同一间深夜办公室，同一盏台灯。鹅蛋脸，大眼双眼皮，肤色暖白，黑色长发披肩微卷，细金属框眼镜，米白色真丝吊带睡裙，锁骨与肩线裸露。

镜头运动：从她的脸缓缓推近。先是手部特写——指尖离开键盘，抬手用手背抹去额角的薄汗，一缕发丝被汗黏在颈侧，顺着锁骨的弧线垂下；镜头继续推成大特写，嘴唇先入画，她轻轻抿了一下，唇上有细微水光；镜头微微上移露出眼睛，睫毛在暖光下投出长影，她眨了下眼，眼神带笑；最后她向后靠进办公椅，长发垂落肩后，抬起食指对镜头做出「嘘」的手势，画面缓缓失焦。

摄影：大特写景别，机位仍略低于视线保持仰角。极浅景深 f/1.4，只有唇与睫毛在焦内。台灯暖光侧打，皮肤上有细密汗珠反光，锁骨凹陷处有阴影。轻微手持呼吸感，35mm 电影镜头，写实电影质感，电影颗粒，末尾焦点缓慢脱焦。

音频：她轻轻笑了一声，气声说话，空调低频嗡鸣持续。

负面：不要俯拍，不要多余人物，不要文字水印，不要变形手指，不要牙齿畸形，不要塑料感皮肤，不要卡通风格。
```

**为什么这么写**
| 写法 | 学自 VOW 哪一帧 |
|---|---|
| 汗珠 + 发丝黏颈 | 攀岩组 —— 全片张力最强的一组 |
| 只拍唇和睫毛 | 特写永远只拍「湿」和「细」 |
| 锁骨阴影 | 睡裙组的光影处理 |
| 「嘘」手势 | 击穿第四面墙，对应台词「你别看啦」 |
| 末尾失焦 | VOW 段落转场手法 |

## 六、台词与画面对位（20 秒完整时间轴）

原台词拆成两句，卡在两段的情绪点上：

| 秒 | 段 | 画面 | 台词 |
|---|---|---|---|
| 0.0–3.0 | A | 贴地推轨，只见桌腿与赤足 | —（留白，只有环境音） |
| 3.0–6.5 | A | 自下而上摇过小腿、裙摆、腰侧 | 「傲天~今晚不加班嘛？」 |
| 6.5–10.0 | A | 停在侧脸，她转头看镜头 | 「人家一个人在办公室……」 |
| **10.0** | — | **xfade 0.4s 交叉溶解** | — |
| 10.0–13.5 | B | 手背抹汗，发丝黏颈 | 「好无聊哦……」 |
| 13.5–17.0 | B | 唇部大特写，抿唇水光 | —（留白，只有气声笑） |
| 17.0–20.0 | B | 眨眼 → 后仰 → 嘘手势 → 失焦 | 「讨厌啦，你别看啦~」 |

**两处留白是刻意的**：0–3s 留白建立悬念，13.5–17s 留白让唇部特写独占注意力。VOW 全片台词极少，靠画面说话。

## 七、执行命令

```bash
S=/Users/fat/.codeflicker/remote-personal-skills/agw-work-mode

# 1. 生成段 A
python3 -m tools.make_videos --model kling-3-pro \
  --prompt-file prompts/op1_segA.txt \
  --aspect 9:16 --duration 10 --audio \
  --out work/op1_A.mp4

# 2. 抽段 A 末帧作为段 B 首帧（保证同一张脸）
python3 $S/tools/process_video/extract.py \
  --input work/op1_A.mp4 --at last --out work/op1_A_last.jpg

# 3. 生成段 B（首帧接力）
python3 -m tools.make_videos --model kling-3-pro \
  --prompt-file prompts/op1_segB.txt \
  --first-frame work/op1_A_last.jpg \
  --aspect 9:16 --duration 10 --audio \
  --out work/op1_B.mp4

# 4. 拼接（0.4s 交叉溶解）
python3 $S/tools/process_video/compose.py \
  --clips work/op1_A.mp4 work/op1_B.mp4 \
  --transition xfade --transition-dur 0.4 \
  --out package/assets/video/op1.v2.mp4

# 5. 验收
python3 $S/tools/process_video/probe.py --input package/assets/video/op1.v2.mp4
python3 $S/tools/process_video/extract_review_frames.py \
  --input package/assets/video/op1.v2.mp4 --fps 1 --out work/review/op1/
```

## 八、验收标准

拼完必须逐项过：

- [ ] **同一张脸** —— 段A末帧与段B首帧五官一致，无变脸（这是双段拼接最容易翻车的点）
- [ ] 总时长 20s ± 0.3s
- [ ] 接缝处光线连贯，台灯位置与色温无跳变
- [ ] 手指无畸形（特写镜头高发区）
- [ ] 台词与口型大致对得上，两处留白保留
- [ ] 9:16 竖屏，720p 起
- [ ] 末尾失焦干净，能接 S1 车祸镜头

**若段B变脸**：不要重写提示词，改用 `--first-frame` + `--last-frame` 双端锁定，或把段B降到 5s 再补一段。
