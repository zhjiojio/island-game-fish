## 一、产品是什么（一句话）

这是一款**快手 AIGC 互动短剧小游戏**。玩家扮演穿越到荒年的男主"李傲天"，通过看剧情视频 + 做选择的方式，一步步经营家业、守护未婚妻沈婉儿，最终走向不同结局（发家致富娶媳妇 / 破产饿死走人）。

**核心体验闭环**：看一段剧情视频 → 遇到抉择点做选择 → 选择影响三项数值（威望/爱意/存粮）→ 数值决定最终结局 → 通过看广告解锁更多章节和番外内容。

## 二、核心功能逻辑（测试同学必须理解的主线）

### 2.1 剧情播放主流程

```
首页（章节选择） → 进入章节 → 剧情视频/图片 → 抉择点 → 反应剧情 → 下一节点 → ... → 章节结束 → 结局/下一章
```

- 内容单位是"节点"（node），节点分三类：
  - **视频节点**：播放一段 AIGC 剧情视频（带原生音轨 + 字幕）
  - **图片节点**：静态场景图 + 旁白（说书大爷配音）
  - **抉择节点（choice）**：给玩家 2-3 个选项，玩家点选后进入不同的"反应节点"再汇回主线
- 全剧共 5 章（EP01–EP05），约 278 个节点。

### 2.2 三项数值系统（贯穿全局的核心机制）

| 数值 | 含义 | 影响 |
|---|---|---|
| **威望（wei）** | 男主在村里的地位 | 高 → 当村长；低 → 被赶出村 |
| **爱意（qing）** | 婉儿对男主的感情 | 高 → 嫁给你/进城开饭馆；低 → 她离开 |
| **存粮（liang）** | 家里的粮食储备 | 高 → 荒年安稳；低 → 冬天饿死 |

- 每次抉择会加减对应数值（选项里带 `stat` 字段）。
- 数值以"胶囊 UI"形式常驻显示在界面上。
- **结局由三项数值最终值决定**（见下方结局表）。

### 2.3 结局系统（多结局分支）

- **好结局（HE）**：如三项 MAX 完美结局、进城开饭馆、当村长、荒年平安度过等。
- **坏结局（BE）**：如爱意过低她离开、存粮过低饿死、威望过低被赶出村等。
- 结局根据数值门槛触发（如"爱意<15 → 她走了"）。

### 2.4 广告变现逻辑（IAA 核心，重点测试）

- **章节解锁**：第二章起，部分章节需要"看广告解锁"。
- **成就卡·直通该章**：看完广告可直接跳到某成就解锁的那一帧剧情。
- **番外内容**：换装、舞蹈加演等番外剧情，通过看广告解锁，看完回到主线。
- **免广告特权**：登录用户长按成就头像 4 秒，可在本次启动内免广告（内部测试用）。

### 2.5 成就 / 技能卡系统

- 剧情推进中会解锁成就卡 / 技能卡（如"技能觉醒"）。
- 解锁时有浮层弹出 + 说书大爷念解锁词 + 卡片收进胶囊动效。
- 成就详情浮层里有"看广告·直通该章"入口。

## 三、重点关注的功能点（产品要求 + 验收标准）

> 下面每一条都是"产品视角"想要保证的体验，测试时请按"要求"逐条验收。

### 3.0 平台合规硬性验收项【P0 · 上线必过】

> 以下三项是平台审核 / 上线的硬门槛，任意一项不通过即不允许上线，测试时优先验收。

#### ① 游戏启动顺畅 · 双端启动时长

| 功能点 | 产品要求 |
|---|---|
| 冷启动时长 | iOS / Android 双端从点击图标（扫码进入）到首屏可交互，时间在合理范围内（目标 ≤ 平台标准，建议冷启 ≤ 5s） |
| 首屏无白屏卡死 | 启动过程 loading 有进度反馈，不出现长时间白屏/黑屏/卡死 |
| 首视频秒开 | 进入后第一章首视频能快速起播，不长时间转圈 |
| 双端一致性 | iOS 与 Android 启动表现基本一致，不出现单端明显偏慢 |
| 二次启动 | 有缓存的二次启动应明显快于冷启动 |

**验收方式**：双端真机分别记录"点击 → 首屏可交互"耗时，各测 3 次取均值；弱网下也需能正常进入。

#### ② 功能交互正常 · 隐私政策完整展示

| 功能点 | 产品要求 |
|---|---|
| 全局交互 | 所有按钮/选项/浮层点击响应正常，无点击无反应、无误触、无穿透 |
| 隐私政策入口 | 首次进入或设置内可找到"隐私政策 / 用户协议"入口，可正常打开 |
| 隐私政策内容 | 隐私政策文本完整展示、可滚动到底、无乱码、无空白、无 404 |
| 授权弹窗 | 涉及登录/授权时弹窗文案清晰；用户拒绝授权不阻断游戏（走默认头像昵称） |
| 合规链路 | 隐私政策展示符合快手小游戏平台审核要求，可正常同意/查看 |

**验收方式**：全新安装/清缓存后首次进入，确认隐私政策能完整打开并阅读；逐个点击主要交互元素确认响应正常。

#### ③ 看广告功能正常 · 广告解锁后功能正确解锁

| 功能点 | 产品要求 |
|---|---|
| 广告正常拉起 | 点击"看广告"能正常拉起激励广告，正常播放到结束 |
| 看完即解锁 | 广告正常看完后，对应功能（章节/成就直通/番外）**真正解锁并生效** |
| 解锁后可用 | 解锁的章节能进入、成就能直通到对应帧、番外能播放并回主线 |
| 中途关闭 | 广告未看完就关闭时，不解锁功能，并给出明确提示，不静默失败 |
| 广告失败兜底 | 广告加载失败/无广告填充时，有合理提示，不卡死、不误解锁 |
| 重复解锁 | 已解锁的功能不重复要求看广告（除设计上刻意要求的场景） |

**验收方式**：真机实际播放广告（模拟器无法验收），覆盖"看完解锁成功"与"中途关闭不解锁"两条路径。

### 3.1 首启与用户承接【高优先级】

| 功能点 | 产品要求 |
|---|---|
| 新用户首启 | 直接播放第一章首视频，不需要额外点击 |
| 老用户进入 | 有真实剧情记录的老用户，进入后承接到"章节页"，不重播开头 |
| 清缓存后 | 恢复到新用户首播流程 |
| 左下角入口 | 显示金边"章节"文字按钮，可随时回到章节选择 |

### 3.2 剧情播放体验【高优先级】

| 功能点 | 产品要求 |
|---|---|
| 视频播放 | 视频流畅播放，画面/音轨/字幕三者同步，不卡顿不黑屏 |
| 字幕正确性 | 字幕文字与语音逐字对齐；双人对话场景不能把两人台词糊成一句 |
| 图片节点 | 场景图正常加载，旁白（说书大爷）配音与文字一致 |
| 节点切换 | 视频→图片、图片→抉择等切换不出现黑屏、白屏、卡死 |
| 弱网表现 | 弱网/切后台再回来时，视频/图片有兜底，不永久转圈 |

### 3.3 抉择与数值【高优先级】

| 功能点 | 产品要求 |
|---|---|
| 抉择点展示 | 每个抉择前有 1 张场景图或视频铺垫，不能干秃秃弹选项 |
| 选项点击 | 点击选项后进入对应的反应剧情，再正确汇回主线 |
| 数值变化 | 选项影响的三项数值，界面胶囊数字正确增减 |
| 数值展示 | 首次抉择后触发引导浮层，三数值胶囊数字滚动出现 |
| 跨章过渡 | 章节之间有过场剧情交代时间/地点变化，不能瞬间跳场 |

### 3.4 结局触发【中优先级】

| 功能点 | 产品要求 |
|---|---|
| 结局正确性 | 按不同数值走到对应的 HE / BE 结局，因果清晰 |
| 结局展示 | 结局文案、标题正常展示，玩家能看懂"为什么是这个结局" |

### 3.5 广告变现【高优先级 · IAA 命脉】

| 功能点 | 产品要求 |
|---|---|
| 章节解锁广告 | 看完广告后真正解锁并进入该章，异常时给明确提示，不静默失败 |
| 成就直通 | "看广告·直通该章"要真的跳到该成就解锁的那一帧，不从章头重播 |
| 番外解锁 | 换装/舞蹈番外看完广告后播放，播完正确回到同章主线 |
| 广告失败兜底 | 广告加载失败/用户中途关闭时，有合理提示，不卡死不误解锁 |
| 待开发章节 | 未开放章节（如"三巴掌"支线）显示"敬请期待"，不能错误指向第一章 |

### 3.6 成就 / 技能卡【中优先级】

| 功能点 | 产品要求 |
|---|---|
| 解锁触发 | 剧情推进到解锁点时，成就/技能浮层正确弹出 |
| 解锁反馈 | 浮层 + 说书大爷念词 + 卡片收进胶囊动效完整 |
| 卡片一致性 | 卡片名称/描述与剧情实际视频一致，不能有"永远解不了锁"的空卡 |

### 3.7 首页与章节选择【中优先级】

| 功能点 | 产品要求 |
|---|---|
| 章节封面 | 5 章封面图、标题、悬念描述正确展示 |
| 章节锁态 | 未解锁章节显示"看广告解锁"提示文案 |
| 章节跳转 | 点击章节进入对应章节起始节点 |

## 六、已知边界与非阻断项（提前同步，避免误报 bug）

- 授权被拒**不阻断**游戏，玩家可继续体验（仅头像/昵称走默认）。
- 管理员广告开关：身份服务未配置，普通账号一律正常出广告，管理员悬浮球不显示——**这是预期行为**。
- 部分原音歧义字幕保留了复听标记（见 `content/subtitles/README.md`），非 bug。
- EP06–EP09 为待拍规划稿，当前版本只上线 EP01–EP05。
