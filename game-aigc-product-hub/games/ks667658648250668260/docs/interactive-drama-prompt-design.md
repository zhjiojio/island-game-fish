# 互动剧情提示词设计方法论
> 来源：拆解竞品 Yoroll《VOW》宣传 PV（54s / 1fps 全帧分析）+ 对照本项目 EP01 现状
> 日期：2026-09-09

---

## 一、VOW PV 的镜头结构拆解

按秒逐帧还原，54 秒被切成 5 段，且**顺序本身就是一套提示词模板**：

| 段落 | 秒 | 画面 | 功能 |
|---|---|---|---|
| ① 钩子 | 0–11 | 卧室/沙发，女主角侧卧直视镜头 | 先给「欲望对象」，不解释任何背景 |
| ② 舞台 | 11–15 | 电竞场馆、蓝色灯带、观众席 | 亮出世界观规模感 |
| ③ **契约** | 15–22 | 双手按住一纸《女子电竞战队教练聘用协议》 | **明示你是谁、你要干什么** |
| ④ 入口 | 22–28 | 挂着 "VOW" 木牌的门 → 手推门把 | 仪式感的「进入世界」动作 |
| ⑤ 角色轮播 | 28–54 | 醒来、泳池、桌下、攀岩、沙滩，多角色多场景 | 展示可收集内容，制造「还有多少没解锁」 |

### 提炼出的核心结论

**VOW 在第 22 秒就完成了「你是谁 + 你要干嘛 + 你能得到谁」的三件事。**

而我们的 EP01，玩家要到第 8 个节点（`s5`）才知道目标是「别饿死」，到 `s6` 才知道自己有技能。**信息给晚了 5 个节点。**

## 二、互动剧情提示词的 6 条设计法则

### 法则 1：先契约，后剧情（Contract-First）

每一集开场 30 秒内必须用一个**具象道具**把身份与目标砸到玩家脸上。
VOW 用「一纸协议」，不是旁白念。

> ❌ 反例（当前 EP01）：靠 `r_f_s2_a` 的内心独白「这具身子从今天起，姓李，叫傲天」——文字流水账，玩家滑过去了。
> ✅ 正例：一个 `system` 契约卡节点，标题式呈现【荒年 1980 · 李家沟】【你：李傲天】【目标：让她活到开春】。

**提示词模板：**
```
一张 <道具载体>，<主体动作>，上面写着「<身份声明>」。
镜头：<景别>，<光线>，<情绪>。
禁止出现：人脸、现代物品。
```
道具载体 = 协议 / 婚书 / 地契 / 粮本 / 病历 / 判决书。
本项目最贴题的是 **一张压在碗底的婚书** 或 **一本快见底的粮本**。

---

### 法则 2：首次交互必须在 20 秒内（First-Choice-20s）

VOW 用「推门」这个动作暗示交互。我们的第一个 `choice`（`f_s2`）出现在三段 10s 视频之后 = **30 秒纯看片**。
小游戏场景下这是致命的，用户还没确认「这是个能玩的东西」就划走了。

**改法：** 在 `s1`（车祸）之后立刻插一个选择，哪怕它只是情绪表态。

---

### 法则 3：第一个选择要「塑造人设」，不是「打发时间」

当前 `f_s2` 的三个选项：
- 摸摸脉 `{qing:3}`
- 抽自己一巴掌 `{qing:1, wei:-1}`
- 看四周 `{qing:5}`

三个选项**都汇进 `s3`，数值差不到 5 点，玩家完全感知不到自己选过**。这是无效选择。

**有效选择的三条判定标准：**
1. 三个选项分别指向**三条不同的数值线**（威望 / 爱意 / 存粮），让玩家第一次就意识到"有三条线"；
2. 反应文案里必须**复读玩家的选择**（"你说你还没娶媳妇——"），让选择被看见；
3. 数值差 ≥ 8，且胶囊有滚动动效。

---

### 法则 4：角色轮播 = 留存钩子（Roster Tease）

VOW 后 26 秒全在轮播不同角色不同场景，本质是在说：**"还有这么多没解锁"**。

我们只有沈婉儿一个女主，但可以轮播的是**同一个人的不同状态**：
灶台边的她 / 舞裙的她 / 红嫁衣的她 / 雨夜的她。
在序章结尾放一个 3 秒的「未来闪回蒙太奇」，比任何"下一章预告"文案都有效。

---

### 法则 5：BE 要可预见，不能是地雷

当前 `f0` 的「一口闷了不给她」直接 `{wei:-99, liang:-99}` 秒死。玩家点之前**没有任何视觉预警**。

**改法：** 危险选项统一加视觉标记（红色描边 / ⚠️ 图标），BE 从"惩罚玩家手滑"变成"玩家主动想看的坏结局"。坏结局是内容，不是陷阱。

---

### 法则 6：一句提示词只描述一个可拍摄的画面

写 AIGC 分镜提示词时，最常见的错误是把剧情写进提示词。

> ❌ `婉儿端着糊糊走进来，她心里很难过，因为家里没粮了`
> （"心里难过""因为没粮"无法成像）
>
> ✅ `土窑洞内，油灯，年轻女子双手端一只粗陶碗走向镜头，碗里是稀糊糊，热气升腾。她眼眶发红，嘴角强撑着笑。中景，暖黄侧光，1980年代中国北方农村。`

**可拍摄性检查清单：** 场景 / 光线 / 人物动作 / 手持物 / 景别 / 年代 / 情绪的外化表现（红眼眶 ≠ 难过）。

## 三、尺度基准（对齐 VOW，不做无谓自我阉割）

**「三层遮盖」这条已作废。** 那是给 80 年代农村场景写的老规矩，被我误套到了现代梦境上——现代都市白日梦本来就不该按农妇标准拍。

VOW 的实际基准，逐帧可查：真丝吊带睡裙、露肩露锁骨、蕾丝短裙、透纱白裙、湿发湿肤、运动内衣攀岩。这是**商业级 glamour**，不是擦边。我们的现代梦境场景对齐这个基准。

**真正的红线只有三条：**
- 不露点、不露三点区域；
- 不做性行为暗示体位；
- 不涉未成年。

除此之外——吊带、露肩、锁骨、腿部线条、湿发、汗珠、蕾丝、真丝质感，**全部可用**。

**顺带说一条 VOW 最值得学的**：它最有张力的一组是攀岩戏，穿得比泳池组多得多，但因为「仰角 + 汗珠 + 手部大特写 + 湿发黏颈」反而最抓人。**张力来自镜头语言，不来自脱**。这是效率最高的打法，不是保守的打法。

古装线（婉儿本体）另算：那边靠舞蹈、换装、红嫁衣、雨夜情绪，是另一套语汇。

## 四、序章提示词模板（可直接套用）

```
【EP0 序章 · 提示词骨架】

1. HOOK（0-10s，视频）
   一句话让玩家产生「我想成为他」的代入。

2. BREAK（10-18s，视频）
   一次剧烈的状态断裂（死亡/穿越/签约），旧身份结束。

3. CHOICE#1（18-22s，选择）  ← 首次交互
   情绪表态三选一，三个选项分别锚定三条数值线。

4. CONTRACT（22-30s，系统卡）  ← 最关键
   具象道具明示：你是谁 / 在哪 / 要做什么 / 有哪三条线。

5. HEROINE（30-45s，视频）
   女主第一次出现，给一个「她为你牺牲」的具体动作（把唯一的饭给你）。

6. STAKES（45-60s，视频+选择）
   亮出危机的物证（见底的米缸），玩家做第一个有后果的决定。

7. POWER（60-70s，视频+技能卡）
   给玩家解决问题的能力，形成「危机→能力」的闭环。

8. TEASE（70-75s，蒙太奇）
   女主未来形态闪回，制造收集欲。
```

## 五、对当前 EP01 的诊断结论

| 问题 | 现状 | 严重度 |
|---|---|---|
| 首次交互过晚 | 30s / 第 4 个节点 | 🔴 高 |
| 身份目标缺失 | 到 `s5` 才明确 | 🔴 高 |
| 首选择无效 | 三选项数值差 <5 且同一出口 | 🟡 中 |
| BE 无预警 | `f0` / `f_saoshi` 秒死无标记 | 🟡 中 |
| 结尾无预告 | `s6b` 技能卡后直接切集 | 🟢 低 |
