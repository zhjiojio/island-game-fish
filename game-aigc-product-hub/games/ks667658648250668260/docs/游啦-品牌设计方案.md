# 游啦 YOULA · 品牌设计方案

> 一个同时支持「做个小游戏」与「做个互动影游」的 AIGC 创作平台
> 中文名：**游啦** ｜ 英文名：**YOULA** ｜ slogan：**一句话，游啦！**

---

## 一、名字解读

### 为什么是「游啦」

**「游」承接两条业务线。** 游戏的游，游历的游。做小游戏是「玩游」，做互动影游是「游历一个故事」。
一个字同时装下了平台的两条腿，不用再解释我们到底做什么。

**「啦」是全中文里最轻快的一个语气词。** 它不是陈述，是报喜：饭做好啦、成啦、来啦。
「游啦」= 做好啦，能玩啦，快来玩啦。名字本身就是一次完工提醒 + 一次邀请，
天然带完成感和分享欲 —— 这正是创作平台最需要用户产生的两种情绪。

**它自带快手的底色。** 「啦」是老铁语感里最自然的尾音，热络、不端着、人人可参与。
比「工坊」「造化」那种端庄的名字更贴近快手的市井气，也更容易在评论区被喊出来。

### 与竞品的位置关系

竞品全在讲「我能生成」（开创、女娲、造化、AI 工坊），语气是庄重的、向上的。
「游啦」讲的是「做好了，快来玩」，语气是平视的、向外的 —— 它站在**用户拿到成品的那一刻**，
而不是站在生成的源头。这是一个没人占的情绪位置，也是最容易被传播的位置。

### 英文名

**YOULA**。五个字母，两个音节，全球任何语言都能读对。
可解为 **You + LA**（你的舞台）或直接音译。与 yoroll 同音域但更短、更响。

## 三、Logo 设计

### 主 Logo：字形方案

中文「游啦」两字横排，采用**圆头黑体重字重**，字形做三处改造：

1. **「游」字的三点水** —— 改为三个大小递增的圆点，从小到大向右上排列，
   像水花溅起，也像信号发射，暗示「从一个念头生发」。
2. **「啦」字的口字旁** —— 改为一个圆角方框，框内留白，
   视觉上等同一个对话气泡，呼应「一句话生成」的交互方式。
3. **「啦」字末笔** —— 向右上方甩出一道上扬的短尾，
   收笔带轻微加粗，像感叹号的余韵，把「啦」的雀跃感落到字形上。

### 图标 Logo：App / Favicon

取「啦」字的口字旁演化 —— 一个**圆角对话气泡**，气泡内是一个**向右的实心三角（播放键）**，
气泡右上角溅出三颗递增圆点。

一个图形同时说了三件事：对话（一句话生成）、播放（影游 / 可玩）、溅射（生成发生了）。
16×16 下仍然可辨：气泡轮廓 + 三角。

### 英文 Logo

`YOULA` 全大写无衬线重字重，字母 **O 内部嵌一个小三角播放键**，
字母 **A 的横画替换为一道上扬短线**，与中文版的甩尾呼应。

### 动效签名

Logo 入场统一动作：三颗圆点由小到大依次弹入（stagger 60ms），
随后「啦」字甩尾由短到长扫出，最后整体轻微回弹一次（scale 1 → 1.04 → 1）。
全程 520ms。这个「溅 — 扫 — 弹」的节奏是品牌的动效签名，在加载、生成完成、发布成功处复用。

## 四、色彩系统

沿用并收敛现有平台的暖米糖果风，确立主次，避免当前多彩并置导致的焦点涣散。

### 主色

| 角色 | 色值 | 说明 |
|---|---|---|
| 品牌主色 · 啦红 | `#FF4D6D` | 沿用现有 brand，热络、有呼喊感，用于主按钮、Logo、强调 |
| 品牌辅色 · 游蓝 | `#4DB4FF` | 代表「游历 / 影游」，与啦红构成冷暖对撞，用于影游侧 |
| 高光色 · 得意黄 | `#FFD466` | 用于成功、奖励、完成态的点睛，不做大面积 |

### 底色与墨色

| 角色 | 色值 |
|---|---|
| 页面底 · 暖米 | `#FFF5E4` |
| 卡片面 | `#FFFFFF` |
| 描边墨 | `#1A1633` |
| 分割线 | `#EFE6D6` |

### 业务线双色分工

这是本次设计的核心决策 —— **用颜色区分两条业务线**，让用户一眼分清自己在哪：

- **做个小游戏** → 啦红 `#FF4D6D` 主导，暖、快、上手即玩
- **做个互动影游** → 游蓝 `#4DB4FF` 主导，冷、深、有叙事纵深
- 平台外壳与公共区域保持暖米中性底，两色只在各自 tab 内生效

### 渐变与氛围

```css
--grad-game:  linear-gradient(135deg, #FF4D6D 0%, #FF9A5A 100%);
--grad-drama: linear-gradient(135deg, #4DB4FF 0%, #B77BFF 100%);
--grad-hero:  radial-gradient(120% 80% at 20% 0%, #FFE8D6 0%, #FFF5E4 60%);
```

首屏背景使用 `--grad-hero` 的暖光晕，配合极低透明度的圆点阵列纹理（呼应 Logo 的溅射点），
避免纯平底色的单薄感。

## 五、字体系统

| 用途 | 字体 | 字重 |
|---|---|---|
| 中文标题 | 阿里巴巴普惠体 / HarmonyOS Sans SC | Bold 700 · Heavy 900 |
| 中文正文 | 同上 | Regular 400 · Medium 500 |
| 英文与数字 | Space Grotesk | 500 / 700 |
| 代码与 ID | JetBrains Mono | 400 |

标题避开系统默认思源黑，选圆润度更高的普惠体，与「啦」的轻快气质一致。
英文用 Space Grotesk 而非 Inter —— 字形有个性、几何感强，不落入默认审美。

### 字号阶梯

```
Display  48 / 1.1   Heavy     首屏大标题
H1       32 / 1.2   Bold      页面标题
H2       24 / 1.3   Bold      模块标题
H3       18 / 1.4   Medium    卡片标题
Body     15 / 1.6   Regular   正文
Caption  13 / 1.5   Regular   辅助说明
```

## 六、形态语言

延续现有「硬阴影 + 粗描边」的糖果风，但规范化为三级：

```css
--stroke:    2.5px solid #1A1633;   /* 主容器描边 */
--hard:      3px 3px 0 #1A1633;     /* 主按钮、主卡片 */
--hard-sm:   2px 2px 0 #1A1633;     /* 次级元素、标签 */
--radius:    14px;                  /* 通用圆角 */
--radius-lg: 22px;                  /* 大卡片、首屏容器 */
--radius-pill: 999px;               /* 胶囊按钮、标签 */
```

**交互规则：** 按钮 hover 时向左上位移 1px、硬阴影加深至 4px；
按下时位移归零、阴影缩到 1px，模拟实体按键被压下。这个「可按」的手感是形态语言的核心。

## 七、核心界面设计

### 首屏

大标题 **「一句话，游啦！」**，副标题「说个想法，AI 给你做成能玩的小游戏和互动影游」。
下方是**单一输入框**，占据视觉绝对中心，placeholder 轮播真实案例：

```
做个东北老铁找茬的小游戏…
做个荒年开局的互动影游…
做个躲落石的手速游戏…
```

输入框右侧是一颗啦红主按钮「**游啦 →**」。
输入框下方一排胶囊标签给冷启动用户直接点：`找茬` `互动剧` `手速` `模拟经营` `恋爱`

### 双业务线入口

输入框下方两张并排大卡片，不是 tab 切换，而是**两个平行入口**：

- 左卡片：**做个小游戏** · 啦红渐变 · 副文案「三分钟出一个能玩的」
- 右卡片：**做个互动影游** · 游蓝渐变 · 副文案「有剧情、有分支、有结局」

两卡片用各自主色的渐变填充 + 墨色描边 + 硬阴影，hover 时轻微抬起。

### 工作台

左侧对话流（用户说 / AI 追问 / 构建进度），右侧真机容器实时预览。
构建流水线的每一步完成时，该步骤前的圆点由灰变为对应业务线主色，并播放一次 Logo 动效签名的「弹」。
全部完成时右侧真机弹出预览，顶部飘一条「游啦！做好了」的得意黄提示条。

### 精选墙

沿用现有 auto-fill 网格（1000px 四列 / 窄屏两列），卡片以**作品封面为主体**，
左上角一枚小色标区分类型（红点 = 小游戏，蓝点 = 互动影游），底部一行作者与玩过人数。

## 九、落地改造清单

基于现有 `demo-platform/`，按优先级：

1. `index.html` title 改为「游啦 YOULA · 一句话，游啦！」，首屏大标题与副标替换。

6. 补 Logo SVG（字形版 + 图标版）与 favicon，实现 520ms 动效签名。

## 十、一页总结

**游啦**把品牌站位从竞品扎堆的「我能生成」挪到了没人占的「做好了，快来玩」。
「游」装下小游戏与互动影游两条线，「啦」提供全中文最轻快的完工感与邀请感，
并天然咬合快手的老铁语感。

视觉上以暖米底承载啦红与游蓝的冷暖对撞，用颜色直接区分两条业务线；
以圆点溅射、对话气泡、上扬甩尾三个元素构成可复用的图形语言；
以「溅 — 扫 — 弹」520ms 节奏作为全站动效签名。

一句话：**一句话，游啦！**
