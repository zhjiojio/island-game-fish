# 视频字幕来源

当前运行时字幕只由 `verified/*.json` 构建。每份记录包含实际视频 URL、SHA-256、时长、ASR 字级时间轴、校正文案及复核备注。

运行 `make build-subtitles`（或完整 `make build`）生成 `package/js/subtitles.js`，随后运行 `make validate-subtitles`。`npm run build` 同样包含字幕构建。

旧目录中的 JSON/SRT 保留作历史资料；其中 `script-authoritative` 文本混入了动作描写，部分 SRT 还早于实际说话时间，已不参与构建。剧本节点 text 继续服务于剧情策划、日志和非视频页面，不能用来补视频字幕。

字幕按视频完整文件名匹配，包括 `_v82`、`_v83`、`.c`。新增或改名视频必须先补充相应 ASR 来源，构建时缺失会报错，不会剥掉版本号套用旧字幕。视频改版请换文件名，并重新记录下载哈希；同名覆盖 CDN 文件无法仅靠离线构建识别。

本轮核对了 99 个实际视频，均下载并计算哈希，使用本地 Paraformer 与 Whisper 交叉识别。95 条记录已完成对白修订或确认无对白/无音轨/仅非语言发声。另有 4 条存在原音歧义：

- `e4s6.c`：打斗声下无法确认整句，暂不绘制猜测字幕。
- `e8s5_v82`：开头短语及“一亩地”后两字含混，保留可确认内容。
- `e8s6_v82`：“我就要你”后音节含混，保留可确认内容。
- `r_f_e7s2_a_v82`：“他…报了出去”中间词含混，保留其余台词。

这些记录使用 `partial_review` / `unclear_audio` 并保存 `audioReview` 时间范围。它们不是人工听写已确认的完整台词；复听明确后再更新对应 transcript 与状态。不得将识别不出的部分擅自替换为剧本。
