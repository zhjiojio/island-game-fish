# 斗地主 联机游戏创意

## 创意概述

经典三人斗地主卡牌游戏，纯 Canvas 渲染，WebSocket 多人联机。

## 核心玩法

- 3 人一桌：1 个地主 vs 2 个农民
- 54 张牌（含大小王）
- 叫地主 → 出牌 → 结算循环
- 支持全部标准牌型：单张/对子/三条/三带一/三带二/顺子/连对/飞机/四带二/炸弹/火箭

## 目标用户

- 休闲卡牌游戏爱好者
- 喜欢实时联机对战的玩家
- 快手小游戏用户

## 差异化

- 纯 Canvas 渲染，性能优异
- WebSocket 实时联机，低延迟
- 快手登录 + 分享邀请好友
- 房间创建/加入/解散机制
- 支持断线重连

## 创意来源

用户明确需求 + 参考桌面斗地主实现。
