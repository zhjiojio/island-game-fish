# 场景 1「80 年代来找茬」· 拓展 Lv19~Lv28 关卡策划

> **版本**：v0.4.x 规划 · 2026-08-14
> **参考**：[老铁找茬王视觉素材范式库 v1.0](https://docs.corp.kuaishou.com/d/home/fcAABjhlSl7kiG41I8bKrmynR)
> **约束**：
> 1. 严禁复用 Lv1~Lv18 已出现的现代违和物（清单见附录 A）
> 2. 每关茬数 ≤ 5，重点在「深度融合的巧妙嵌入」，不求数量
> 3. 难度梯度：承 Lv18「究极地狱」（7 茬）之后，先深谷喘息再重新爬坡
> 4. 敏感词禁用：供销社 / 洗浴中心 / 国营 / 春运 / 生产队
> 5. 标题 ≤ 8 字，不带「地狱 / BOSS」难度词
