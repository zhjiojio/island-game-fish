# 主题5「吃瓜现场」剧情与关卡 V2

## 项目结论

- 剧名：**《1808房间》**
- 类型：连续捉奸悬疑爽剧。
- 总关卡数：**20关**，分4章，每章5关。
- 总线索数：**146个**。
- 当前制作范围：**只制作第1～5关**；第6～20关先锁剧本，不生正式图、不上传、不标注。
- 核心真相：老公周铭与闺蜜林薇长期出轨，并计划在结婚周年宴后逼妻子苏晴离婚、转移共同财产。秘书许妍一度被误认为第三者，实际是匿名举报人和后期盟友。

## 难度标准

| 难度 | 体验目标 | 线索构成 | 建议时间 |
|---|---|---|---:|
| ★★ | 教学但不白送 | 1易、3中、2难 | 60秒 |
| ★★★ | 开始需要完整扫图 | 1易、2中、3～4难 | 55秒 |
| ★★★★ | 多数玩家会需要一次提示 | 1易、2～3中、4难 | 50秒 |
| ★★★★★ | 章节高潮，主打广告提示/续时 | 0～1易、2～3中、5难 | 45秒 |

难度来自物体尺寸、透视、同色伪装、自然纹理和前中后景切换；不得靠错误坐标、遮死答案、过暗画面或重叠热区制造失败。

## 第一章：他没有出差（第1～5关，33条线索）

### 第1关 · 主卧里的她

- 线索数：**6**
- 难度：**★★**
- 开场：结婚纪念日前夜，周铭说公司临时有事。苏晴回卧室拿充电器，却发现房间里多了另一个女人的痕迹。

- 通关揭示：这些东西来自同一个女人，而且她刚刚在这里待过。
- 下一关钩子：周铭拿着手机躲进浴室接电话，门没有关严。

### 第2关 · 浴室里的第二个人

- 线索数：**6**

## 美术与标注硬规则

- 当前只制作第1～5关；用户确认后再继续下一章。
- 每关必须先列出全部线索，再生图；生图后逐项点数，少一个就不得进入标注。
- 图片内只允许准确简体中文和阿拉伯数字，禁止英文、日文、繁体字和乱码。
- 线索物不挨得过近，不重叠、不交叠、不互相包含；热区之间必须留出明确空隙。
- 不使用四角网格藏法。答案分布在前中后景、家具表面、墙面、地面和纵深区域。
- 视觉物体可以小，点击热区必须适当放大；难度不能来自点不中。
- 每关至少保留一个较明显线索帮助玩家进入状态，其余线索通过透视、同色和纹理增加难度。
- 广告提示只高亮一个尚未找到的线索；广告续时建议每次增加45秒。
