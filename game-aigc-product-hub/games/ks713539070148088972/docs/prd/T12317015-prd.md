## 1. 产品概述

### 1.1 一句话定位

「火眼来找茬」是一款快手平台休闲观察力小游戏：玩家进入不同影视/IP 风格的主题，用眼力完成找茬、找不同、寻物、换装、拼图、剧情找线索等多玩法关卡挑战，看广告获得道具与解锁能力，靠"眼越尖、过得越快"形成正向循环。

### 1.2 背景与目标

- **背景**：游戏已完成 v1.0.0 提测（单关卡换装版本），后续迭代形成 v2.0.0 多主题 × 多玩法完整形态，需回测确认当前功能完整性与合规可用性。
- **产品目标**：
  1. 玩家在首页能一眼看懂"主题活动 + 多种玩法"的差异化体验；
  2. 广告变现链路（IAA）完整可用，看完必得、中途关闭必不得；
  3. 内容可通过远程配置持续上新主题/关卡，客户端无需发版。

### 1.3 目标用户

快手 App 内浏览小游戏/小玩法入口的自然流量用户，以休闲玩家为主，利用碎片时间 1-3 分钟完成一关。

---

## 2. 核心体验闭环

```
欢迎页 → 首页主题选择 → 关卡内玩法 → 结算（通关/失败）
              ↑                    ↓
              └── 看广告换道具/解锁主题 ←┘
```

- **欢迎页**：展示游戏主视觉，新用户可一键直飞首关（冷启动新手引导），老用户走正常选主题路径。
- **首页（主题选择）**：展示主题活动卡片，含封面、主题名、玩法标签、关卡进度、锁定状态。
- **关卡内**：按主题玩法类型进入对应模式，内含限时、道具栏、进度 HUD。
- **结算**：通关（含星级）/ 失败（可复活/重来），并引导下一关或下一主题。

## 3. 功能需求

### 3.1 主题与关卡系统【P0 · 数据驱动】

| 需求项 | 描述 |
|---|---|
| 主题数据 | 全部主题与关卡数据**从远程 JSON 拉取**（唯一配置来源，无本地 baseline），支持运营随时上新/调整 |
| 主题字段 | 主题 id、名称、封面（http 开头校验）、隐藏标记 hiddenIdxRanges 运行时过滤 |
| 关卡字段 | themeId、序号 idx、标题、玩法 mode、时长 duration、难度 diff、提示文案、Boss 关标记、目标物品 odds（x/y/w/h 百分比 + clue 线索文案） |
| 拉取策略 | 超时/失败自动重试（最多 3 次），最终失败展示"空态 + 重试按钮"，不卡死 |
| 内容现状 | 当前远程配置含 **20 个主题**：换装类 7 个（职业换装、同框恋人、剧中身份等）、找茬/找不同 6 个（好汉找异常、黛玉来找茬、慧眼识三国等）、找隐藏 5 个（真假美猴王、同福客栈、一眼找不到等）、拼图 2 个（爱情公寓、识君归位） |
| 难度曲线 | 按玩法内置 setupSec + 目标物数量 × perOdd + Boss 加成计算建议时长；支持关卡内联 diff 覆盖全局难度键 |
| 宽容机制 | 连续失败多次后自动触发 mercy 宽容（放宽判定/时长），降低挫败感 |

### 3.2 多玩法系统【P0】

一主题一套玩法，六大模式全部可用：

| 玩法 mode | 名称 | 核心规则 |
|---|---|---|
| `hidden` | 找出图中的穿越物 | 在场景图中找出若干"不该出现"的物品，点击命中，限时 60s |
| `spot` | 找出上下两幅图不同之处 | 上下双图对照，点出差异点 |
| `hunt` | 寻物 | 按线索清单逐个找出目标物 |
| `story` | 剧情找线索 | 开场案件简报（点「开始」才计时）→ 旁白打字机气泡逐条搜证 → Boss 关卡触发亮度变化 |
| `dressup` | 换装 | 看场景/台词 → 从候选衣服中选对的一套换上，支持点选与拖拽、角色切换、气泡对话 |
| `puzzle` | 拼图 | 拖动碎片到正确位置 |

每个玩法独立实现 `assetGroups`（进关前资源清单）、`hint`（提示效果）、`revive`（复活恢复量）等接口，新增玩法只需注册，无需改业务代码。

### 3.3 局内规则与道具栏【P0】

| 项 | 规则 |
|---|---|
| 限时 | 每关倒计时递减，归零即失败结算 |
| 错误次数 | 答错/点错扣 1 次，扣光即失败 |
| 失败结算 | 失败弹窗给出「看广告复活」（按 limitType 精确恢复：加时或加次数）与「重来」「回首页」 |
| 复活加时 | 加时超出关卡原始时长依然生效（不被钳制） |
| 星级 | 通关后按剩余时间比例评星：≥50% 三星、≥25% 两星、>0 一星 |
| 道具栏 | 底部广告按钮栏，各玩法可独立配置开关：加时、放大（双指缩放手势）、+5 次机会、提示（每玩法可配置每关最大使用次数）、跳关（连续看 2 个广告直接进入下一关） |

### 3.4 广告变现（IAA）【P0】

全部走激励视频，一步一反馈、零静默失败：

| 入口 | 位置 | 看完后效果 |
|---|---|---|
| 提示 | 关卡内道具栏 | 高亮/引导当前未找到目标（dressup/puzzle 走玩法内 onHint 效果） |
| +30s 加时 | 关卡内道具栏 | 倒计时 +N 秒（按玩法配置），Toast 提示 |
| +5 次机会 | 关卡内道具栏 | 错误剩余 +5，Toast 提示 |
| 放大 | 关卡内道具栏 | 启用双指捏合缩放，便于看细节 |
| 跳关 | 关卡结算/进行中 | 连续看 2 条广告直接进下一关 |
| 看广告复活 | 失败弹窗 | 按玩法 limitType 精确恢复对应资源（加时或加次数） |
| 解锁下一主题 | 主题切换处 | 看进度型广告解锁下一个未解锁主题 |
| 解锁全部主题 | 首页/主题切换处 | 连续看 3 条广告全部解锁，支持限时解锁时长（到时自动回锁） |
| 语音包解锁 | 语音包入口 | 每日看广告解锁当日语音包 |

**广告规范**：
- 看完「立即到账」：奖励真正写入状态并展示 Toast；
- 中途关闭：**不发放任何奖励**，并给出明确"未完成"提示，不静默失败；
- 加载失败/无填充：合理提示并恢复游戏，不卡死；
- 广告期间游戏逻辑暂停（暂停计时/暂停点击），结束后恢复。

### 3.5 主题解锁与进度存档【P0】

| 存档字段 | 含义 |
|---|---|
| passedLevels | 已通关关卡 |
| themeUnlocks | 已解锁主题 |
| themeUnlockAdCount / unlockAllAdCount | 主题解锁/解锁全部的广告计数进度 |
| tempUnlockAllUntil | 限时"解锁全部"的到期时间戳 |
| stats / playtimeMs | 个人成绩与总游玩时长 |
| sfxEnabled / bgmEnabled | 音效/BGM 开关 |
| shortcutInstalled | 是否已加桌面 |
| newUserFirstLevelDone | 新手引导标记（老用户走正常流程） |
| checkinState / checkinPropCount / checkinHintCount | 签到周期状态与奖励计数 |
| failStreak | 各关连续失败计数（宽容机制依据） |
| voicePack / voiceUnlocks | 当前语音包与每日解锁状态 |

- 快手环境存 `ks.setStorageSync`，H5 环境存 `localStorage`。
- 解锁全部主题支持"永久白名单 + 限时到期自动回锁"两种模式。

### 3.6 登录与社交互动【P1】

| 需求项 | 要求 |
|---|---|
| 登录 | 快手一键登录（session 校验 + 拿 code），code 换 openId 需后端支持（本期未接后端，走游客态） |
| 用户信息 | 拉取头像/昵称；授权被拒→静默回退默认头像 + 兜底昵称"铁子"，不阻塞游戏 |
| 分享 | 结算页"分享"按钮，调起对比分享（查看谁更快/击败百分比），模板 id 待补填 |
| 加桌面 | "添加到桌面"按钮调起平台能力，失败不阻塞 |

### 3.7 每日签到【P1】

- 7 天循环签到，连续签到递增奖励（道具/提示计数/限时解锁全部主题时长）。
- 断签后连签天数重置；奖励类型支持 prop / hint / hourly（限时解锁全部）多种。
- 道具/提示计数暂为独立计数，消耗侧系统待后续版本接入。

### 3.8 语音包系统【P1】

- 多套语音包（不同人设配音），支持 BGM/SFX/VO 三类音频统一管理。
- 语音包支持"每日看广告解锁当日包"的每日轮换模式。
- 运营可配置分包开关（voice-extra 分包），生产环境按需开启避免音效缺失。

### 3.9 新手引导与冷启动【P0】

- 新用户（无完成标记）首次进入 → 欢迎页一键直飞第一关（跳过主题选择）。
- 老用户正常路径：欢迎页 → 首页选主题。
- 欢迎页资源可预热加载，提前拉取首关素材缩短白屏时间。

## 5. 验收标准（摘要）

1. **启动**：iOS/Android 双端冷启动 ≤ 5s，二次启动明显更快，无白屏卡死；
2. **存档**：清缓存后回初始态，存档字段跨退出重进仍生效；
3. **广告**：4 大入口真实拉起，观看完毕奖励到账，中途关闭不发奖 + 明确提示；
4. **玩法**：6 大玩法各选 1 关全流程跑通，不卡死不误触；
5. **内容**：远程配置拉取成功，主题/关卡能正确加载与展示；
6. **解锁**：进度型解锁计数正确累加；限时解锁到期自动回锁；
7. **复活**：失败→看广告复活→资源精确恢复，不重复扣；
8. **合规**：隐私政策可访问且入口可见；实名防沉迷不阻塞。
