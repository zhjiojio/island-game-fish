# 自助餐消消乐 v1.0.53

## 运行与架构

package/是唯一运行包。H5入口index.html；快手入口game.js → js/main.js，两条链共用原生JavaScript、Canvas 2D和M3命名空间，无后端、数据库或运行时npm依赖。根目录运行 node tools/preview.cjs 可预览8766端口。

按用户两份框架规范保留登录、授权、分享、分包、远程关卡与埋点适配骨架。尚未对接的能力不冒充成功。所有页面、弹窗、餐架、食物和动画使用750×1624设计坐标，经Canvas变换适配实际屏幕并反算触摸位置。素材保留原始像素尺寸，绘制时等比缩放。食物与关卡数据使用三消结构，不采用找茬odds字段。

## 当前规则

- 100关；1–2关6组、3–4关9组、5关起12组，每组横向3空位。前4关不限时。
- 一次拖动一个食物，可同架调整空位，不能覆盖或交换。普通消除仅锁正在动画的餐架，道具动画锁全场。
- 三同类消除；大架清空才整层补位。每层1–3份，初始每组至少3层；视觉最多显示3层，无层数数字。
- 每次消除1星，10秒内连击额外1星，道具消除计连击。局内显示历史余额加当局未花星星；通关结算，主动退出/失败丢当局未花余额，历史余额不倒扣。
- 刷新、打包、变换均100星，无每关一次限制。库存优先；无库存且余额足够弹广告/支付二选一；不足直接广告。没有打包×2和自动刷新。
- 刷新只重排剩余食物，至少保留开局空位；优先为原有非空补位盘保留一层，残局上方可增加空位，不生成新食物。
- 变换优先9/6/3份交换保持数量；兜底先重排形成同类三元组，全部食物仍在变换快照中，再走正常消除及补位动画，不直接扣除食物。
- 共100关，末关胜利弹窗的下一关替换为返回首页，保留重玩本关。
- 体力每10分钟+1，自然上限5；广告+1可超过5。开始新局消耗1，续局不重复扣。
- 星星广告+100，神秘道具广告随机+1库存；每日挑战广告解锁，完成自动+200星，北京时间06:00重置。
- 首次超时可广告复活60秒，第二次直接失败。归零后不能接受新移动，已开始的动画允许完成。广告、弹窗、后台暂停计时。
- 切后台/关闭保存续局；主动退出清除本局。存档版本2，兼容结构完整的无版本旧存档，异常数据拒绝恢复。
- 新增确认规则：保留首次添加桌面+100星、设为常用+5体力。桌面需checkShortcut返回installed=true后一次性发奖；不支持验证不发奖。设为常用验证接口尚待核实，目前仍是说明入口，不发放奖励。

## 资源

## 验收与发布

当前10套专项回归165项通过；新增边界/流程21项、平台修复12项通过；原生SDK模拟通过，不代表真机验收。初始布局验证有完整解，不代表玩家任意操作都不会卡局。

仍须开发提供：真实广告位ID、项目appid、如需CDN则提供域名与分包策略、埋点映射、设为常用验证接口。不要在CDN未配置时排除必需资源。当前激励广告未配置时明确失败；H5广告是人工点击的模拟流程，不产生收益。

规范的插屏/Banner示例不是本游戏已确认的广告需求，本版不擅自增加。登录、授权、分包、CDN与埋点骨架保留但未宣称全部投产。

纯前端本地存储没有跨设备同步、账号级防刷和强反作弊保证；一次性奖励目前按本地存档幂等。存储失败会显示提示，不能保证异常设备强制退出后仍能恢复。
