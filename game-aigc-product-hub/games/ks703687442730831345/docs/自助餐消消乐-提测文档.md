## 一、产品是什么（一句话）

这是一款快手休闲三消小游戏。玩家将餐品拖到餐架空位，在同一个餐架内凑齐 3 份相同餐品即可消除；持续清空餐架并使用道具，完成自助餐挑战。

**核心体验闭环**：进入首页 → 消耗 1 点体力开始关卡 → 观察餐架与隐藏餐品 → 拖动餐品到空位 → 同架 3 个相同餐品自动消除 → 餐架清空后下方餐盘补位 → 清空全部餐品通关；时间耗尽时可看激励广告复活一次或结束本局。

## 二、核心功能逻辑

### 2.1 主流程

```text
HOME 首页 → GAME 关卡内 → WIN 通关结算 / LOSE 失败结算 → 下一关 / 再试一次 / 返回首页
```

| 阶段 | 界面内容 |
|---|---|
| HOME | 游戏标题、星星、体力、开始按钮、每日挑战、获得星星、获得道具、设置等入口 |
| GAME | 餐架、餐品、星星与连击反馈、计时器、刷新/打包/变换道具、返回与设置入口 |
| WIN | 通关结算、星星奖励、再玩一次、下一关 |
| LOSE | 失败提示、再试一次、返回首页 |

### 2.2 一次移动的生命周期

```text
玩家按住餐品 → 拖动跟手 → 松手检测目标空位
  → 合法：餐品移动并进入动画 → 同架凑齐 3 个相同餐品则消除 → 星星/连击奖励 → 必要时餐盘补位
  → 非法：不移动、不扣资源、不改变局面
```

**关键规则**：

- 只能拖到餐架的空位，不能交换已有餐品。
- 可拖到当前餐架或其他餐架的空位。
- 同一个餐架横向最多放 3 份餐品；同架凑齐 3 份相同餐品自动消除。
- 餐架清空后，下方整层餐盘自动补位。
- 动画、弹窗、广告期间不响应重复操作。
- 第 1 关首次进入有引导，按提示拖动高亮餐品；完成引导后继续游戏。

### 2.3 关卡与资源

- 当前代码预置 100 个关卡，关卡按餐架数量、餐品种类和三元组数量递进。
- 第 1～2 关使用 6 个餐架，第 3～4 关使用 9 个餐架，后续关卡使用 12 个餐架。
- 第 1～4 关 `duration` 为 0，属于不计时关卡；第 5 关起开始计时，时长按关卡递进。
- 初始体力为 5/5；开始一局消耗 1 点体力，体力每 600 秒恢复 1 点，上限 5 点。
- 通关获得星星，连击窗口为 10 秒，连续消除有额外奖励。

### 2.4 道具与激励广告

广告位：`2300061896_01`（激励视频）。H5 预览环境走平台降级逻辑，广告相关结果以快手真机为准。

| 入口 | 方式 | 效果 |
|---|---|---|
| 体力 | 看完广告 | 体力 +1，不超过 5 点 |
| 获得星星 | 看完广告 | 星星 +100 |
| 获得道具 | 看完广告 | 随机获得刷新、打包、变换其中 1 个 |
| 刷新 | 看广告或支付 100 星星 | 重新排列尚未消除的餐品，恢复开局空位，不直接增加星星 |
| 打包 | 看广告或支付 100 星星 | 随机打包 3 份相同餐品 |
| 变换（魔法棒） | 看广告或支付 100 星星 | 按剩余数量变换 9、6 或 3 份餐品，并保证局面可继续 |
| 时间复活 | 时间耗尽时看广告 | 本局复活一次，增加 60 秒；再次耗尽进入失败结算 |
| 每日挑战 | 看广告解锁 | 每日生成挑战任务，完成后奖励 200 星星 |

看广告未完成或广告失败时不得发放对应奖励，应有提示且不能卡死。

## 三、重点关注的功能点与验收标准

### 3.1 平台与启动【P0】

| 功能点 | 产品要求 |
|---|---|
| 启动 | iOS/Android 扫码后能进入首页，无白屏、黑屏、卡死 |
| 首屏资源 | 标题、背景、按钮、餐厅相关素材正常显示，无裂图 |
| 竖屏与安全区 | 竖屏展示，顶部内容不被刘海或状态栏遮挡 |
| 音乐 | 首次资源准备完成后背景音乐可初始化；点击操作后可恢复播放；设置可开关音乐 |
| 登录 | 授权拒绝不阻断游客态游玩 |
| 隐私合规 | 隐私政策、用户协议入口和内容需按提审要求确认；当前项目提供 `docs/game-privacy.md`，上线前需完成真实入口链路验收 |

### 3.2 首页与体力【P0/P1】

| 功能点 | 产品要求 |
|---|---|
| 开始游戏 | 体力充足时进入关卡；体力不足时弹出获得体力弹窗，不进入关卡 |
| 体力显示 | 显示当前体力与恢复倒计时；初始值为 5/5，上限为 5 |
| 每日挑战 | 入口可打开；未解锁时可看广告，解锁后显示当日任务状态 |
| 星星/道具 | 获得星星、获得道具入口可打开并正确发放资源 |
| 设置 | 音乐、音效、震动开关状态可切换并持久化 |

### 3.3 关卡内核心玩法【P0】

| 功能点 | 产品要求 |
|---|---|
| 餐架展示 | 餐架、餐盘、餐品清晰可见，隐藏餐品层级正确 |
| 拖拽 | 餐品跟手移动，松手到空位后完成移动；拖到非空位不改变局面 |
| 三消 | 同一餐架凑齐 3 份相同餐品后自动消除，动画完整且只奖励一次 |
| 补位 | 餐架清空后下方餐盘自动补位，补位后状态与可操作区域正确 |
| 反馈 | 消除显示星星奖励，连续消除显示连击反馈；不可重复触发 |
| 防误触 | 动画、道具执行、弹窗和广告期间不可重复移动或重复扣费 |
| 引导 | 第 1 关首次进入展示引导，按提示完成后进入正常玩法 |

### 3.4 道具、广告与结算【P0】

- 广告看完才发放奖励，中途关闭、失败或无填充不发放奖励。
- 刷新应恢复空位且不直接消除；打包和变换后局面必须可继续，不得产生非法餐品数量。
- 同一局时间耗尽首次可选择广告复活；复活后再次耗尽进入失败结算。
- 通关后星星计入历史余额，当前局快照清除；失败时当前局未结算星星清除，历史余额保留。
- 下一关推进不越界；最后一关应回到首页或关卡入口，不白屏、不死循环。

### 3.5 存档与异常【P0/P1】

- 星星、体力、工具库存、关卡等级、设置开关、每日挑战状态应在退出重进后保持正确。
- 游戏中支持运行快照；异常退出重进后应尽量恢复未结束局面。
- 断网、切后台、来电、广告无填充时不崩溃、不永久卡住、不误发奖励。

## 六、已知边界与非阻断项

- 当前为自助餐补位三消玩法，不是按题目选择答案的找茬玩法。
- H5 环境的广告接口可能直接走奖励降级分支，不能据此验收真实广告展示与关闭回调。
- 登录、加桌面、平台震动等能力在 H5 环境不可完全验证。
- 当前项目使用 Canvas 2D 渲染，并通过分包加载 `assets-all` 资源；属于当前实现方案，测试重点是显示、加载和交互结果。
- 拖拽体验以真机触控为准，需记录跟手性和误触，但不以桌面鼠标体验替代移动端结论。
