## 一、基础 UI

### 设计域与安全区
- 画布：9:16，设计基准 1080×1920（游戏内以 vw/vh 等比缩放，DPR 自适应）。
- 顶部安全区：状态栏下 88px 内只放主播卡与右上角胶囊/关闭，不放剧情表演。
- 底部安全区：礼物栏 + 输入栏占底部 ~320px，字幕与选择必须落在其上方。
- 中央表演区：竖屏中部为角色视频/图片主舞台，两侧不压角色脸部与关键动作。

### 色彩与氛围（酒吧世界观）
- 基底：深黑棕 `#0d0a08` → `#1a1210` 渐变（暖光酒吧夜店）。
- 主强调：霓虹金 `#ffd257` / 暖金 `#f5a623`（星光、排名、店长仪式）。
- 对抗色：PK 左金 `#ffca3a` ↔ 右红 `#ff2e4d`。
- 点缀：霓虹红 `#e83b52`、粉 `#ff5b8a`（应援花/告白气球）、冷蓝紫 `#6a5cff`（星球礼物）。
- 弹幕：半透明白字带柔和描边，昵称用彩色。

### 字体
- 中文：系统黑体族（PingFang/思源黑），标题加粗；数字用等宽感强调票数/星光。
- 层级：主播名 32、排名名 26 / 票数 24、弹幕 26、字幕 34、选择 30、礼物名 24 / 价 20。

### L3 拟物材质（关键组件 ≥5 层：底材/投影/高光/描边/纹理）
1. **礼物图标**：拟物 3D——小心心（粉红玻璃高光）、啤酒（琥珀液体+泡沫+杯壁反光）、火箭（金属机身+尾焰）、穿云箭（红晶箭簇+流光）、星球（紫蓝星环+镜面高光）、提艾默之夜/幸运城堡（金色宫殿+粒子）。底材+内阴影+顶部高光+金色描边+表面纹理。
2. **排名徽章**：1金2银3铜金属牌，浮雕数字+边缘高光+投影+底纹。
3. **PK 进度条**：胶囊玻璃管，左右两色液体填充，中缝"PK"金属徽章+发光，下挂倒计时药丸。
4. **星光余额药丸**：深底+金环描边+星芒图标+内发光。
5. **看广告按钮**：暖金渐变胶囊+"📺 看广告 +10"，按下内凹。

### 对话 / 字幕
- 角色台词：底部字幕条（半透明黑底+金色说话人名+白色正文），带角色小头像。
- 老板助理（中控）旁白：顶部横幅式黄字通告条。
- 长文案自动分行，最多 3 行，超出滚动；不遮脸不越界。

### 选择
- 选择卡：2–4 张竖排卡片，浮在字幕上方；卡含图标+主文案+副文案（星光消耗）。
- 状态齐全：idle / hover / pressed / disabled（星光不足灰化并提示看广告）/ selected（金框+勾）。
- 选中后播放对应礼物特效再跳转。

### 章节 / 转场
- 幕间转场：黑场+金色幕标题（如"第一幕 · 竞选出场"）淡入淡出 0.6s。

### 暂停 / 加载 / 错误 / 结局 / 重玩
- 加载：酒吧霓虹 logo + 进度条 + 首帧海报占位。
- 暂停：右上暂停键 → 半透明遮罩 + 继续/静音/重玩。
- 媒体失败：占位海报 + "点击重试"，不黑屏。
- 结局：今日店长金座仪式（还原 012735）+ 结局台词 + "再玩一次"/"选别的候选人"。
- 静音：全局静音开关（顶部胶囊区），持久化。

### 反馈五件套
飘屏礼物动画、票数滚动跳变、排名榜实时重排、亲密度升级 toast、屏幕暖光脉冲。

## 二、剧情专属 UI（仅关键节点）

### A. opening / intro-host / candidate-voices（还原 012739 开场剪影）
- 情绪目标：悬念、窥探欲。玩家身份=刚刷进的老板。
- 表演区：中央屏风后四剪影（视频/动图），左下 "Cocktails & Dreams" 霓虹。
- 信息显隐：候选人只显剪影+昵称，脸不可见；点击剪影看一句介绍。
- 关系感知：团员排名榜显票数与倒计时"距结算"。
- 转场：老板助理旁白横幅逐条推入。

### B. *-a1 亮相 / *-a3 龙哥PK / *-final 巅峰（还原 012729 PK 应援）【代表节点组】
- 情绪目标：应援上头、对抗紧张。
- 表演区：中央候选人真人视频；PK 时左右分屏（你的候选人 vs 龙哥候选人）。
- PK 进度条：中部两色百分比+倒计时；票数变化实时驱动。
- 选择形式：底部礼物栏点击送礼；关键节点弹选择卡（提艾默之夜 all-in / 看广告攒星光）。
- 关系变化感知：送礼→候选人镜头前专属反应+亲密度 toast（路人→常客→铁杆→守护大哥）+ 排名榜跳动。
- 道具交互：礼物飘屏（花瓣/啤酒杯/火箭/星河/星空降临）+ 全服通告条（提艾默之夜）。
- 字幕安全区：候选人台词落底部字幕条，不被礼物特效压住。

### C. *-ending 结局（还原 012735 今日店长加冕）
- 情绪目标：加冕仪式感、情感回报。
- 表演区：金色宝座候选人手捧花束居中，其余三人两侧鼓掌，礼花金屑漫天。
- 结局仪式：顶部"今日店长"金牌皇冠，左侧钥匙串+荣誉披风递入，最终排名榜定格。
- 专属台词：该候选人结局白（4 条结局各不同）。

## 三、代表节点（唯一送审代表体验）

选定 **`pijiu-a3`（第三幕·啤酒妹·龙哥出现 PK 选择）** 作为代表节点，直接对标参考图 012729。

它同时覆盖：
- 真实角色/场景：啤酒妹真人视频（源素材裁剪）+ 酒吧 PK 场景。
- 真实字幕：啤酒妹"老板……人家刚才还是第一的……"。
- 真实选择：提艾默之夜 all-in（500 星光）/ 看广告攒星光。
- 关系或情绪反馈：送礼后亲密度升"守护大哥" toast + 排名反超动画。
- 剧情专属交互：礼物飘屏 + PK 进度条实时驱动 + 全服通告。

### 代表节点可观察验收标准（UI Designer 与 Media Director 同一份）
1. 首屏 1s 内出现啤酒妹主视频或其首帧海报，不黑屏。
2. 团员排名榜（4 人+票数+金银铜牌）、PK 进度条+倒计时、右侧弹幕流、底部礼物栏（小心心/啤酒/火箭/穿云箭/星球/送礼）全部就位且不重叠。
3. 点"送礼→提艾默之夜"：星光足→飘屏星空特效+全服通告+票数跳变+排名反超+亲密度 toast→跳转；星光不足→按钮灰化并弹"看广告 +10"。
4. 啤酒妹台词字幕清晰可读，不被礼物特效或礼物栏遮挡。
5. 窄屏（360px 宽）下无截断、无遮脸、无越界；触控目标 ≥44px。
6. L3 拟物：礼物图标与 PK 条呈现底材/投影/高光/描边/纹理五层，非灰白默认控件。

## 四、媒体构图约束（给 Media Director）
- 所有角色媒体 720×1280 或 1080×1920 竖屏；人脸落在中上部安全区，不被顶部主播卡/底部礼物栏裁切。
- 源视频（各候选人 output.mov / 主场景.mp4 / 卡座.mp4 / 瑜伽.mp4）需裁剪/转码为游戏可用 MP4（H.264）与首帧 PNG。
- 普通对话优先动态图片；候选人亮相、才艺、龙哥对抗、终局优先视频。
- approved Anchor：以三张 Kim*.png 为角色身份基准（兔耳啤酒妹为代表主角）。
