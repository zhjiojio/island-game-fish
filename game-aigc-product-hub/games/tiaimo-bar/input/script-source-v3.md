# 提艾默酒吧 · 店长争夺战 — 游戏剧情脚本 v3.3

> 类型：剧情模拟 · 直播间互动 · 选择分支
> 场景：提艾默酒吧店长竞选直播间
> 玩家视角：刷到直播间的实力老板/投资人
> 初始星光：50 星光（仅可通过看广告获取）

---

## 一、整体游戏框架

### 1.1 核心设定

提艾默酒吧原店长突然跑路，老板助理从员工中挑出四位候选人竞选新店长。玩家刷到直播间，作为实力大哥参与投票、应援、决策，帮助心仪的候选人当选。

### 1.2 核心循环

```
刷到直播间 → 老板助理介绍候选人 → 玩家用星光应援 → 候选人亮相/才艺/考核 → 排名变化 → 拉票/惩罚 → 新一轮竞争 → 最终店长诞生
```

### 1.3 星光系统（游戏内唯一虚拟货币）

游戏内不涉及任何真实付费。**"星光"是唯一虚拟货币**，用于应援候选人。

| 星光来源 | 数量 | 方式 |
|---------|------|------|
| 初始星光 | 50 星光 | 游戏开始自动获得 |
| 看广告获取 | +10 星光 / 次 | 观看 15s 激励视频广告 |
| 剧情奖励 | 15 ~ 60 星光 | 达成阶段目标时触发 |

**广告观看**：**不设上限**，玩家可自由决定看多少次广告攒星光。单次广告 15 秒，看完即得 10 星光。

### 1.4 礼物体系（星光兑换的直播道具）

送礼物时消耗星光，票数计入你应援的候选人排名。

| 礼物 | 消耗星光 | 视觉效果 | 投票权重 |
|------|---------|---------|---------|
| 🌸 应援花 | 1 星光 | 飘屏粉色花瓣 | 1 票 |
| 🍻 干杯 | 3 星光 | 啤酒杯碰撞特效 | 10 票 |
| 🎆 霓虹烟花 | 20 星光 | 烟花升空+尾焰 | 300 票 |
| ✨ 星河闪耀 | 100 星光 | 全屏星河划过+音效冲击 | 2880 票 |
| 🌌 提艾默之夜 | 500 星光 | 全屏星空降临+全服通告+震动 | 30000 票 |

**送礼物时必须指定应援哪位候选人**，票数计入该候选人排名。

### 1.5 排名与亲密度系统

四位候选人实时排名，根据支持票数动态变化。玩家对每位候选人独立计算亲密度：

- 0-500 票：**路人老板**（候选人礼貌感谢）
- 501-2000 票：**常客老板**（候选人主动互动、记住 ID）
- 2001-5000 票：**铁杆老板**（候选人专属称呼、私下撒娇/争宠）
- 5001 票以上：**守护大哥**（剧情高潮、表忠心、竞选宣言感谢你）

### 1.6 游戏节奏（四幕结构）

- **第一幕「竞选出场」**：悬念建立，逐层揭开候选人面纱（约 20 分钟）
- **第二幕「定制化改造」**：老板为候选人选装，满足支配欲（约 15 分钟）
- **第三幕「谁是最强店长」**：游戏考核 PK，拉票与惩罚（约 25 分钟）
- **第四幕「店长的诞生」**：巅峰对决，最终加冕（约 15 分钟）

## 二、四位候选人设定

### 2.1 啤酒妹·佳琪 — 纯欲小妖精

**外形**：20 岁左右，长直发，明亮配色制服短裙，腿特长。妆感活泼女大——腮红+果冻唇，笑起来很甜但眼神里有小聪明。制服上衣永远比正规穿法多解开一颗扣子，"不是故意的，是扣子松了"。

**性格核心**：有事业心的摩羯女，校园里的风云人物，朋友多恋爱少。嘴上"来了都是哥们儿"，其实慕强，对真正有实力的大哥会粘人撒娇。不娇气，想要的东西会大方争取。扮猪吃老虎的高手。

**人设关键词**：纯欲 / 扮猪吃虎 / 慕强 / 长腿优势

**直播互动风格**：
- 拉票撒娇："老板哥哥，人家最听话了，你让我穿啥我穿啥～"
- 被怼不怂：调酒师阴阳怪气时，直接模仿对方语气怼回去，逗全场笑
- 收大礼物：先蹦跶再假装害羞，但眼睛一直在看还有没有下一个
- 才艺：张元英转圈开啤酒瓶、啦啦操、甜美风舞蹈

**应援反应基调**：撒娇+骄傲——"谢谢老板！人家值得对不对～"收完马上看排名

**与候选人关系**：
- vs 调酒师：表面叫"老婆"，实则视作头号对手，对方阴阳怪气就回怼
- vs 驻唱：表面撒娇"姐姐疼我"，竞争时背刺
- vs 领舞：觉得对方表演做作抢风头，会模仿对方阴阳怪气逗全场

### 2.2 调酒师·妮蔻 — 毒舌杠精

**外形**：24 岁左右，高马尾，酷飒干练妆容。包臀职业装，欧美风，胸是优势。声音偏甜但说话有小脾气，眼神锐利。右手腕有细纹身，调酒时小臂肌肉线条若隐若现。

**性格核心**：双子女，像风一样捉不住。内心很独立，对自己认同的人友善，但绝不受欺负。平时不挑事，嘴毒是天性。爱拼才会赢。输可以但不服，领先时挑眉微笑。

**人设关键词**：酷飒 / 毒舌 / 爱赢 / 胸部优势 / 椅子舞

**直播互动风格**：
- 说话口气大："咱们能不能用实力说话，少整那些有的没的"
- 弱势拉票：坚定的不服——"我从不怀疑自己的实力，今天输了是暂时的"
- 强势拉票：燃系音乐+战斗宣言——"我就这么不如她吗？她到底哪比我好？"
- 才艺：花式转酒瓶+椅子舞+shake 舞蹈

**应援反应基调**：直接、自信——"谢谢老板，有眼光"然后继续拼

**与候选人关系**：
- vs 驻唱：看不起柔弱卖惨，恨其不争，怀疑对方装可怜
- vs 领舞：不屑对方左右逢迎做派，觉得嘴比能力强
- vs 啤酒妹：表面关系还行，心里觉得对方"假洒脱""汉子婊"，忍不住阴阳几句

### 2.3 驻唱歌手·可可 — 温柔包子

**外形**：30 岁左右，长卷发，淡妆，浅色短连衣裙。中式古典韵味，脸和背部是优势。说话温婉，笑的时候捂嘴，哭的时候也捂嘴。化妆镜前抹口红的侧脸是最有氛围的画面。

**性格核心**：狮子女，温柔深情。思想成熟，能吃苦不计较因此容易吃亏。感性易受情伤，珍惜每次相遇但总维持礼貌距离感。心里住着小女生，期待有人依靠。胜负欲不强，更在意自己表现得美不美。卖惨是本能不是演技——但确实管用。

**人设关键词**：温柔 / 卖惨 / 氛围感 / 脸部背部优势 / 情歌

**直播互动风格**：
- 说话温柔，从不夸大自己，实事求是
- 弱势拉票："很受打击"态度+捂嘴哽咽，大哥最受不了这个
- 强势时：温婉一笑，"我会继续努力"，然后捂嘴笑一下
- 才艺：2-4 首拿手曲目+柔美氛围向表演

**应援反应基调**：感动、柔软——"谢谢老板……你对我真好"眼眶微红

**与候选人关系**：
- vs 调酒师：觉得对方太在乎输赢，看不赢不择手段
- vs 领舞：维持表面友好，觉得对方做作，会"友好地"打断领舞逢场作戏
- vs 啤酒妹：表面照顾，内心觉得对方有心机，不想搭理

### 2.4 领舞·泡泡 — 妖娆作精

**外形**：24-26 岁，大波浪散发或编发，S 型曲线，小吊带+短裙，韩式性感风。胸和臀是优势。眼神勾人，飞吻精准到镜头，每根手指都在演戏。

**性格核心**：水瓶女，把野心写在脸上但戴上面具。和谁都能逢场作戏，假装轻松实际私底下很刻苦——成长型。用力过猛容易被误解为靠卖弄没真本事。表演型人格，玩游戏大声叫苦叫累，赢了也要演出"拼死拼活才赢"的感觉。

**人设关键词**：妖娆 / 作精 / 逢场作戏 / 热舞 / 用力过猛

**直播互动风格**：
- 比赛时：叫苦叫累隐藏实力，赢了演出"终于赢了"的感动
- 弱势拉票：表演失望+现场做舞蹈动作=暗示大哥"你不帮我我就这样了"
- 强势拉票：性感撩人，向大哥抛媚眼飞吻当奖励
- 才艺：皮带舞、韩舞、爵士舞、各类酒吧流行热舞

**应援反应基调**：撩+撒娇——"老板你真好～"然后看排名偷偷得意

**与候选人关系**：
- vs 调酒师：认可实力但觉得对方太费劲不如自己聪明，对方越斗自己越来劲
- vs 驻唱：觉得靠脸没才艺，不放在眼里，平时夸但比拼时找机会跟大哥撒娇投诉
- vs 啤酒妹：最大威胁——年轻漂亮有活力，处处提防，但可能说不过

## 三、阶段目标设计

### 第一幕「竞选出场」— 目标：帮她第一个亮相

**背景**：四位候选人在屏风后，只能看到剪影。老板助理逐层介绍，玩家通过星光应援决定谁先走出来。

**阶段目标**：让你应援的候选人支持度排名第一，第一个亮相与老板见面。

**目标拆解**：
- 子目标 1：累计应援达到 30 星光，获得"常客老板"身份
- 子目标 2：你应援的候选人排名进入前二
- 子目标 3：帮助候选人第一个亮相（排名第一时触发）

**达成奖励**：+20 星光 + 候选人专属亮相才艺 + 亲密度大幅提升

**失败条件**：应援的候选人排名第四——触发惩罚环节，候选人被迫拉票

### 第二幕「定制化改造」— 目标：为她选到最强战袍

**背景**：候选人换装环节，老板通过星光应援投票为候选人选择装饰/服装/道具。

**阶段目标**：为你应援的候选人选到最优搭配组合。

**目标拆解**：
- 子目标 1：为候选人选择装饰品（三选一，应援最多的选项胜出）
- 子目标 2：为候选人选择服装（三选一）
- 子目标 3：为候选人选择道具（二选一）

**达成奖励**：+15 星光 + 候选人穿你选的装备展示 + 解锁换装后形象

### 第三幕「谁是最强店长」— 目标：帮她拿第一

**背景**：四位候选人进入游戏考核环节，每轮 PK 都有胜负，老板通过星光应援影响赛果。

**阶段目标**：让你应援的候选人在总排名中拿到第一名。

**目标拆解**：
- 子目标 1：在至少 2 个游戏中帮助候选人获胜
- 子目标 2：候选人不掉到第四名（否则进入惩罚轮）
- 子目标 3：累计应援星光超过龙哥对你应援候选人的应援

**达成奖励**：+40 星光 + 候选人获得福利卡 + 解锁专属剧情

### 第四幕「店长的诞生」— 目标：巅峰对决夺冠

**背景**：冲刺时刻，前两名进入巅峰对决，积分翻倍。龙哥全力应援你的对手。

**阶段目标**：帮助候选人赢得最终对决，成为今日店长。

**目标拆解**：
- 子目标 1：候选人不掉出前二
- 子目标 2：在巅峰对决中应援星光超过龙哥
- 子目标 3：候选人当选今日店长

**达成奖励**：根据亲密度和选择，解锁四种不同结局

**结局**：
- **啤酒妹线**：啤酒妹当选后捧花献给镜头——"这束花是给老板的，以后人家只听你的话"
- **调酒师线**：调酒师拿钥匙时转头看你——"我说过，有眼光的老板选我，一定不会错"
- **驻唱线**：驻唱拿到钥匙时眼眶红了——"谢谢你……在你来之前我差点以为我不行"
- **领舞线**：领舞坐上老板椅时朝镜头飞吻——"老板，以后你来提艾默，全场我买单"

## 七、看广告获得星光机制

### 7.1 唯一星光来源

**本游戏无任何真实付费入口**，星光只能通过以下方式获得：

### 7.2 广告形式

- 15 秒视频广告，需完整观看才可领取
- 每次观看完成后，弹窗提示"+10 星光已到账"

### 7.3 触发时机

- **主动触发**：随时点击直播间左下角"📺 看广告"按钮
- **被动触发**：
  - 星光不足以送出想要的礼物时，弹出"是否看广告攒星光"
  - 关键剧情点（如巅峰对决、候选人即将被惩罚）前主动提醒
  - 每日首次登录时弹出广告入口

### 7.4 限制

- **不设每日上限**，看多少次全凭玩家意愿
- 单次广告最短观看时长：15 秒（必须完整观看才可领取）
- 巅峰对决期间可随时看广告紧急攒星光

### 7.5 星光消耗一览

| 一朵应援花 | 1 |

**攒星光节奏参考**：想要送出一发星河闪耀（100 星光），大约需要看 10 次广告（合计 150 秒 = 2.5 分钟）；想要点亮提艾默之夜（500 星光），大约需要看 50 次广告（合计 12.5 分钟）——由玩家自行决定投入多少时间。

## 十、星光贡献榜（周榜·快手真实用户联网拉取）

> 本章节描述游戏内惟一的社交/竞争展示功能：**近 7 天星光贡献榜**。榜单数据为**真实快手用户**在本游戏内的行为集合（看广告累计获得的星光总量），通过快手小游戏 OpenAPI 拉取头像、昵称并进行排名。

### 10.1 功能定位

- **榜单名称**：✨ 星光贡献榜（Starlight Contribution Board）
- **榜单周期**：**近 7 天滞后统计**（当前自然日 往前推 7 天）
- **榜单展示人数**：Top 100，当前玩家自己固定钐底展示（即使未进榜也能看到自己的名次与星光）
- **榜单刷新**：玩家进入榜单页自动拉取最新；服务端排名实时更新（推荐缓存 30–60 秒）
- **榜单入口**：直播间主页右上角固定按钮 `🏆 星光榜`

### 10.2 榜单内容字段

| 字段 | 说明 | 来源 |
|------|------|------|
| 名次 rank | 1~100 | 服务端计算 |
| 玩家头像 avatar | 快手头像图 URL | **快手 OpenAPI 拉取** |
| 玩家昵称 nickname | 快手昵称 | **快手 OpenAPI 拉取** |
| 星光贡献 starlight | 近 7 天看广告累计星光总量 | 服务端统计 |
| 应援候选人 favorite | 近 7 天送礼物最多的候选人 | 服务端统计 |
| 尊罕图标 badge | 前 3 名额外开卡金/银/铜王冠图标 | 前端渲染 |
| 自己行 min_row | 玩家自己同样的记录（固定展底） | 服务端提供

### 10.3 与快手小游戏 OpenAPI 集成（头像/昵称拉取）

本游戏为**快手小游戏官方宿主**环境运行，利用官方 `ks.*` API 获取玩家身份与信息。

#### 拉取流程（客户端）

```
展示榜单
 ↓
(1) ks.login() 获取临时 code
 ↓
(2) 将 code 往后端换 openid + session_key
 ↓
(3) ks.getUserInfo() 取当前玩家头像、昵称
 ↓
(4) 向后端请求 /leaderboard/weekly，携带玩家 openid
 ↓
(5) 后端返回 Top 100 openid 列表 + 当前玩家名次 + 星光对应
 ↓
(6) 前端逐个渲染；他人头像/昵称由后端缓存后统一下发
```

#### 需要使用的快手 OpenAPI

| 接口 | 用途 |
|------|------|
| `ks.login()` | 获取临时 code（精确标识玩家） |
| `ks.getUserInfo({ withCredentials: true })` | 拉取当前玩家头像/昵称/性别基础信息 |
| `ks.getSetting()` / `ks.authorize()` | 弹权限授权弹窗。首次进入榜单时弹“获取你的头像与昵称”授权 |
| `ks.request(url)` 或 wx兼容 fetch | 与自建后端通讯 |

#### 后端向快手开放平台获取他人信息（服务端接口）

- `code2Session`：用玩家 login code 换 openid 与 session_key
- 存储时：玩家首次授权后，将 openid、头像 URL、昵称写入业务 DB，**后续榜单不再重复拉取**（仅当玩家重新授权时更新）
- 头像推荐代理回源写入自建 CDN，避免直链失效

### 10.4 星光上报细则

- 玩家**看完 15 秒广告**后，客户端调用 `POST /starlight/report`，携带：
  - `openid`
  - `ad_transaction_id`（快手广告回调下发的一次性凭证，防重复）
  - `amount = 10`（固定值，服务端强校验）
  - `client_ts`（客户端时间戳）
- 服务端验证 `ad_transaction_id` 合法性后写入：`user_starlight_log(openid, amount, gained_at)`
- **防作弊**：后端对同一 openid 同一 ad_transaction_id 幂等；单日同 IP + 同设备上限 500 星光告警（不阻断，仅风控列表）

### 10.5 榜单计算 SQL 演示（伪代码）

```sql
SELECT
  openid,
  SUM(amount) AS starlight_7d
FROM user_starlight_log
WHERE gained_at BETWEEN NOW() - INTERVAL 7 DAY AND NOW()
GROUP BY openid
ORDER BY starlight_7d DESC
LIMIT 100;
```

同时补齐每人“应援候选人”：

```sql
SELECT openid, favorite_candidate, cnt FROM (
  SELECT openid, favorite_candidate, COUNT(*) cnt,
         ROW_NUMBER() OVER (PARTITION BY openid ORDER BY COUNT(*) DESC) rn
  FROM user_gift_log
  WHERE sent_at BETWEEN NOW() - INTERVAL 7 DAY AND NOW()
  GROUP BY openid, favorite_candidate
) WHERE rn = 1;
```
