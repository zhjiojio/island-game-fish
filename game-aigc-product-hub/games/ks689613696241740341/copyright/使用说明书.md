# 豆了个豆小游戏软件 V1.0 · 使用说明书

## 一、软件概述

豆了个豆是一款运行在移动终端的休闲益智类拼图消除游戏。玩家通过调度带颜色的车辆，将屏幕上同色的圆形颗粒逐批清除，直至完成整幅图案。软件采用竖屏显示，全程触控操作。

运行环境：Android 8.0 及以上或 iOS 12.0 及以上，需安装快手客户端。

## 二、启动与主界面

启动软件后进入加载页，加载完成即进入第一关对局界面。软件不设独立主菜单页，关卡进度自动读取本地存档，从上次未通过的关卡继续。

【❗需补图 1】加载页截图。截图内容需包含：页面中央的加载进度提示，以及页面底部的版本号标识。

对局界面自上而下分为四个区域：

顶部为关卡信息栏，显示当前关卡序号，左上角为齿轮图标（暂停入口），右上角为道具栏。

中部为图案区，显示由彩色圆形颗粒拼合的图案，颗粒之间存在上下层遮挡关系。图案背后为角色立绘，随着颗粒被清除逐步显现。

图案区下方为停靠位区域，共六个位置。其中五个可直接使用，第六个需通过观看激励视频广告解锁。

底部为候选车辆队列，横向排列若干辆车，每辆车显示自身颜色与可装载的颗粒数量。

## 三、核心操作

### 3.1 选车与停靠

点击底部候选队列中的车辆，将其拖入空闲的停靠位。车辆入位时以倒车方式驶入。

车辆停稳后，图案区中与该车颜色相同、且当前未被上层颗粒遮挡的颗粒会自动排队向车辆走去，依次进入车内。

【❗需补图 3】车辆停靠与颗粒行走过程截图。截图内容需包含：至少一辆已停入停靠位的车辆，以及正在向该车行走的同色颗粒队列。

### 3.2 装满与驶离

当车内颗粒数量达到该车标注的载客数量时，车辆自动驶离停靠位，该位置随即空出，可停入下一辆车。

### 3.3 遮挡规则

被上层颗粒压住的颗粒无法被取走。玩家需要先清除外层颗粒，才能取到内层颗粒。这构成了游戏的顺序判断要求。

### 3.4 失败判定

当六个停靠位全部被车辆占据，且场上已无任何颗粒能够进入这些车辆时，本局判定失败，界面弹出失败提示。

## 四、道具功能

对局界面右上角道具栏提供四类道具，点击后弹出对应确认弹窗：

| 道具 | 作用 |
|---|---|
| 升级 | 提升指定车辆的载客容量 |
| 加速 | 临时提高颗粒行走速度 |
| 清车 | 移除一辆已停靠但无法装满的车辆，解开停靠位死锁 |
| 刷新 | 重新排列候选车辆队列 |

## 五、复活功能

当对局进入无解状态时，界面弹出复活提示弹窗。玩家可选择观看激励视频广告，广告播放完毕后获得一次继续对局的机会。

【❗需补图 6】复活提示弹窗截图。截图内容需包含：复活提示文字，以及观看广告的入口按钮。

## 六、暂停浮层

点击对局界面左上角齿轮图标，唤起暂停浮层。浮层弹出时游戏暂停，背景画面冻结。

浮层内容包含：

上半部分为三项设置开关，分别为声音、震动、音乐。点击开关可切换开启或关闭状态，设置结果保存至本地存储。

下半部分为四个操作按钮：

| 按钮 | 作用 |
|---|---|
| 主页 | 当前版本尚未开放，点击后提示暂未上线 |
| 重新开始 | 从第一关重新开始游戏 |
| 跳过 | 需观看激励视频广告，播放完毕后直接进入下一关。按钮右上角带有视频标识角标 |
| 继续游戏 | 关闭浮层，返回当前对局 |

浮层右上角设有关闭按钮，底部显示存档提示文字。

## 七、通关与展示环节

完成一关后进入通关界面，界面提供进入下一关的入口。

通关界面另设角色展示入口，点击后加载并播放该角色的动画视频。视频播放期间游戏内所有音频自动静音，播放结束后返回通关界面。

## 八、关卡与难度

软件内关卡由程序生成，逐关推进难度。随关卡序号上升，图案颗粒总数增加、颜色种类增多、单辆车载客容量下降、遮挡层数加深、干扰车辆比例提高。

每关生成时会经过可解性校验，确认存在完整通关路径后才投入使用，不会出现无解关卡。

第一关为教学关，颜色数量与车辆容量均较为宽松，用于让玩家熟悉基本操作。

## 九、数据存储

以下数据保存在设备本地存储中，卸载软件后清除：

- 声音、震动、音乐三项设置开关状态
- 当前关卡进度
