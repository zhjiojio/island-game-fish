# 龙凤劫：我的战神保镖｜互动短剧

一款手机竖屏优先的多结局互动网页游戏。玩家代入苏念卿，在保护契约、龙芯阴谋、发布会袭击和婚礼危机中平衡信任、证据与公司控制权。

## 玩法

- 8 个短剧视频片段与 12 张剧情静帧；
- 至少 4 个会改变后续状态的决策；
- “并肩破局”“王座独行”“未完之劫”三个可达结局；
- 本地保存进度、选择轨迹和结局收藏；
- 视频失败时可切换到海报和剧情摘要继续游玩。

## 本地运行

```bash
npm install
npm run dev
```

## 验证

```bash
npm test
npm run build
npm run preview
```

测试覆盖剧情状态变化、分支断链、结局可达性、进度恢复、锁定选择和完整真结局路径。

## 技术

React、TypeScript、Vite、Vitest、Testing Library。所有媒体通过 Vite 构建图生成带 hash 的部署资源，原始长视频不在本仓库中。

## 媒体说明

仓库中的短视频和静帧只服务于本互动改编演示，请勿脱离项目另行分发。
