# 《龙凤劫：我的战神保镖》互动游戏设计规格

## 目标

把 48 分 25 秒竖屏短剧改编为一款手机竖屏优先、桌面可玩的 8–12 分钟互动网页游戏。玩家代入苏念卿，在保护契约、龙芯阴谋、发布会袭击和婚礼危机中改写命运。首版以可见选择后果、多周目价值和完整公开部署为成功标准。

## 设计原则

1. 选择必须改变后续状态、可见反馈或结局，不设置无后果的装饰按钮。
2. 原片视频是叙事舞台，界面只在决策、状态变化和章节转换时出现。
3. 允许少量重剪原作顺序，以缩短“选择—反馈”的距离，但保持“雇佣—调查—发布会—婚礼—幕后钩子”的主线可辨认。
4. 不擅自补全证据不足的人名和角色关系；必要对白使用剧情摘要而非伪装成原片台词。

## 玩家视角与核心体验

玩家主要代入苏念卿。黑衣保镖的姓名与战神身份作为逐步揭开的悬念。核心体验采用“三幕蝴蝶效应”：早期对信任、真相和公司权力的取舍，在终章组合成不同结局。

## 故事结构

### 第一幕：契约与试探

- 保护契约：接受贴身保护，或坚持自主处置危机。
- 玉佩旧事：追问二十年前的联系，或暂时保留距离。
- 主要影响：信任状态，以及后续保镖是否主动公开信息。

### 第二幕：项目与真相

- 实验室阴谋：留下取证，或优先守住龙芯项目窗口。
- 发布会袭击：维持直播并承担风险，或立即疏散保护现场。
- 主要影响：证据、公司控制权、公开声誉和安全代价。

### 第三幕：婚礼与终局

幕后黑客在婚礼前发动系统攻击。终章不再使用单一“最后一选”覆盖前序行为，而是综合信任、证据和公司控制权三项状态。

至少实现三个可达结局：

- 真结局“并肩破局”：拥有足够信任与证据，公开战神身份并击破幕后计划。
- 守业结局“王座独行”：守住龙芯和公司控制权，但因长期不信任失去亲密关系。
- 劫后结局“未完之劫”：证据或控制权不足，只解决眼前危机，幕后威胁仍在。

实现时允许增加一个短失败回路用于立即重试，但不得以此替代以上三个正式结局。

## 状态模型与数据流

剧情由独立 story graph 驱动。每个节点包含媒体、对白摘要、选择或结局；每个选择包含目标节点和状态变化。状态至少包括：

- `trust`：苏念卿与保镖之间的信任。
- `evidence`：实验室事故和幕后势力的证据完整度。
- `control`：苏念卿对龙芯项目与公司的控制权。
- `history`：本轮已做选择，用于终章回放与结局解释。

数据流为：加载剧情图 → 播放节点媒体 → 展示选择 → 应用状态变化 → 写入本地进度 → 跳转目标节点 → 计算并展示结局。剧情引擎不得把具体节点判断硬编码进播放器组件。

## 界面与反馈

- 手机竖屏优先，原片画面占据主要视觉区域；桌面端居中呈现竖屏舞台。
- 顶部仅保留作品名、章节和必要的状态提示。
- 决策时在底部出现“命运岔路”选择卡，选择后立即隐藏。
- 选择反馈分三层：播放不同结果片段；显示状态变化；终章回放关键选择并解释组合后果。
- 隐藏具体结局公式，只展示状态的方向变化，保留探索感。
- 提供对白摘要、静音提示、章节续玩、本轮命运轨迹和结局收藏。

视觉方向采用深蓝黑、暖金和低饱和红，表达都市权力、龙凤信物与危机感；不使用通用霓虹赛博风覆盖原片气质。

## 技术架构

- React + Vite 单页静态应用。
- 剧情图、结局条件和媒体映射使用可校验的数据文件。
- 播放器、选择面板、状态引擎、进度存储、结局收藏分别保持清晰边界。
- 使用浏览器本地存储保存当前节点、状态、选择历史和已解锁结局。
- 不引入账号、后端、排行榜、支付或联网 AI 功能。

## 媒体策略

- 原始 126.4 MiB 视频仅保留绝对路径引用，不进入部署包。
- 从源视频切取剧情必需的 10–30 秒片段，并为每个关键节点准备静帧。
- 单个可部署媒体资源不得超过 25 MB。
- 媒体通过 Vite 构建图引用，不依赖未经校验的根路径字符串。
- 资源清单必须覆盖故事图引用的全部视频和图片。

## 故障处理

- 视频加载失败：显示对应静帧与对白摘要，提供重试和继续选项。
- 进度损坏或版本不兼容：保留已解锁结局，安全回到当前章节入口。
- 非法或缺失剧情节点：记录错误并回到最近有效章节，不显示空白页。
- 自动播放被浏览器阻止：显示明确的“点击继续”入口。
- 部署资源返回兜底 HTML 或错误内容类型：视为部署失败，不发布完成声明。

## 测试与验收

自动验收至少包含：

1. story graph 结构校验、目标节点存在性和所有正式结局可达性。
2. 至少四个有意义的选择节点和三个正式结局。
3. 状态变化、进度恢复与结局条件的单元测试。
4. 资源清单路径、格式、大小和“源视频未误入包”检查。
5. `npm run test` 与 `npm run build` 成功。
6. 手机竖屏和桌面尺寸下的关键路径浏览器验证。
7. 公网首页返回 HTTP 200；JS、MP4 和图片均返回正确内容类型，缺失媒体不会变成兜底 HTML。

## 部署

构建产物部署为独立的公开静态站点，首选当前已授权 GitHub 账号下的 GitHub Pages。部署动作只发布本游戏的构建产物与必要媒体，不公开源视频、调查帧全集或工作流文档。最终链接必须经过部署验证阶段后才可交付。

## 明确不做

- 不完整复刻 48 分钟线性短剧。
- 不把选择做成不影响状态或结局的装饰。
- 不补写长篇原创对白掩盖字幕证据不足。
- 不加入账号、服务端、排行榜、付费、广告或多人系统。
- 不承诺续作内容，只保留幕后黑客作为开放钩子。
