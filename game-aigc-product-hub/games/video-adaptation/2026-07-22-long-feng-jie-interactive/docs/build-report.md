# 《龙凤劫》互动网页游戏构建报告

## 构建结论

本地 Web 构建门控通过。游戏使用 React 19、TypeScript、Vite 8 和 Vitest，生产包包含 8 个短视频、12 张静帧、类型化故事图、纯状态引擎、版本化本地存储和三个结局页。

## 执行命令与结果

| 命令 | 结果 |
|---|---|
| `npm --prefix package test` | 通过；4 个测试文件、12 项测试 |
| `npm --prefix package run build` | 通过；43 个模块转换，`dist/` 生成成功 |
| `python3 ../../../skills/agw-video-adaptation/scripts/check_assets.py docs/asset-manifest.json` | 通过；`ok: true`，无资源错误 |
| Playwright + 本机 Chrome 三路径脚本 | 通过；三个正式结局均在真实浏览器中到达 |

## 测试覆盖

- 剧情引擎：状态变化不修改旧状态、flag 去重、锁定选择可见、断链检测、合法结局可达性。
- 生产故事：`storyData.ts` 无结构错误，三个承诺结局全部可达。
- 进度存储：有效恢复、损坏 JSON 回退、版本不兼容回退、重开保留结局收藏。
- 玩家界面：完整信任路线、累积条件锁定、视频失败时海报/摘要兜底。
- 浏览器路径：
  - 信任路线 → `并肩破局`；
  - 控制路线 → `王座独行`；
  - 保全路线 → `未完之劫`。

## 构建产物尺寸

- `package/dist/`：约 9.7 MiB。
- 源媒体目录：约 9.4 MiB。
- 最大文件：`jade-trust` 视频，1,490,763 bytes。
- JS：约 207.29 kB，gzip 后约 66.49 kB。
- CSS：约 7.61 kB，gzip 后约 2.50 kB。
- 所有视频和图片均由 Vite 生成带 hash 的构建引用。

## 媒体与交互说明

- 原始 126.4 MiB 视频未进入 `package/` 或 `dist/`。
- 非结局视频节点提供“跳过片段，进入抉择”；播放失败时显示对应海报、剧情摘要、重试和继续操作。
- 本地存储保存当前节点、三项状态、flag、选择历史和已解锁结局。
- 选择结算会显示“命运已改写”，终章回放本轮选择历史。

## 已知限制

- 源视频分辨率为 206×360；大屏展示采用竖屏居中，不进行虚假高清放大。
- 缺少完整逐字稿；界面文字是基于可见字幕和场景证据的剧情摘要，不伪装成原片逐字对白。
- 当前报告仅证明本地测试、生产构建和真实浏览器路径通过；公开 URL 仍需进入 `deploy-verifier` 阶段验证。
