# UI · 我的温柔未婚妻 · Flash 代表段落

## 设计域
- 竖屏 9:16 · 720×1280 基准 · rem 缩放
- 安全区：顶部 96px（状态栏 + 章节指示），底部 200px（选择栏），左右 32px

## 基础 UI

### 色彩（温柔邻家风 · 暖调）
- 主色 primary  #FF9BAA（樱粉）
- 强调 accent   #F5D1A6（黄昏米金）
- 底材 paper    #FFF6EE（米白纸）
- 文本 text     #3B2A24（深栗）
- 副文 muted    #8A6E60（棕灰）
- 关系条 warm   linear-gradient(90deg, #FFD6DF 0%, #FF7A93 100%)

### 字体
- 标题：'Ma Shan Zheng', '楷体', serif · 24–36px
- 正文：'Noto Sans SC', 'PingFang SC', sans-serif · 16–20px
- 数值：'DIN Alternate', sans-serif · 14px

### L3 拟物层（关键组件五层）
1. **对话气泡（她的台词框）**
   - 底材：#FFF6EE 米白纸 + 极细米黄纸纹（噪点 3%）
   - 阴影：0 8px 24px rgba(140, 90, 60, 0.18)
   - 高光：内左上 1px #FFFFFF 30%
   - 描边：1px #F1D9C4
   - 装饰：左上角 12×12 樱花小图形（SVG）· 尾巴指向立绘
2. **选择按钮（3 选项卡）**
   - A（真心）：底材 #FFEDF1 · 描边 #FF9BAA · 内心图标 ♥
   - B（打岔）：底材 #FFF6DE · 描边 #F5D1A6 · 内心图标 ★
   - C（冷漠）：底材 #EFEBE6 · 描边 #B8A798 · 内心图标 ○
   - 全部：圆角 16 · 阴影 0 4px 12px rgba(0,0,0,.08) · 点击态 scale .96 · 高光顶部渐变
3. **好感度条（顶部左侧）**
   - 心形容器 + 数字（0–200） + 渐变填充
   - 变化时 +N 浮字动画 300ms · 上飘 24px + 淡出
4. **章节/节点指示（顶部右侧）**
   - 小圆点 10 个（F1–F10）· 已过深樱粉 · 当前发光脉冲
5. **广告卡点 UI**
   - 中央金色徽章 "📺 观看广告解锁 CG" + 底部 A/B/C 选项
   - 广告结束后 CG 立绘 fade-in 1s + 提示"已解锁"

## 剧情专属 UI

- **f1 玄关初见**：暖色胶片颗粒滤镜（vignette）+ 木门缝光带（右上→左下）
- **f5 童年录音带**：磁带 icon 旋转 + 音波线（正弦上下 4px）+ 老照片黄色 tint
- **f6 广告卡点 A**：中心徽章 + 观看后 CG 立绘弹出（粉色棉睡衣）
- **f10 阳台夜风**：深蓝夜幕背景 + 温牛奶蒸汽微动 + 星光 3 颗慢闪
- **结局仪式**：全屏黑 → 立绘 fade-in → 标题楷书从上落下 → BGM 变奏 → "重新开始"按钮

## 组件状态
- Idle / Hover / Pressed / Disabled / Loading 全状态设计
- 音频静音按钮：右上 40×40 · 有音 🔊 / 静音 🔇
- 重玩：结局页中央大按钮 "回到开始"
