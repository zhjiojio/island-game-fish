# 分支拓扑

每集采用“核心视频 → 四选一 → 四条独立后果视频”的骨架。四个选项必须直接进入四个不同视频节点，静帧 callback 不得代替分支；每条路径先兑现可见后果，到下一个决策或结局边界时，最多只允许 2/4 选项汇到同一目标，禁止四路立即汇流。全剧 11 个 choice 中仅第 9、10 集共 2 个 choice 使用有限汇流，其余选择通往不同的下一决策或结局。按每条可达路径计算，相邻决策通常间隔 2–3 条视频；全剧控制为 55 条核心视频。

首集特殊重排：露台分手 → 第一条视频后立即四选一 → 四种可见后果；背叛、坠落与救援压入开场钩子。正式、反转、荒诞、隐藏结局分散在第 1–11 集的不同选择上，不设统一末尾结局路由。

条件分支按携带 flag 的真实路径回放；每个前序 flag 都能在到达对应 choice 的同一路径上获得。
