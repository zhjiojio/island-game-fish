# 孤岛烤鱼店 — 首日原型

## 当前目标

验证首日闭环：七步钓鱼、20 秒接椰子、分步动手建店、生火与翻面制作、交付随机订单，以及二十分钟解锁的永久离线采集。

## 明确规则

- 海鱼只用于烤鱼，椰子只用于椰子汁。
- 钓鱼按选点、观察气泡、选饵、抛竿、等待咬钩、提竿、拉锯战七步进行；绿色 40～70 力度落入气泡中心，过早提竿可继续等待，过晚可广告复活。
- 拉锯战左侧松手放线、绿色按住收线、右侧强收增加张力，超红线断线；进度满后显示鱼种与重量。
- 使用小海鱼、三文鱼、金枪鱼、金色传说；重量按二倍向上取整转成鱼肉，小鱼至少两份，每份烤鱼消耗一份。经用户确认，3kg 三文鱼为六份。
- 新用户钓到三条鱼后提示通过地图前往椰林，不再自动跳转。
- 椰林每轮二十秒，起手三颗椰子，后续每批至少三颗并持续掉落，每八秒提升数量与速度，椰子飞入筐内并最多实物展示十个。
- 钓鱼体力三十格，每次甩竿消耗一格，十五分钟恢复一格，广告补满不限次数。
- 采摘体力五格，每轮消耗一格，三十六分钟恢复一格，广告补满每天最多三次；两种体力均在凌晨重置。
- 椰林回合结束后显示采摘结算，由玩家选择搭建烤鱼店或再采一轮。
- 建店需要玩家依次完成砍树、锯木、搭店和篝火整理，首个烤鱼工具为一个篝火堆。
- 烤鱼需要选择鱼种、把握生火时机和主动翻面；完美火势加速 20%，完美翻面的「外焦里嫩」售价两倍，错过为「一般」。
- 椰子汁需要三次独立敲击，第三次锤击动画结束后再点击插上吸管；触摸和模拟鼠标不得重复计数，所有商品都不会因等待自动完成。
- 厨房、椰子汁区和送餐口分区，四种熟鱼各用固定餐盘，每盘最多画三条，超出后右上角小字显示实际数量。
- 普通椰子与金椰子分别入库，金椰子在背包显示金色边框；未接住的椰子有摔裂动画，离开保留已接库存。
- 最多两位顾客，订单只显示商品图和数量，完整交付前不会离开，交付后金币在顾客头顶上浮消失。
- 顾客鱼种概率与钓鱼一致；浅滩普通提竿只产小海鱼，完美提竿有机会获得三文鱼。
- 累计前台在线二十分钟可关闭弹窗并选择看一次广告永久解锁离线采集；提前关闭广告不解锁，地图可再次进入。
- 离线每小时产出两份沙丁鱼肉和三个椰子，最多累计六小时；上线后可普通领取或看广告双倍领取，取消广告和重复点击不得入账。
- 金币、鱼肉份数、椰子、等级、建店、累计在线、永久解锁和待领取收益均持久化，兼容旧首日存档。
- 游戏和 H5 预览均为横屏十六比九。
- 当前只验证首日与离线采集，不包含夜晚、真实广告 SDK 配置和后续区域。

## 操作

- 钓鱼：依次选择浅滩和蚯蚓，按住并松开抛竿；等待浮标下沉后及时提竿，拉锯时绿色按住收线、其他区域松手放线。
- 椰林：点击任意椰树开始 20 秒回合，接住随机掉落的椰子，筐内显示本轮数量。
- 建店：按提示点击完成砍树、锯木、搭建和生火。
- 烤鱼店：根据窗口订单选择鱼种，点击完成生火时机判定，等待烤制后主动翻面；直接点击前台椰子开始制作并插吸管。
- 售卖：制作完成自动摆盘，商品备齐后点击对应顾客交付完整订单。
- 导航：底部地图切换区域，背包查看库存。

## 技术约束

- 快手小游戏单机运行，无网络行为。
- 使用 WebGL 1.0，无 DOM、CSS 或 Canvas 2D 游戏绘制。
- 界面文字使用苹方简体中文字帖，通过 WebGL 纹理绘制，不再使用手工像素字。
- 中文字图首次加载失败后会间隔自动重试，无需刷新即可恢复。
- 游戏代码位于 `package/gameplay/`，入口装配位于 `package/game.js`。
