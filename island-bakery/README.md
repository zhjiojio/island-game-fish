# 孤岛烤鱼店（小岛烘焙 island-bakery）

## 本地浏览器预览（推荐）

本目录下可玩包在 **`package/`**（含 `index.html`）。

```bash
cd /Users/zmj/Downloads/kwaigame/island-bakery
./start-dev.sh
```

默认 **http://127.0.0.1:8000/**（macOS 会尝试自动用默认浏览器打开）。

指定端口：

```bash
./start-dev.sh 8080
```

按 **Ctrl+C** 结束服务。

需要环境：**Python 3**（系统自带 `python3` 即可）。

## 快手小游戏开发工具

将 **`package/`** 目录导入「快手小游戏开发工具」即可真机/模拟器调试（与本地 HTTP 预览互补）。
