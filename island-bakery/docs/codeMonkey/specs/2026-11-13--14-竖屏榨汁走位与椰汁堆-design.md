# 竖屏榨汁接到圆木板和左侧空桌

## 背景

横屏兔子已经走到青椰子和榨汁器之间敲椰子，椰汁最多堆 3 个在成品桌上。竖屏仍把正在敲的椰子画在榨汁器上，成品椰汁一堆都不画。根因是竖屏槽位没有操作点，绘制又用「只在横屏」把同一套动作挡掉了。

## 调用链路

1. 店铺每帧按横竖屏读取烤鱼店槽位，画出烤架、兔子和成品
2. 开始榨椰子汁后，兔子应走到操作点，在那里敲开、插吸管
3. 敲满 3 下后，青椰图换成带吸管的椰汁图 ← 竖屏这一步仍锚在榨汁器上
4. 出餐后，椰汁数量大于等于 1 就堆到成品桌空位，最多画 3 个 ← 竖屏被「只在横屏才画」直接跳过

## 根因分析

直接根因：竖屏槽位没有操作点；敲椰子时锚点写成榨汁器；椰汁堆和出餐飞行都写了「不是竖屏才画」。

根本原因：横屏补操作点时，竖屏被明确留在旧榨汁器锚点上，成品堆也没有单独的竖屏落点。两套画面的柜台位置不同，不能把横屏像素直接套到竖屏。

## 方案设计

不改横屏像素，不改点击热区和烤制阶段。只给竖屏补上同一个操作点和成品堆。

1. 竖屏槽位增加操作点，落在中层柜台、青椰子堆和榨汁器之间的圆木板上，坐标是相对画面宽高的比例
2. 兔子从原位置走到柜台前方地面，椰子画在圆木板上。敲的时候用青椰图，满 3 下换成带吸管的椰汁图，插吸管继续用这张图
3. 椰汁数量大于等于 1 时，堆在下层左侧空桌、四条鱼那一排的右侧空位，垂直堆叠，最多画 3 个；多于 3 个仍只画 3 个，旁边写数量
4. 出餐时，椰汁从圆木板飞到这张空桌，不再停在榨汁器上
5. [新增] 竖屏操作点、竖屏堆叠落点、兔子前走和出餐飞行不再被「只在横屏」挡住

## 预期效果

- 竖屏敲椰子和插吸管发生在中层圆木板上，兔子站在柜台前面
- 成品椰汁出现在下层左侧桌子的右侧空位，最多看见 3 个，更多时旁边有数量
- 椰汁不压在四条鱼的位置上，也不堆在榨汁器上
- 横屏兔子落点、成品堆位置和榨汁器坐标保持原样
