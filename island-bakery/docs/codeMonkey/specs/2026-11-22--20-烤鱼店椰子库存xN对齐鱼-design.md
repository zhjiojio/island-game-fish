# 烤鱼店椰子库存 ×N 对齐鱼（R0040）

## 背景

烤鱼店台前烤鱼成品有 `×N` 总数；椰子侧原料堆无数量字，成品椰汁堆要多于 3 杯才出 `×N`，和鱼不一致。

## 根因

- 原料椰子只画提示/堆图，未读 `ingredients.coconut` 画 `×N`。  
- `drawJuiceStack` 用 `count > 3` 才标总数，鱼盘是 `count > 1`。

## 方案

```
1. [新增] drawShopCoconutStockLabel：在 juiceNut/work 旁画 ×ingredients.coconut（>0）
2. [改] drawJuiceStack：×N 条件改为 count > 1，与 drawShopPlates 一致
3. 非皮肤兜底成品椰汁同样 >1 时标 ×N
```

## 预期

台面原料椰子可见 `×N`；成品椰汁与烤鱼一样多于 1 即显示总数。
