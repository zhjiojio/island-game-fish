# 钓鱼区：三长方形海面合一（R0002）

## 背景

R0001 验收未过：船区垫层、上带 swell、下带 crash 一眼三块长方形；下带底边方形截断右下角漏静底板；船区与上带重合处浪像自上而下。

## 根因

1. **三块矩形分别绘制**：`drawFishingFarSeaSwell` 大矩形 + `drawFishingNearShoreCrash` 大矩形 + `fishingBoatWaveStableRect` 第三块 → 必然看出三区。  
2. **下带 `seaBottom = beachTop`**：浪停在沙滩线以上，右下功能区旁露出静 seabase。  
3. **船区 stable 垫层**：单独矩形里拉伸 swell 的 UV，观感像竖直「自上而下」的浪——由第 1 点引入。

## 方案（推荐）

```
删掉：船区独立垫层矩形；上下两大块硬带。

改为：山脚 → 画布底（功能区下方）一条连续海面
  - 拆成多条细水平条（同一 surfPhase）
  - 上段 swell、下段 crash、中段双层交叉混色（不是直线硬切）
  - 左岸仍用 spans 内缩露栅栏/沙滩
  - 碎浪画在原沙滩视觉线附近
  - 全部 clip 在 0..width / 0..height，不画出游戏页

地图/背包/抛竿/体力 UI 仍后画，压在海面上（海在它们「下面」盖住静底板）。
船兔只跟 surf bob，不再铺第三块浪矩形。
```

## 预期

一整片连续海；无三块长方形；右下不再漏静底板；船周无竖直异向浪；不越出画布。

## 回滚

回退 `renderer.js` 海面绘制相关函数至 R0001。
