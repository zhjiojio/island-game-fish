# 横屏未解锁路牌弹窗 + 竖屏钓鱼顶栏槽位居中

## 背景

横屏地图上，森林 / 养殖 / 菜园 / 面包房 / 仓库，以及尚未建好的烤鱼店，点下去要么无反应、要么不该进场景；需要弹出共用结算底板，提示「暂未解锁」。同时竖屏钓鱼顶栏五个资源文字未落在 `ui-skin-fish-port` 槽内，需只改竖屏槽位居中。

## 调用链路

### 问题 1 · 横屏地图点击

1. 玩家在横屏地图点击  
2. `Input.press` 调 `MapZones.hitLandscape`（按矩形命中区域）  
3. 命中钓鱼 / 椰林 / 已建烤鱼店 / 离线 → 现有跳转 ← 保持不变  
4. 命中带锁路牌或未建烤鱼店 → 当前返回 `null`，无反馈 ← 问题点  
5. [新增] 返回 `locked` → 打开未解锁结算弹窗 → 点「知道了」关闭

### 问题 2 · 竖屏顶栏文字

1. 竖屏钓鱼场景绘制 HUD  
2. `drawHUD` → `drawHudMetric` 用 `hudSlotCenters` 竖屏 `cx` + `hudBarY/H` 算字心  
3. 当前竖屏 `cx` 仍按旧艺注比例，与现版 `ui-skin-fish-port` 五个空槽错位 ← 问题点  
4. [新增] 按皮肤实测改竖屏 `cx` 与竖屏槽内垂直居中；横屏槽位不动；艺术字「孤岛烤鱼店」不改

## 根因分析

### 直接根因

- 横屏 `hitLandscape` 只判定钓鱼 / 椰林 / 已建店 / 离线，带锁路牌无热区；未建烤鱼店命中 shop 矩形时直接忽略。  
- 竖屏 `hudSlotCenters` 为 `0.27/0.415/0.56/0.705/0.85`，与现皮肤槽内实测中心 `≈0.30/0.426/0.555/0.685/0.809` 不一致（尤其第 4、5 槽偏右）。

### 根本原因

地图交互与 HUD 叠字都依赖「皮肤锚点标定」，皮肤重制后热区 / 槽位表未同步更新。

## 方案设计

### 问题 1

**旧：**

```
点击地图 → hitLandscape
  → offline / fishing / coconut / shop(已建) → 跳转
  → 其它 → null（无反馈）
```

**新：**

```
点击地图 → hitLandscape
  → offline / fishing / coconut / shop(已建) → 跳转（不变）
  → [新增] 带锁五区 或 shop(未建) → "locked"
       → Game.mapLockedPrompt = true
       → 画结算壳：标题「暂未解锁」+ 短按钮「知道了」
       → 点「知道了」关闭
```

横屏热区（设计坐标 960×540，按 `ui-skin-map-land` 带锁路牌量取；与钓鱼 / 椰林 / 烤鱼店矩形不重叠；验收图 `docs/_debug-map-zones-locked-final.png`）：

| 区域 | x,y,w,h |
|------|---------|
| 森林 | 560,105,130×115 |
| 养殖 | 600,250,130×115 |
| 面包房 | 225,372,134×115 |
| 菜园 | 412,377,134×115 |
| 仓库 | 600,370,120×70 |
| 烤鱼店（未建） | 复用现有 shop 矩形，未建时返回 locked |

命中顺序：离线 → 钓鱼 → 椰林 → 烤鱼店（已建进店 / 未建 locked）→ 带锁五区。仓库与离线矩形有少量像素重叠时，离线优先，保证离线按钮行为不变。竖屏地图点击逻辑不改。

改动文件：`map-zones.js`、`game.js`、`renderer.js`、`input.js`。

### 问题 2

**旧：** 竖屏 `cx = 0.27/0.415/0.56/0.705/0.85`，垂直用共用 `hudBarY=10, hudBarH=44`。

**新：**

- 竖屏 `cx ≈ 0.299 / 0.426 / 0.555 / 0.685 / 0.809`（槽内水平中心）  
- 竖屏垂直：按槽内实测约 design y `19~46`，在 `drawHudMetric` 内对竖屏使用 `barY≈19, barH≈27`，字心落在槽内；横屏仍用原 `hudBarY/H`  
- 不改横屏 `cx`、不改左侧艺术字

改动文件：仅 `renderer.js` 的 `hudSlotCenters` 竖屏分支与 `drawHudMetric` 竖屏垂直参数。

## 预期效果

1. 横屏点森林 / 养殖 / 菜园 / 面包房 / 仓库 / 未建烤鱼店 → 弹出「暂未解锁」，点「知道了」关掉，不进场景。  
2. 横屏点钓鱼区、椰林区、已建烤鱼店、离线按钮 → 行为与现在完全一致。  
3. 竖屏钓鱼顶栏「第N天 / 金币 / 鱼肉 / 椰子 / 等级」各自落在对应空槽内水平垂直居中；横屏顶栏与「孤岛烤鱼店」不变。
