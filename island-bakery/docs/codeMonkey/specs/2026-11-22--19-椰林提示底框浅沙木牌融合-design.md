# 椰林提示底框浅沙木牌融合（R0036）

## 背景

椰林区玩法提示为了可读加了深棕半透明方块底框，叠在绿叶原画上像硬贴 UI，材质与场景突兀。

## 调用链路

1. `drawCoconut` 顶部提示 → `drawGuideTip(..., { backdrop: true })`
2. `drawGuideTip` 在画字前用单层 `rect(..., [0.12,0.09,0.06,0.62])` ← **问题点**
3. 字色仍为暖奶油金 + 流光（R0033），本轮不动

## 根因分析

- **直接根因**：底框只用深棕实心矩形，色相/明度与叶绿场景反差大且无过渡。
- **根本原因**：对比度方案只考虑「压暗保字可读」，未对齐游戏已有 cream/sand/wood/leaf 材质语言。

## 方案设计

```
旧: 单层深棕半透明方块
新: 三层浅沙木牌感
  1. 外扩叶绿半透明晕边（贴合叶底）
  2. 内层浅沙/奶油半透明底板（贴合 cream/sand）
  3. 细木色描边（贴合木牌 UI）
字色/流光/居中包围盒逻辑保持 R0033–R0035
```

- [改] 仅 `drawGuideTip` 的 `opts.backdrop` 绘制段
- 字色、描边、流光、调用点不变

## 预期效果

椰林提示底框融入绿叶与木牌画风，不再像硬贴黑条；奶油金字仍清晰可读。

## 回滚

恢复 backdrop 为单层 `[0.12, 0.09, 0.06, 0.62]` 矩形。

## 落地记录（2026-11-22）

用户确认推荐方案。已改 `drawGuideTip` backdrop 为叶绿晕边 + 沙色底板 + 细木描边；`renderer.js?v=136`；PdeMonster R0036。
