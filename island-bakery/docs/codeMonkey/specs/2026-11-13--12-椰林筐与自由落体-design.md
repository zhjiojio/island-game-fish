# 横屏椰林把两只空筐盖回树根，未点中的椰子改自由落体

## 背景

横屏椰林底板已经把沙滩上的两只椰子筐抹掉。掉下来的椰子仍在生成时写好筐的坐标，没点中也会沿直线飞进筐。

## 调用链路

1. 进入横屏椰林，先铺没有筐的底板
2. 画三棵椰子树
3. 再画大筐、小筐，盖住树干下端 ← 新增
4. 数量写在小筐中心；点中的椰子从当前位置滑进这个中心
5. 没点中的椰子只加快竖直速度，水平位置不动，落到地面后按原来的落地失败处理 ← 改掉飞向筐

## 方案设计

只改横屏椰林的画法和椰子下落。竖屏锚点、摇树热区、采摘倒计时和接椰子判定保持原样。

1. 大筐、小筐画在三棵树后面。大筐中心对齐中间树 (480, 436)，小筐中心对齐右边树 (695, 440)，筐沿压住树干下端
2. 接椰子的落点和数量字都用小筐中心。大筐只摆放
3. 生成椰子时不再写 fallToX / fallToY。下落时竖直速度每秒增加 240，横坐标不变。碰到地面后仍记为裂开并在半秒后消失
4. 只有点中的那颗，才沿现有滑入路径进小筐

## 预期效果

- 横屏能看到中间大筐和右边小筐，树干下端被筐挡住
- 没点到的椰子竖直落地，不再飞向筐
- 点到的椰子滑进小筐，小筐里的数字加一
- 竖屏、地图、钓鱼和摇树热区保持原样
