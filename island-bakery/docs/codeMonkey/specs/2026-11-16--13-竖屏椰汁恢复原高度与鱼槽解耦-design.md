# 竖屏椰汁恢复原高度，并与成品鱼槽解耦

## 背景

下移竖屏成品鱼锚点后，左侧椰子汁堆也一起变矮；原先高度合适，这次不应被改动。

## 调用链路

1. 画椰汁堆 → `drawJuiceStack` → `portJuiceStackPoint`
2. `portJuiceStackPoint` 用「最下一槽成品鱼」`last.x+0.10`、`last.y-0.08` ← **问题点：鱼槽 y 下移，椰汁被连带下移**
3. 旧鱼槽 golden `y: 0.855` → 椰汁脚底 `0.775`；新 golden `y: 0.950` → 椰汁脚底 `0.870`

## 根因分析

- **直接根因**：竖屏椰汁落点相对 `port.plates` 末槽计算，成品鱼整列下移后椰汁 y 从约 `0.775` 变成约 `0.870`。
- **根本原因**：椰汁与鱼槽共用相对偏移，一次只想改鱼却隐式改了椰汁。

## 方案设计

恢复改鱼前的竖屏椰汁绝对落点，并与鱼槽解耦。横屏仍可相对 `land.plates`。

旧（相对末槽，会被鱼槽拖走）：

1. `x: last.x + 0.10`，`y: last.y - 0.08`

新：

1. [新增] `ShopLayout.port.juiceStack: { x: 0.23, y: 0.775 }`（等于改鱼前 `0.13+0.10` / `0.855-0.08`）
2. [修改] `portJuiceStackPoint` 只读该固定槽，不再读 `plates`
3. [不变] 成品鱼新锚点、横屏椰汁相对逻辑

## 预期效果

- 竖屏椰汁回到改鱼前高度
- 以后再调成品鱼 y，不再带动椰汁
