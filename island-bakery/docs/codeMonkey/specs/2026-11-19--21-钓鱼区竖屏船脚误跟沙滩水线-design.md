# 竖屏船脚误跟沙滩水线导致船缺一半

> 状态：已实施（用户确认「修」）
> 轮次：R0010 补丁（同轮次，不新开号）
> 关联：`2026-11-18--22-钓鱼区第3批C1海域几何统一蒙版-design.md`

## 背景

竖屏钓鱼区兔子对应的船看起来缺一半。根因是 R0010 把船脚 Y 改成跟蒙版沙滩水线，竖屏水线在画面中部，船被拽离甲板槽。

## 调用链路

```
1. fishingBoatFoot()
2. 旧：竖屏/横屏都 shoreLineAtX ← 问题（竖屏不该跟沙滩线）
3. paintFishingBoatSprite / 兔子相对船脚偏移
```

## 根因

- 直接：竖屏也用了 `shoreLineAtX`，Y 从 920 被拉到约 758。
- 根本：竖屏是甲板视角，船槽是固定构图；横屏才是岸边看船。

## 方案

```
旧：有蒙版 → 一律贴水线
新：竖屏固定 y=920 甲板槽；仅横屏贴 shoreLineAtX  [改]
```

## 预期

竖屏船与兔子回到甲板位置，完整可见；横屏仍跟水线。
