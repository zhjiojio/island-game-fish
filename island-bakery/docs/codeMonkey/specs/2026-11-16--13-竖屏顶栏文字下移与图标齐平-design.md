# 竖屏顶栏文字下移与图标齐平

## 背景

Chrome 打开 localhost 竖屏时，钓鱼区 / 椰林区 / 烤鱼店顶栏「第N天 / 金币 / 鱼肉 / 椰子 / 等级」相对槽内圆形图标偏高；Cursor 小窗因缩放不易察觉。根因是叠字按墨盒几何居中，中文位图视觉重心略偏上，看起来飘在图标上方。

## 调用链路

1. 进入竖屏钓鱼 / 椰林 / 烤鱼店  
2. 画全屏皮肤底图（槽内图标已画在皮肤上）  
3. `drawHUD` → `drawHudMetric`（按竖屏槽位叠资源文字）  
4. 用 `hudBarYPort=19`、`hudBarHPort=27` 做槽内垂直居中 ← 几何中心≈32.5，视觉上字仍偏高  
5. [改] 把竖屏居中带整体下移约 3 设计像素，字心与图标齐平

## 根因分析

### 直接根因

`drawHudMetric`（画顶栏五项资源字）用 `textYInBox`（按字形外框在矩形里垂直居中）把字心放到 `19+27/2≈32.5`；皮肤图标中心约在 31～34，几何上接近，但中文位图视觉重心高于外框中心，Chrome 大图上字明显偏高。

### 根本原因

槽位参数只按墨盒几何标定，没有留「中文光学齐平」余量；三个竖屏皮肤共用同一套顶栏叠字。

## 方案设计

**旧：**

```
drawHudMetric
  → barY=19, barH=27
  → textYInBox → 字心 ≈ 32.5
```

**新：**

```
drawHudMetric
  → [改] barY=22, barH=27（居中带下移 3）
  → textYInBox → 字心 ≈ 35.5，与图标视觉齐平
```

- 只改 `renderer.js` 竖屏 `hudBarYPort`（19→22）及注释；横屏 `hudBarY/H`、水平 `cx` 不动  
- `index.html` 里 `renderer.js` 缓存版本号 +1，避免 Chrome 继续用旧脚本  
- 在 `drawHudMetric` 竖屏分支打一条调试日志（参数与算出的字 y），方便以后对照

不改皮肤图、不改字号、不改横屏。

## 预期效果

1. Chrome 竖屏钓鱼 / 椰林 / 烤鱼店：五项资源字与左侧圆形图标视觉垂直齐平  
2. 横屏顶栏不变  
3. 强刷 localhost 后即可验收；若仍略高/略低，再对 `hudBarYPort` 做 ±1 微调
