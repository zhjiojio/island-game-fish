# 真船切图残缺导致船体不完整

> 状态：已实施（用户确认「确认」后落地）
> 轮次：R0010 重新打开 → 补丁2（验收未过；脚点补丁保留，根因改为切图残缺）
> 关联：`2026-11-19--21-钓鱼区竖屏船脚误跟沙滩水线-design.md`（脚点补丁保留）

## 背景

竖屏船脚已回到甲板槽后，船体仍明显缺一块：用户标注红框=当前可见船体，绿框=应有完整范围（左右外延、底部更深）。对照资源后确认：**不是再挪脚点能修好，而是真船切图本身被裁坏了。**

## 调用链路

```
1. 资源 boat_fish_port.png / boat_fish_land.png
2. paintFishingBoatSprite → paintFootSprite(foot.h)
3. 画面上只出现切图里有的像素 ← 问题（切图底边/左边锯齿透明，船体残缺）
4. 脚点 y=920 仅决定摆放位置，补不齐缺失像素
```

## 根因分析

- **直接根因**：现行 `boat_fish_port.png`（962×467）底边/左边几乎全透明（底 5 行不透明占比约 0.9%），锯齿裁切，甲板以下舷侧与左侧弧线被切掉。横屏 `boat_fish_land.png` 同类残缺。
- **根本原因**：当初从一体皮抽真船时裁框过紧/蒙版不完整；上一补丁只修了「竖屏误跟沙滩水线」的位移，没有核对切图完整性，所以验收仍失败。

对照证据：

| 资源 | 尺寸 | 底边不透明占比 | 结论 |
|------|------|----------------|------|
| 现行 `boat_fish_port.png` | 962×467 | ~0.9% | 残缺 |
| 预览完整稿 `_boat_out_port.png` | 730×720 | ~100% | 可用完整源 |
| 一体皮 vs noboat 差分 | 730×631 | ~99% | 佐证完整船体范围 |
| 一体皮原构图船区（设计坐标） | 约 (9,604)–(352,900) | — | 目标摆放：脚约 (180,900)，高约 296 |

## 方案设计

```
旧：残缺切图 + 竖屏 h=height*0.24(≈230)、脚 (210,920)
新：
  1. 用完整真船切图替换 port/land 精灵（优先已有完整预览稿，必要时从一体皮重抽）[改·资源]
  2. 竖屏脚点/高度对齐原一体皮构图：约 x=180,y=900,h=296（横屏逻辑不变，仍可贴水线）[改·摆放]
  3. 兔甲板相对偏移若明显错位则微调 seat（仅必要时）[改·可选]
  4. 缓存版本号 +1，便于硬刷新吃到新图 [改]
```

不改：动态海着色器、蒙版几何、C7 UI 层、横屏贴水线策略。

## 预期效果

- 竖屏：船体左右外轮廓与底部甲板完整，接近绿框范围；兔子仍坐在甲板上。
- 横屏：船同样不再缺底/缺边；贴水线行为保持。
- 地图/背包仍由独立 UI 层绘制，可点。

## 影响与回滚

- 影响：仅真船精灵观感与竖屏摆放尺寸；可能需微调节兔子相对位置。
- 回滚：还原两张 `boat_fish_*.png` 与 `fishingBoatFoot` / seat 数值及缓存版本号。

## 验收

1. 硬刷新竖屏钓鱼区。
2. 船体底部与左右不再呈锯齿缺块，整体接近标注绿框。
3. 兔子仍在船内甲板；抛竿按钮可读。
4. 底栏地图/背包可点。
5. 横屏快速看一眼船也不缺底。
