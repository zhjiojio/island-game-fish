# 横屏烤鱼阶段提示字对齐空闲白加粗（R0022）

## 背景

横屏烤鱼店空闲提示「点击生鱼开始烤」是白色伪加粗；点生鱼后「生火 绿区点击」「烤制中」「翻面 绿区点击」等变成深墨色普通字，观感不一致。

## 调用链路

1. `drawShop` 横屏分支：空闲 → `textBold(..., 19, C.white)`  
2. 同位置阶段字 → `text(..., grillHintColorLand)`，皮肤层 `grillHintColorLand = C.ink` ← **问题点**  
3. 竖屏同源仍用 ink/`text`（本轮用户只提横屏，竖屏不动）

## 根因分析

- **直接根因**：阶段提示未复用空闲的 `textBold` + `C.white`，皮肤层走了 R0015 的墨色普通字。  
- **根本原因**：空闲后来改成白加粗可读，阶段字未同步同一套样式。

## 方案设计

```
旧: 阶段 text + grillHintColorLand（皮肤=ink）
新: 阶段 textBold + C.white，字号统一 19（与空闲一致）
```

- [改] 横屏 `stoke` / `cooking` / `flip` 三处提示  
- 文案内容不变；进度条不变  
- 竖屏本轮不改（用户只点名横屏）

## 预期效果

横屏从「点击生鱼开始烤」到生火/烤制/翻面，提示字体与颜色肉眼一致。

## 回滚

恢复为 `text` + `grillHintColorLand`。

请确认后按此实施（PdeMonster R0022）。
