# 钓鱼区海浪验收失败：根因重做

## 背景

上一轮「裁带/UV 微移」没有真正修好。验收仍见：山脚下静止深蓝条、右下沙滩静海、鱼只剩一条、浪假且不连贯。承认：在错误资源/错误 UV 映射上叠半透明层，属于表象适配，不是根治。

## 根因（有证据）

1. **山脚静海条**  
   seabase 里海水约从纹理高度 **21.5%**（y≈248/1152）开始；代码 `seaTop = height * 0.335`，动画从更下面才开始 → 山脚到动画起点之间整条深蓝是**未被动过的底板**。  
   另外用「整张 UI 皮肤」做 UV 偏移，会扫到顶栏文字 → 红框里出现幽灵字。

2. **沙滩静海**  
   静浅水**烤在 seabase 像素里**（右下偏青绿）。`coverBeachStaticWater` 又用错误 UV 盖回去，等于没删。

3. **鱼变一条**  
   环境鱼被 `pool` 过滤 + 过透 + 下带高透明浪盖住，小鱼几乎看不见。

4. **浪假、不连贯**  
   现用 sheet 是整幅风景挤成条，再裁 UV 硬拉；双帧交叉也遮不住「贴一张半透明风景条」的观感。

## 方案（根治）

```
约束：天空/远山只露底板静帧，绝不进动画层，也不删除。

1. [改资源] seabase / port-seabase：右下沙滩静浅水改成干沙（像素级删掉）
2. [改几何] seaTop = 山脚比例（横屏约 0.22，竖屏按 port 山脚标定），缓涌从山脚紧接开始
3. [删] 禁止对整张 UI 皮肤做 UV 缓涌（杜绝幽灵 UI）
4. [新资源] 两套透明底、纯海动画（无天空无山无沙滩）：
   - sea_swell_* ：远海缓涌 12 帧（深蓝微涌）
   - sea_crash_* ：近岸碎浪 12 帧（拍岸白沫）
   双帧交叉 + 周期 ~2.5s
5. [改层序] 底板 → 远海 swell（山脚起）→ 环境鱼（不按订单 pool 砍光，alpha 可见）→ 近岸 crash → 船兔同频
6. 近岸底边停在沙滩线；沙滩已无静海像素
```

### 改动文件

- `package/res/Image/ui/ui-skin-fish-*-seabase.png`（去沙滩静海）
- 新建 `sea_swell_*_sheet` / 重做 `sea_crash_*_sheet`（或替换现 shallow sheet）
- `package/gameplay/render/renderer.js`
- `package/index.html`

- 多条鱼在水下可见  
- 浪连续、像海不是贴图条
