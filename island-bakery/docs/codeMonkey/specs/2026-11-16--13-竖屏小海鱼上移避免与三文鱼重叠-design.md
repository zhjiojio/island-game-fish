# 竖屏小海鱼上移，避免与三文鱼重叠

## 背景

竖屏成品区小海鱼与三文鱼叠在一起；用户要求不重叠，且只改小海鱼的 y，其余槽位与椰汁不动。

## 调用链路

1. 有库存 → `drawShopPlates` 按 `port.plates` 脚底锚点画各鱼种
2. 成品高度约 48（约屏高 0.05）
3. ← **问题点**：`small.y = 0.800`、`salmon.y = 0.820`，步距仅 0.02，小于成品高度，必然重叠

## 根因分析

- **直接根因**：三文鱼上移到 `0.820` 后，与小海鱼 `0.800` 间距过近。
- **根本原因**：两槽未按成品高度预留步距（约 ≥0.05）。

## 方案设计

只改小海鱼 y 上移（减小 y），拉开与三文鱼距离。salmon / tuna / golden / juiceStack 不动。

旧：

- small `{ x: 0.13, y: 0.800 }`（与 salmon `0.820` 差 0.02）

新：

1. [修改] small → `{ x: 0.13, y: 0.765 }`（与 salmon 差 0.055，约等于成品高度，上下分开）
2. [不变] salmon `0.820`、tuna、golden、椰汁

## 预期效果

- 竖屏同时有小海鱼与三文鱼成品时，上下错开不重叠
- 三文鱼及椰汁位置保持不变
