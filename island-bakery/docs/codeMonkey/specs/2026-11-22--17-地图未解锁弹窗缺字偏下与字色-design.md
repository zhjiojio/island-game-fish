# 地图未解锁弹窗缺字、条件偏下与字色（PdeMonster R0023）

## 背景

R0021 验收截图：标题显示成「未到解锁条」、养殖条件缺「养/花费」等字；第二行贴木牌底边；黑色字在木纹上不显眼。开门金币数值权威来源见 GDD §三 / A2.1（R0024 已回写）。

## 调用链路

1. 弹窗文案来自 `map-zones.js` 条件表  
2. 绘制走位图字帖；缺字形则跳过该字 ← 问题点（缺损）  
3. `detailY = signH * 0.68` ← 问题点（过靠下）  
4. `C.ink` 深棕叠木牌 ← 问题点（对比差）

## 根因分析

- **直接根因**：字帖无「达/件/森/花/费/仓/库/养/殖/菜/园/并」；排版比例与字色未按两行长文案调。  
- **根本原因**：`generate_font_atlas.py` 的扫描源未包含 `map-zones.js`，新增中文不会自动进字帖。

## 方案设计

1. [改] 字帖以 `--append-missing` 追加「达件森花费仓库养殖菜园并」12 字（全量重生会超 2048）；`?v=3`  
2. [改] 条件行上移至约 `signH * 0.58`，木牌略加高；过长用 `textWidth` 缩小字号  
3. [改] 标题与条件改为奶油色（`C.cream`），提高木牌对比   

本轮不做：真解锁扣币。

## 预期效果

标题完整「未达到解锁条件」；养殖等条件句完整可读；两行间距适中；浅色字在木牌上清晰。
