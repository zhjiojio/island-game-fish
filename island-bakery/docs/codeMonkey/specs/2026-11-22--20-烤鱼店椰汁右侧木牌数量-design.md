# 烤鱼店椰汁右侧木牌数量（R0042）

## 背景

R0040 在原料椰子/椰汁旁加了 `×N`，与预期不符。需要和底部小海鱼、三文鱼一样：制作好的椰汁右侧一块小木牌显示数量。

## 根因

误把鱼盘旁的 `×N` 当成目标样式；真正对齐对象是底部 `button`(btn-wood) 的「名+数量」小牌子。

## 方案

```
旧: 原料椰子 ×N + 椰汁堆 ×N
新:
  1. 去掉全部椰汁/原料 ×N（含 drawShopCoconutStockLabel）
  2. drawJuiceStack 在堆右侧画小木牌 button：「椰子汁 N」
  3. 非皮肤兜底成品椰汁同样右侧木牌
```

## 预期

制作好的椰汁右侧有木牌数量；无 `×N` 字样。
