# 真机精灵层丢失（路径带 `?v=`）修复方案

## 背景

用户用交付包 `island-bakery-20261120-r0012.zip`（用户口中的 `island-bakery-20261120.zip`）在 Yoola + 快手 App 横屏试玩时：文字全无、弹窗内容空、顾客订单气泡空、顶栏空、椰林无椰树、海不动、船不动。本地 H5 预览里这些层通常正常。本轮只修横屏可用；竖屏船/海等观感优化暂缓。

## 调用链路

1. 玩法目录写死资源路径（大量带 `?v=N` 破浏览器缓存）  
   ← 例如字帖、顶栏 chrome、椰树、船、海 sheet、订单气泡  
2. `KwaiMedia.Image.load(path)` → `ResourceLoader.resolve(path)`  
3. `resolve` 用**整段字符串**（含 `?v=`）查 CDN 清单；未命中则**原样**回调  
   ← **问题点**：快手端按本地相对路径打开文件时，真实文件名没有 `?v=`，加载失败  
4. 失败资源进 `sceneFailed` / `fontReady=false` → 对应层不画  
5. 无 `?v=` 的底板皮肤（如 `ui-skin-*-land.png`）仍能加载 → 只剩「空壳场景」

现象与带 `?v=` 的资源一一对应：字帖、chrome、椰树、海/船、订单气泡、图标图集。

## 根因分析

- **直接根因**：`resource-loader.js` 的路径解析未剥离查询串；快手端把 `res/Image/...png?v=2` 当文件名，读盘失败。  
- **根本原因**：H5 用 HTTP `?v=` 破缓存的习惯被写进玩法资源路径，但平台规范要求包内相对路径对应真实文件；解析层未做「查表用净路径、本地加载用净路径」的统一兜底。

次要风险（本轮顺带在横屏侧收敛，不单独扩竖屏改造）：

- `loadScenes` 一次拉齐横+竖全部大图，解压后 RGBA 粗估数百 MB，真机易触发后续纹理失败。横屏优先时先跳过 `*-port*` / 竖屏专用项加载。  
- 包内误打入中文名源图 `竖屏钓鱼区-小船-底图基地.jpeg`（违反资源命名规范），应从交付包剔除（不参与运行时引用）。

## 方案设计

### 旧流程

```
path = "res/Image/foo.png?v=2"
  → resolve 原样返回
  → 快手按带 ? 的路径读文件 → 失败 → 精灵/字不画
```

### 新流程

```
path = "res/Image/foo.png?v=2"
  → resolve 剥离查询串得到净路径
  → CDN 清单用净路径命中；未命中则回传净路径
  → 快手读真实文件成功 → 纹理就绪 [新增：剥离逻辑]
H5 非快手：仍可保留原 path（含 ?v=）以便浏览器破缓存 [保留]

横屏 loadScenes：
  只入队横屏 + 共用资源；跳过 *-port* / ui-hud-chrome-port 等竖屏专用 [新增]
  切到竖屏时再按需加载（本轮不优化竖屏观感，仅保证不堵横屏）

交付：
  从 package/res 移除未引用的中文 jpeg [新增]
  validate + build-zip 产出新横屏验收包
```

## 改动文件（请确认范围）

| 文件 | 改动 |
|------|------|
| `package/kwaiStandard/loaders/resource-loader.js` | `resolve`/`preload` 路径剥离 `?` 查询串；快手回净路径，H5 可保留 query |
| `package/gameplay/render/renderer.js` | `loadScenes` 横屏跳过竖屏专用资源；关键失败日志带净路径 |
| `package/res/Image/ui/竖屏钓鱼区-小船-底图基地.jpeg` | 移出交付包（可挪到 `docs/_sea-verify/` 备份，运行时不引用） |
| `docs/PdeMonster/island-bakery__问题索引.md` + 区域文档 | 归档 R0013 |

不改：竖屏船脚/摆动/裁剪等观感参数；不改海 sheet 像素内容。

## 预期效果

- 快手 App 横屏：文字、顶栏、弹窗文案、订单气泡、椰树、海动画、船晃动恢复。  
- H5 预览：行为与现网一致（仍可用 `?v=` 破图缓存）。  
- 竖屏：本轮仅保证资源能加载；观感优化另开轮次。

## 自测计划

1. 静态：所有 `KwaiMedia.Image.load` / 目录 path 经 resolve 后无残留 `?`（快手分支）。  
2. 本地：`validate-package.mjs` + H5 预览抽查字帖/顶栏/椰树/钓鱼海与船。  
3. 真机：用户上传新 zip 在 Yoola 横屏复验上述项。  
4. 未实测：竖屏观感、低端机极限显存（仅记录风险）。
