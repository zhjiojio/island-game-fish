# 竖屏顶栏统一为钓鱼规格

## 背景

分场景标定槽位后，地图 / 烤鱼 / 椰林仍难与各皮肤图标齐平；钓鱼区竖屏顶栏已完全正确。改为「所有竖屏区域共用钓鱼区顶栏皮肤条 + 同一套叠字参数」，一处对齐则全区对齐，后续只改钓鱼规格。

## 调用链路

1. 进入竖屏任意区（地图含未开放区 / 钓鱼 / 椰林 / 烤鱼 / 搭建）  
2. 画当前区全屏皮肤  
3. 叠字用 `hudPortByArea[area]` ← 各区皮肤槽位不同，参数永远追不上  
4. [改] 全屏皮肤画完后，用 `ui-skin-fish-port` 顶部条盖住各区自带顶栏  
5. [改] 叠字一律用钓鱼区 `cx` / `barY`（删掉分场景表）

## 根因分析

### 直接根因

顶栏图标画在各区皮肤里，槽位锚点不一致；分场景 `cx/barY` 只能跟皮肤赛跑。

### 根本原因

「顶栏视觉」与「叠字」未抽成单一权威源；钓鱼区才是已验收的权威源。

## 方案设计

**旧：**

```
画 area 全屏皮肤（自带顶栏）
→ drawHudMetric 按 area 取不同 cx/barY
```

**新：**

```
画 area 全屏皮肤
→ [新增] 竖屏 + uiSkinChrome：用 ui-skin-fish-port 顶部条
         （设计高约 0～64）覆盖画面顶栏
→ [改] drawHudMetric 竖屏一律 fishing 槽表
       （去掉 hudPortByArea 分表，或仅保留 fishing 一份）
→ 横屏逻辑不动
```

改动文件：
- `renderer.js`：共享顶栏绘制、叠字回钓鱼规格、加载时保证 fish-port 可用  
- `index.html`：缓存版本号 +1  

未开放区在地图场景内，随地图一起盖上钓鱼顶栏，无需单独热区。

## 预期效果

1. 竖屏地图 / 椰林 / 烤鱼 / 钓鱼顶栏视觉与叠字完全一致（以钓鱼为准）  
2. 以后只调钓鱼顶栏参数或 fish-port 顶栏条，全区同步  
3. 横屏不变
