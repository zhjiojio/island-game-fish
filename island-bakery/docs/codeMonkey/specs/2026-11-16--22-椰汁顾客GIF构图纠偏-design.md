# 椰汁 / 顾客 GIF 构图与动作纠偏

## 背景

上一轮同款管线做出的椰汁与顾客 GIF 构图和玩法对不上：敲椰带桌子且角色站位反了；`juice_straw` 做成「喝椰汁」但店内并无喝的动作；走路还抱着椰子，且缺「放下烤鱼工具再空手走」；猪顾客侧身走成了四足；进出场左右向需要明确。

## 调用链路

1. 点椰汁 → `put_tools`（放下烤铲）→ `walk_to_work`（空手侧身走）→ `pick_coconut` → `crack`（敲三下）→ `straw`（点一下出餐）← 旧 `juice_straw` GIF 误做成喝饮，无挂点  
2. 顾客从右进 / 向右出 → `AnimDriver` 选 walk clip + `facing` 镜像 ← 现只有「朝右」一张 walk；猪为四足  
3. 绘制读 sheet UV；椰子本体仍由柜台 `work` 锚点单独画，不依赖 crack 帧里的桌子

## 方案设计

### A. 删掉 `juice_straw` 动图（推荐）

| 项 | 处理 |
|----|------|
| 预览 / sheet | 删除 `rabbit_juice_straw.gif` 与 `rabbit_juice_straw_sheet.png` |
| clip | 去掉 `rabbit_straw` / `rabbit_straw_ready`；加载表去掉对应 key |
| 玩法 `straw` 阶段 | **保留**「点一下插吸管并出餐」；**另做插管 GIF**（把吸管插入已开口椰子，禁止喝饮姿势） |

已确认（2026-11-16）：做单独插管 GIF；向左走用朝右 sheet + 运行时镜像。

### B. 重做 `juice_crack`

构图硬约束（绿幕、无场景）：

- **无桌子 / 无台面**
- 兔子在画幅**左下**，椰子在**右上**（兔子抬手向右上敲）
- 只含兔子 + 椰子 + 敲击工具；椰子仍可与柜台锚点叠画

产出：`rabbit_juice_crack.gif` + `_sheet.png`（8×256），替换旧资源。

### C. 拆开「放工具」与「空手走」

| 新 GIF | 用途 | 内容 |
|--------|------|------|
| `rabbit_put_tools` | `put_tools` 阶段 | 兔子在烤架旁放下烤鱼夹/铲，双手变空（可带烤架参考，或只画角色+工具落地） |
| `rabbit_juice_walk` | `walk_to_work` / 走回 | **空手**侧身走循环，**不抱椰子** |

`pick_tools`（走回拿回工具）可镜像复用 `put_tools` 后半或同一 sheet 倒序/末段；本轮优先保证「放下 → 空手走过去」。

### D. 顾客左右走 + 猪双足

方向语义（与既有设计一致；「向左右」按 **进场向左、离场向右**）：

```
进场：右侧入 → 侧身向左走（facing 镜像）
离场：侧身向右走（不镜像）→ 右缘淡出
等餐：正面 wait 循环（不动）
```

资源策略（建议）：

1. 每种动物只生成 **面朝右** 的侧身走 sheet 一张  
2. 进场用运行时水平翻转得到向左走；离场直接播朝右  
3. **猪**：必须 **两足站立** 侧身走（拟人直立），禁止四足爬行；参考立绘围巾等特征保留，姿态改为 bipedal  
4. 熊 / 企鹅 / 狐：若现 walk 朝右正确，可只重做猪；若左右观感差再统一重出

不另烘焙「朝左原画 sheet」，避免包体翻倍且左右步态不一致。若你坚持左右各一张独立原画，再说一声再加生成。

### E. 代码改动范围

- `shop-anims.js`：换 crack/walk/put_tools 的 sheetKey；删 straw clips；顾客 walk 仍按类型映射  
- `anim-driver.js`：`straw` 阶段改待命 clip；去掉 `juice_hit` 的 straw 喝饮播放  
- `renderer.js`：去掉 straw sheet 加载；`put_tools` 走独立 sheet  
- 资源：替换/删除上述 GIF 与 sheet  

不改：订单、敲三下/点吸管结算、顾客槽位位移公式。

## 预期效果

1. 敲椰：左下兔子、右上椰子、无桌子，点击才播敲击段  
2. 无「喝椰汁」动图；吸管阶段只是待命 + 点击出餐  
3. 从烤鱼切到椰汁：先放下工具，再空手走到柜台  
4. 顾客进左出右侧身走；猪两脚站着走  

已确认开工：插管单独 GIF；左右走 = 朝右 sheet + 镜像。
