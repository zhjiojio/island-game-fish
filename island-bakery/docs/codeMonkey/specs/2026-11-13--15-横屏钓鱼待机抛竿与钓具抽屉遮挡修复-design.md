# 横屏钓鱼待机抛竿按钮与钓具抽屉遮挡修复

## 背景

横屏钓鱼把钓具收到左下「地图」上方后，收起时画面上往往只剩「选取钓鱼区和鱼饵」；钓点、鱼饵在收起时本就不画，但「按住抛竿」也不见了。根因是横屏把钓具画在船舱原画之前，展开面板容易被挡住，抛竿钮又写死在 `(520,405)`，没有和入口绑在同一套安全区布局里。

## 调用链路

1. 进入钓鱼且待机 → 画横屏钓鱼区（`drawFishing` 横屏分支）
2. 先画抛竿相关按钮 → 再画钓具入口/展开木牌 ← 当前横屏把钓具画太早，船舱原画会盖住
3. 点击入口 → 展开或收回面板（只影响钓点/鱼饵木牌，不应影响抛竿钮）
4. 点击「按住抛竿」热区 → 开始蓄力（`input.js` 横屏待机分支）← 热区仍写死 `520,405`，钮若挪位会对不齐

## 根因分析

- **直接根因**：横屏 `drawFishing` 里先画钓具、后画原画与抛竿；竖屏已改为「抛竿后再画钓具」避免被船舱挡住，横屏没对齐。抛竿坐标写死，未接入与入口共用的布局函数。
- **根本原因**：横屏钓具改版时只迁了入口和抽屉，没有把「待机三组控件（钓点 / 鱼饵 / 抛竿）」收成同一套安全区布局，绘制顺序也未按「原画之上、导航之下」统一。

## 方案设计

只改横屏待机相关绘制与热区，竖屏分支不动。

旧流程（横屏待机）：

1. 画钓具入口（收起）或入口+两行木牌（展开）
2. 画船舱等原画动作
3. 在固定坐标 `(520,405)` 画「按住抛竿」
4. 点击仍打这个固定矩形

新流程（横屏待机）：

1. 用与入口同源的布局算出抛竿钮（贴在入口右侧、底栏导航上方）[新增] `fishingCastLandButton`
2. 先画「按住抛竿」（蓄力时同位置画「松开抛竿」）
3. 再画钓具入口/展开木牌，保证不被船舱挡住 [改] `drawFishing` 横屏绘制顺序
4. 点击热区跟 `fishingCastLandButton` 走 [改] `input.js` 横屏抛竿矩形
5. 收起仍只隐藏钓点/鱼饵两行；展开后点面板外收起，抛竿钮始终保留

安全区约束（逻辑分辨率 960×540）：

- 顶栏以下、底栏导航以上：`y` 落在 `64 … height-72`
- 钓点一行、鱼饵一行、抛竿钮互不重叠
- 未解锁灰木牌与提示规则不变

## 预期效果

- 收起：能看到「选取钓鱼区和鱼饵」和「按住抛竿」
- 展开：能看到两行钓点/鱼饵木牌、当前选中文案，以及「按住抛竿」，都在 960×540 安全区内
- 点面板外仍收起抽屉，抛竿钮不会跟着消失
- 竖屏钓鱼界面与热区保持现状
