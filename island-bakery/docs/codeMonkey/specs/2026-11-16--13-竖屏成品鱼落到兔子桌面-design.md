# 竖屏成品鱼落到兔子同一高度的桌子上

## 背景

竖屏烤鱼店左侧成品鱼（截图红框里的小海鱼烤鱼×8）脚底锚点偏高，看起来悬在半空；兔子脚底与烤架都在下层木桌（约画面高度 0.825），需要把成品鱼整列下挪到同一张桌面上。

## 调用链路

1. 有库存烤鱼 → `drawShopPlates`（按竖屏成品槽画鱼+木盘）读取 `ShopLayout.port.plates`
2. 出餐飞行动画终点 → 同一套 `port.plates` 锚点
3. 椰汁堆落点 → `portJuiceStackPoint` 相对「最下一槽」再偏右上
4. 兔子/烤架脚底 → `port.rabbit` / `port.grill`，当前均为 `y: 0.825` ← **桌面参考高度**
5. ← **问题点**：`port.plates` 竖列从 `y: 0.690` 起，比兔子桌面高约 0.13 屏高，鱼悬空

## 根因分析

- **直接根因**：`shop-layout.js` 里竖屏 `port.plates` 四槽 y 为 `0.690 / 0.745 / 0.800 / 0.855`，最上槽（小海鱼）明显高于兔子桌面 `0.825`。
- **根本原因**：此前为解决四鱼重叠改成左侧竖排时，列起点按「留空不挡烤架」估在偏上区域，未按原画下层木桌与兔子脚底对齐。

## 方案设计

只改竖屏成品桌锚点 y（及随动的椰汁相对落点自动生效）。横屏 `land.plates`、绘制分层、成品高度约 48、有货才画等逻辑不动。

旧（竖列偏上，悬空）：

- small / salmon / tuna / golden：`x: 0.13`，`y = 0.690 / 0.745 / 0.800 / 0.855`

新（整列下移，脚底落在兔子同层木桌；仍竖排、步距约 0.05 防叠）：

1. [修改] `island-bakery/package/gameplay/data/shop-layout.js` → `port.plates`：
   - small `{ x: 0.13, y: 0.800 }`
   - salmon `{ x: 0.13, y: 0.850 }`
   - tuna `{ x: 0.13, y: 0.900 }`
   - golden `{ x: 0.13, y: 0.950 }`
2. [不变] 出餐飞行、椰汁堆仍读同一套锚点，随 y 自动下落；绘制仍在兔子之下
3. [不变] 横屏成品排位、点击热区逻辑

若预览后仍略高/略低，只微调这四个 y（保持竖排与步距），不改渲染代码。

## 预期效果

- 竖屏有货烤鱼脚底落在下层与兔子同一高度的木桌上，不再悬空
- 四鱼种仍左侧竖排、互不严重重叠；椰汁堆仍在鱼列旁
- 横屏成品位置不变
