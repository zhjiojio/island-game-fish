# 竖屏三文鱼成品往上微调

## 背景

竖屏烤鱼店左侧成品区，三文鱼烤鱼脚底落在偏下木墩（约画面高度 0.850），比兔子同层桌面（约 0.825）还低一截；用户要求「往上一点」。

## 调用链路

1. 有三文鱼库存 → `drawShopPlates` 读 `port.plates` 里 `id: "salmon"` 的脚底锚点画鱼
2. 出餐飞行终点也读同一 `salmon` 槽
3. ← **问题点**：`salmon.y = 0.850`，视觉上贴在下层矮墩，偏低于兔子脚底

## 根因分析

- **直接根因**：竖排四槽里三文鱼是第二槽，整列下移后 `y: 0.850`，落在原画偏下木墩区域。
- **根本原因**：四槽等步距竖排，第二槽必然比兔子桌面参考线略低；需按观感单独微调，不能再动椰汁独立锚点。

## 方案设计

只改竖屏三文鱼一槽的 y。小海鱼 / 金枪鱼 / 金色、椰汁堆、横屏均不动。

旧：

- salmon `{ x: 0.13, y: 0.850 }`

新：

1. [修改] `shop-layout.js` → `port.plates` 中 salmon → `{ x: 0.13, y: 0.820 }`（上移约 0.03，约对齐兔子脚底略上方）
2. [不变] small `0.800`、tuna `0.900`、golden `0.950`、`juiceStack: { x: 0.23, y: 0.775 }`

若仍略低/略高，只再改这一个 `salmon.y`。

## 预期效果

- 竖屏三文鱼成品略上移，更接近兔子同层桌面，不再贴底矮墩
- 其它鱼种与椰汁位置不变
