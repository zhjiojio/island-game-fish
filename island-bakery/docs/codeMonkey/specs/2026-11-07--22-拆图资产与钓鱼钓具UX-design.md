# 拆图资产目录 + 钓鱼钓具 UX + HUD 对齐

## 背景

皮肤模式下钓鱼界面左侧常驻「浅滩/蚯蚓/更多」木牌与画面内路牌重复，点击「更多」变「收」易被当成多余神秘框；顶栏数值未按皮肤纸槽居中；背包仍为矢量奶油面板。

## 方案

1. **`assets/sprites/`**：manifest + `sync_sprite_assets.sh` 分类同步 UI/弹窗/角色 demo 图并白底抠透明（全屏 ui-skin 不抠）。
2. **钓具**：`uiSkinChrome && artOn` 时仅显示「钓具/收起钓具」，展开后再显示六格；默认浅滩+蚯蚓，引导文案保留。
3. **HUD**：槽位中心按 ART_COMPOSITION_NOTES 百分比 + `textYInBox` 垂直居中。
4. **背包**：`dialog-inventory.png` + 鱼种精灵行列表。

## 产品说明（钓具解锁）

前期不铺开未解锁木牌；展开抽屉内用「锁」+名称；解锁后 toast/剧情说明优于 mystery box。
