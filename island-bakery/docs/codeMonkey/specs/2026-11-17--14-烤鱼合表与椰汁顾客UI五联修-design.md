# 烤鱼合表 / 椰汁时序朝向 / 顾客离场 / 锁鱼 / 气泡透明度

## 背景

验收中发现五处体验问题：烤鱼一开动态合表就「烤架变小且兔炉左右对调」；点椰汁出现「放下工具」文案且插管与回位并行、走向柜台时身子朝左；顾客离场身子朝左；未解锁鱼槽只有「锁」字看不到灰鱼；订单气泡太实挡住身后顾客。

## 调用链路

1. 静帧：`paintFootSprite(grill)` + `hero_rabbit_grill`（兔左炉右）  
2. 开烤：`combinedGrill` sheet → `paintSheetFoot(..., flip=兔朝向)` ← **镜像把整表翻成炉左兔右；sheetH=168 把炉挤小**  
3. 点椰汁 → `put_tools` 画「放下工具」→ walk `facing:-1` ← **朝左** → straw `finish` 立刻 plating 回走 ← **插管与回位并行**  
4. 顾客 `leaving`：`facing:1` 理应朝右；需核对 sheet 镜像是否仍翻成朝左  
5. 未解锁鱼槽：只画「锁」字，不画鱼标  
6. `drawShopOrderBubble` tint alpha=顾客透明度（到位=1）← 气泡几乎不透明

## 根因分析

| 问题 | 直接根因 | 根本原因 |
|------|----------|----------|
| 烤架变小/对调 | 合表用兔朝向整表翻转；高度 168 装不下静帧炉宽≈164 | 合表按「角色朝向」镜像，未按「场景布局兔左炉右」固定 |
| 「放下」文案 | 横竖屏 `put_tools` 分支写死 `text("放下工具")` | 调试提示留在正式绘制 |
| 插管与回位并行 | straw 点击立刻 `finish`→plating 开走 | 出餐与插管 oneshot 未门闩串行 |
| 走向柜台朝左 | `walk_to_work` 写 `facing:-1` | 柜台在烤架右侧，应朝右走 |
| 离场朝左 | 需验证：walk sheet 朝右 + leave `facing:1`；若仍朝左则 flip 语义反了或被别处盖掉 | 朝向约定未在顾客侧身走验收 |
| 锁槽无鱼 | 未解锁分支只 `text("锁")` | 未复用灰态鱼标 |
| 气泡挡人 | 气泡 alpha 跟顾客=1 | 缺独立半透明 |

## 方案设计

### 1. 烤鱼静→动丝滑（兔左炉右、尺度对齐）

```
旧: 合表脚底中点 + sheetH=168 + flip=兔朝向
新: 合表不镜像（sheet 已是兔左炉右）
    脚底锚到「兔脚↔炉脚」布局中点（或炉槽对齐）
    sheet 绘制高度按静帧炉宽反推（目标炉视觉≈grillW），shopGrillBox 与静帧同槽
```

- 点火/翻面/持续烤凡 `combinedGrill`：**强制 `flip=false`**  
- 缩放：横屏以 `grillW` 为炉目标宽，按合表内炉约占半格估算 `targetH≈grillW/0.5`（再夹在合理上下限），竖屏同比  
- 回退无 sheet 时仍画静帧炉+兔，不变

### 2. 椰汁：去「放下」+ 插管后再回位 + 向右走

```
旧: put_tools 文案「放下工具」
    walk_to_work facing=-1
    straw hit → 立刻 finish → plating 回走∥插管

新: 去掉 put_tools（及自动段）提示文案
    walk_to_work / 走回 facing=+1（身向右）
    straw hit → 播插管 oneshot（锁帧）→ 播完再 finish → 再 plating 回走
```

- 新增短阶段 `straw_anim`（或 straw 点后锁 `elapsed`），时长对齐 `rabbit_straw`（约 480ms）  
- 回走仍用现有 plating 位移，但不再与插管重叠

### 3. 顾客离场朝右

- 保持 leave `facing:1`；进场 `facing:-1`  
- 若验收仍朝左：在 `paintSheetFoot` 顾客路径对 leave **禁止镜像**（或 leave 显式 `flip:false`），并打日志 `[ShopAnim] customer leave facing`

### 4. 未解锁鱼槽：灰鱼标，无「锁」字

```
旧: text("锁")
新: paintFishIcon(..., 灰色 tint)；点击仍走 startRecipe → 现有「去钓鱼」等弹窗（不改弹窗）
```

- 横竖屏未解锁分支去掉「锁」  
- `paintFishIcon` / `paintUiRegion` 传入灰 tint（约 `[0.55,0.55,0.55,1]`）

### 5. 订单气泡 50% 透明

- `drawShopOrderBubble`：气泡底图与文案 tint alpha = `0.5 * foot.alpha`（离场淡出仍乘顾客 alpha）  
- 不改气泡尺寸与文案内容

## 改动范围

- `renderer.js`：合表 flip/缩放/锚点；删放下文案；灰鱼标；气泡 0.5  
- `anim-driver.js`：椰汁 walk 朝右；顾客 leave 朝向兜底  
- `baking.js`：straw 播完再 finish  

不改：订单规则、弹窗文案与结构、烤鱼进度玩法。

## 预期效果

1. 点烤鱼后炉与兔相对静帧几乎不跳、不左右对调  
2. 点椰汁无「放下」；先插完管再走回；去柜台时侧身向右  
3. 顾客离场侧身向右  
4. 未解锁槽是灰色鱼标，点开仍是原弹窗  
5. 头顶需求框半透明，能看清后排顾客
