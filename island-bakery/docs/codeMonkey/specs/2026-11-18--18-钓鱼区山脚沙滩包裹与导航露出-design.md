# 钓鱼区：山脚下移 / 沙滩包裹 / 地图背包露出（R0004）

## 背景

R0003 后：多块海与近岸方块蒙版仍在；左缘发毛且左侧漏静海；地图/背包被盖没；上带过高盖远山。新增：上带须围绕沙滩包裹，漏出沙滩。

## 根因

1. `seaTop` 标定偏高 → 盖山。  
2. `seaBottom=height` 不透明底盖住 seabase 上的地图/背包木牌（chrome 模式不再单独画按钮）。  
3. 两大层整块矩形用单一 midY 左切 → 无法沿沙滩曲线包裹，近岸呈方块。  
4. 左侧 cut 过小 → 静海仍露。

## 方案

1. 下移 `seaTop`（露出山脚）。  
2. `seaBottom = height-72`，让开导航木牌。  
3. 按行 `beachWrap` 左切：沙滩区大挖空，远水区小让栅栏，羽化软边。  
4. 单层主 swell（连续 UV）+ 近岸轻量 crash 软混，统一 tint。

## 预期

远山露出；沙滩漏出、海包裹；地图/背包可见；左侧无静海硬边；无近岸大方块蒙版。
