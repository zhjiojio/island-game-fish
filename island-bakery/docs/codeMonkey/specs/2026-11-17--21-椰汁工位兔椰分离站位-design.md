# 椰汁工位：兔子与椰子站位分离

## 背景

横屏制作椰子汁时，兔子与台面椰子都锚在同一个 `work`（柜台空位）点，放大后头与椰子重叠成一团。验收要求：横屏兔子落左红框、椰子落右红框；竖屏只把兔子挪到红框，椰子仍用现有 `work`。

## 调用链路

1. 布局读 `ShopLayout.land/port.work`（柜台中心锚点）
2. 画兔子脚底 → `standX/Y = work` + 半身下移 ← **问题：与椰子同 X**
3. 画台面椰子 → `shopWorkPoint = work` ← **问题：横屏应改到右红框（榨汁器侧）**
4. 出餐飞行 / 提示字仍可读 `shopWorkPoint`（椰子所在台面）

## 根因分析

- **直接根因**：`renderer` 椰汁段兔子 `standX` 与 `drawArtJuice` 椰子锚点都取 `board.work`，无左右分工。
- **根本原因**：布局只定义了「操作台中心」一个点，未区分「兔子站位」与「椰子落点」。

## 方案设计

在 `shop-layout.js` 增独立锚点，绘制分流：

```
旧: work ──┬── 兔子站位
           └── 椰子 / shopWorkPoint

新: juiceStand ── 兔子走到/敲插时的脚底
    juiceNut   ── 横屏台面椰子（竖屏不新增，仍用 work）
    work       ── 保留；竖屏椰子与兼容读点
```

| 槽位 | 横屏（960×540） | 竖屏（比例） |
|------|-----------------|--------------|
| `juiceStand`（兔） | `{ x: 390, y: 248 }` 左柜台、脚在台下 | `{ x: 0.34, y: 0.52 }` 青椰堆与圆木板之间 |
| `juiceNut`（椰） | `{ x: 455, y: 200 }` 靠左红框（柜台空位，勿贴榨汁器） | `{ x: 0.45, y: 0.50 }` 右红框圆木板台面 |
| `work` | 保留 `{ 468, 210 }` | 与 juiceNut 对齐 `{ 0.45, 0.50 }` |

改动文件：

1. **`shop-layout.js`**：增加 `land.juiceStand`、`land.juiceNut`、`port.juiceStand`
2. **`renderer.js`**：
   - 椰汁兔子 `toX/toY` 改读 `juiceStand`（无则回退 `work`）
   - `drawArtJuice` / `shopWorkPoint`：横屏优先 `juiceNut`，竖屏仍 `work`
   - 关键节点补 `[ShopLayout] juiceStand/juiceNut` 日志
3. **`index.html`**：对应 `?v=` 缓存 bump

热区逻辑不改（仍按青椰堆～榨汁器扩框）。

## 预期效果

- 横屏：兔子在左红框一带敲椰，椰子在右红框/榨汁器侧，头与椰不再重叠
- 竖屏：兔子站到左红框（圆木板左侧），椰子仍在原 `work` 圆木板位置
- 走位、回烤架、插管动画路径跟新站位走

请确认红框对应坐标是否接近你的标注；若要再左/再右，直接说偏移方向即可。
