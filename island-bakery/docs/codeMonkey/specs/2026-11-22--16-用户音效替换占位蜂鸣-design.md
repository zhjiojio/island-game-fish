# 用户音效替换占位蜂鸣

## 背景

P0 正弦占位音效不符合治愈预期。用户已在 `assets/声音/` 放入按场景命名的成品音效；需撤掉全部自加占位，接入用户素材，并保证循环音效随交互结束停止。

## 用户素材 → 语义 ID（能复用则复用）

| 用户文件 | 语义 ID（主） | 额外复用 |
|----------|---------------|----------|
| 按钮点击音效.wav | `ui.click` | 建店 hit、翻面、顾客到达、失败轻提示、结算次要按钮 |
| 椰子点击音效.flac→wav | `coco.catch` | `coco.shake`、`juice.crack`、`shop.ingredient`、摔裂 |
| 钓鱼-抛竿&收杆音效.mp3 | `fish.cast` | `fish.bite`、`fish.catch`（收杆成功） |
| 钓鱼-拉鱼线时的循环音效.flac→wav | `fish.reel`（loop） | 仅按住收线；松手/断线/钓成/离区 **stop** |
| 烤鱼-火焰燃烧音效.mp3 | `shop.grill_loop`（loop） | 进入 cooking 开；翻面/完成/离区 **stop** |
| 烤鱼区-顾客取餐成功音效.mp3 | `shop.deliver` | — |
| 结算-金币到账.mp3 | `common.coin` | `ui.settle_open`（结算弹窗） |
| 胜利音效.wav | `common.success` | `build.done`、`build.step_done` |

分区 BGM（2026-11-22 晚）：地图/椰林/烤鱼店各一轨；钓鱼区主曲+海浪叠轨等响度；包内 MP3 已做约 1.8s 首尾淡化；建店复用烤鱼店曲。

## 循环停止（强制）

```
烤鱼：stoke 完成进 cooking → playLoop(grill)
      → 翻面等待期间继续播
      → 点击收获 finish / 切区 → stopLoop(grill)

钓鱼：提竿进拉锯 → playLoop(reel)（全程，不依赖按住）
      → 收杆成功 / 跑鱼 / reset / 切区 → stopLoop(reel)
```

## 改动范围

- 删除 `res/audio` 下全部占位 wav（含静音 BGM）与 `gen_audio_placeholders.py` 依赖的蜂鸣生成
- 拷贝用户音到 `package/res/audio/`（flac 转 wav）
- 重写 `SoundManager` CATALOG；关掉 BGM 占位播放
- 核对 baking/collection 停环；切区 `stopAllLoops`

## 预期

只听到用户下载的音效；烤鱼火焰与拉线循环随流程起停；无「呜呜」蜂鸣。
