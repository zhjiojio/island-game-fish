# 竖屏顶栏只叠钓鱼木板条（不带背景）

## 背景

此前用 `ui-skin-fish-port` 顶部整条矩形盖住各区顶栏，把钓鱼区天空/水面背景一并贴上，导致地图 / 椰林 / 烤鱼顶栏与场景不融合。正确做法是只抠「木板 + 槽位图标 + 标题艺术字」，透明叠到各区自有背景上，数字仍用钓鱼区叠字参数。

## 调用链路

1. 画当前区全屏皮肤（保留该区背景）  
2. [旧] 用 fish-port 顶部矩形整块盖上 ← 背景一起被盖住  
3. [改] 叠独立透明图 `ui-hud-chrome-port.png`（从 fish-port 抠出的木板条）  
4. 再用钓鱼区 `cx/barY` 叠资源数字  

## 根因分析

### 直接根因

`paintSharedHudChromePort` 取的是全屏皮肤 UV 顶条，像素含场景背景。

### 根本原因

把「顶栏 UI」和「场景原画」绑在同一张全帧图里复用，没有透明 UI 层。

## 方案设计

**旧：**

```
paintUiRegion(ui-skin-fish-port, 顶条矩形 UV)
→ 木板 + 钓鱼背景一起盖住当前场景
```

**新：**

```
[新增素材] res/Image/ui/ui-hud-chrome-port.png
  ← 自 ui-skin-fish-port 抠出木板/绳柱/槽/图标/「孤岛烤鱼店」艺术字，背景 alpha=0

paintSharedHudChromePort
  → 透明绘制 ui-hud-chrome-port（铺满设计宽，高度按素材比例）
  → 当前场景背景从木板镂空处透出

叠字仍用钓鱼规格 hudSlotCxPort + hudBarYPort
横屏不动
```

改动文件：
- 新增 `package/res/Image/ui/ui-hud-chrome-port.png`
- `renderer.js`：目录注册该图；共享顶栏改为画此透明条  
- `index.html`：缓存版本号 +1  

## 预期效果

1. 地图 / 椰林 / 烤鱼顶栏木板与钓鱼一致，数字对齐同钓鱼  
2. 木板外仍是本场景天空/海面/岛景，不再出现钓鱼区背景色块  
3. 以后只维护钓鱼叠字参数 + 这一张木板条即可全区同步
