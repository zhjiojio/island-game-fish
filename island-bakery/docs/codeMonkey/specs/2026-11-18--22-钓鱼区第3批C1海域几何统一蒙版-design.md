## 背景

鱼群上限、岸线泡沫、左岸切割仍在用「屏幕百分比猜海岸线」（`seaTop/beachLine/cut`），和像素蒙版不是同一套标准。蒙版改了岸线，代码猜的还是旧线，就会出现鱼上沙滩、泡沫错位。本批只把**谁说了算**改成蒙版，**不改浪怎么画**。

## 用户补充（与本批关系）

远海最上沿有一道白光从右往左扫：已确认贴天海交界。这是**旧片元着色器里的碎沫/波峰带**，属于第 4 批 **C3 重写波场**（必要时 C4 收泡沫），**不在本批修**。

## 调用链路

```
1. 加载 sea-mask → 目前只进 GPU 纹理
2. drawDynamicSea 用蒙版 alpha 裁海     ← 已对
3. 鱼群 Y 上限读 fishingSeaLayout.beachLine  ← 问题：猜的线
4. drawFishingShoreFoam 读 beachLine + leftMask ← 问题
5. fishingSeaLeftMask 硬编码 cut         ← 问题：第二套海岸
```

## 根因分析

**直接根因**  
`fishingSeaLayout()` / `fishingSeaLeftMask()` 用固定纹理比例和经验 `cut` 猜岸线，鱼/泡沫读这套，动态海读蒙版。

**根本原因**  
海域边界有两套真源（父方案根因一）。

## 方案设计

### 新旧对比

```
旧：屏幕几何猜 seaTop/beachLine/cut → 鱼/泡沫/左岸

新：
  加载蒙版时额外缓存 CPU 像素（含半分辨率）          [新增]
  seaMaskAt(x,y) 双线性采样 alpha                    [新增]
  seaBoundsAtY(y) / shoreLineAtX(x)                  [新增]
  鱼群活动范围、泡沫落点改为查蒙版                     [改]
  fishingSeaLayout 只保留 letterbox + deep 等相机信息 [改]
  fishingSeaLeftMask 标废弃，新路径不再调用           [改]
  ?seaDebug=mask 叠蒙版岸线与代码岸线对比             [增强]
```

### 具体动作

1. `loadScenes`：对 `sea-mask-*` 额外保存 `seaMaskCpu[key] = { w,h, data(Uint8Clamped alpha 或 RGBA) }`
2. 屏幕坐标 → 蒙版 UV：与 `paintScene`/`drawDynamicSea` 同一 letterbox
3. 实现 `seaMaskAt` / `seaBoundsAtY` / `shoreLineAtX`（边界双线性）
4. 鱼群：用蒙版限制可游区域（本批最小：上限/左右界查蒙版；不重做自主游动，那是 C6）
5. `drawFishingShoreFoam`：落点要求 `seaMaskAt > 0.6`，否则跳过；不再用 leftMask cut
6. 船脚 `fishingBoatFoot`：Y 尽量贴 `shoreLineAtX(seatX)` 附近水线（有缓存则用；蒙版未就绪则回退旧常量）
7. 日志：首次用蒙版几何时打 `[FishAnim] R0010 sea geometry from mask`

### 本批不做

- 不改波场 / 不去远海白光（C3）
- 不重做拍岸泡沫观感（C4）
- 不改船兔刚体（C5）、鱼群自主游动完整逻辑（C6）
- 不洗蒙版（C2 已完成）

## 预期效果

1. 鱼不再按猜的沙滩线越界（采样点蒙版 alpha 应 > 0.6）
2. 泡沫不再沿硬编码左切线乱飘
3. 画面相对 C2 **基本不变**（除鱼/泡沫落点更贴岸）；浪和远海白光仍在
4. `?seaDebug=mask` 能看到代码岸线与蒙版对齐
