# 钓鱼区重做：新海面资源 + 真船切图分层

## 背景

假浪/UV 硬裁无法验收。改为：**新做可循环海面层 + 干净船精灵 + 去船（且浅海不烤礁石）底板**，按钓点切换浅海/深海观感；礁石为可升级独立精灵，初期浅滩不摆。

## 已确认决策（2026-11-18）

1. **海浪**：日落水彩风；**8 帧循环**；要有**大浪 + 碎浪/白沫**（不是细闪点）
2. **横竖屏同时做**两套资源与接入
3. **礁石**：不属于底板，是独立精灵；**初期浅滩不放礁石**（可先做出 lv1 礁石精灵入库，钓点未解锁前不画）；后续礁石钓点再换皮升级  
4. **深海钓点**：看不到沙滩和礁石，只保留一望无际大海（独立深海 seabase + 深海浪 sheet）

## 钓点与图层对应

| 钓点 `spotId` | 底板 | 海浪 sheet | 礁石精灵 | 说明 |
|---------------|------|------------|----------|------|
| `shallow`（初期可用） | 浅海 seabase：有岸/天空/UI，**无船、无礁石** | 浅海大浪+碎浪 8 帧 | 不画 | 现有默认 |
| `reef`（未解锁） | 同浅海 seabase 或礁石区 seabase | 浅海浪可复用 | **画** `rock_reef_lv1` 等 | 后续升级换精灵 |
| `deep`（未解锁） | **深海 seabase**：无沙滩、无礁石、远洋 | 深海大浪 8 帧 | 不画 | 一望无际 |

## 调用链路（目标）

```
1. 按 spot 选 seabase（浅/深）
2. 海浪 sheet 循环（大浪+碎浪）盖在海域 mask
3. 水下游鱼
4. （仅 reef）礁石精灵
5. 真船精灵随浪 bob/微倾
6. 钓鱼兔 cast/reel sheet
7. 鱼线 / 浮标 / UI
```

删除：`drawFishingWaveOverlay` 假浪、`paintFishingBoatBob` UV 硬裁。

## 制作顺序

1. 真船切图 land + port  
2. 浅海 seabase（去船去礁石）land + port  
3. 深海 deepbase land + port  
4. 浅海浪 8 帧（大浪+碎浪）land + port → sheet  
5. 深海浪 8 帧 land + port → sheet  
6. 礁石 lv1 精灵（先入库）  
7. 代码接入：按 `spotId` 切换底板/浪；船 bob；假浪删除  

## 预期效果

- 浅滩：水彩大浪+碎浪在动，岸线在，水里初期无礁石；船干净随浪摆  
- 深海：只有大海在涌，无沙滩无礁石  
- 礁石钓点解锁后：浅海上叠可替换的礁石精灵  

## 不做

- 程序亮点/椭圆/通屏横线假浪  
- 把礁石继续烤进底板  
- 物理流体模拟  

确认已收到，开工按上表制作。
