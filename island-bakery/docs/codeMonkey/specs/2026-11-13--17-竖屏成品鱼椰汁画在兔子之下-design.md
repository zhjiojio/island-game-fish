# 竖屏烤完的鱼和椰汁改到兔子之下

## 背景

竖屏烤鱼店里，成品桌上的烤鱼和椰子汁精灵现在盖在兔子身上；期望它们画在兔子下面（桌子上的成品被兔子挡住一部分是正常的）。

## 调用链路

1. 进入烤鱼店原画层 → 先画烤架、兔子、顾客（`drawShopCast`）
2. 再画厨房进度、榨汁过程等
3. 最后画成品桌上的鱼和椰汁堆（`drawReadyGoods`）← **问题点：后画所以盖在兔子上面**
4. 再画出餐飞行（`drawPlating`）

## 根因分析

- **直接根因**：竖屏成品（鱼盘 + 椰汁堆）在整段店铺绘制末尾才画，晚于兔子。
- **根本原因**：原画层角色与成品桌未按「桌面在角色后」分层，只按功能块串行绘制。

## 方案设计

只改竖屏原画层分层。横屏绘制顺序不动；出餐飞行仍在上层以便看得见。

旧：

1. 烤架 → 兔子 → 顾客
2. …厨房 UI…
3. 成品鱼 + 椰汁堆（盖住兔子）

新：

1. 烤架
2. [修改] 竖屏在画兔子之前先画成品鱼 + 椰汁堆
3. 兔子 → 顾客
4. …厨房 UI…
5. [修改] 竖屏原画层末尾不再重复画成品（避免又盖回兔子上）
6. 出餐飞行仍最后画（保持可见）

## 预期效果

- 竖屏成品桌上的烤鱼、椰汁在兔子之下
- 横屏分层不变
- 出餐飞行动画仍能看见
