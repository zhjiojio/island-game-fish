# 鱼跑了弹窗圆盘补鱼素材（R0041）

## 背景

「太晚了 鱼跑了」弹窗已有中部圆盘，但未像「钓到鱼了」那样在盘心画鱼素材，显得空。

## 根因

`drawFishEscapedDialog` 只 `paintUiStretch(dialog-settlement-mid-plate)`；`drawFishResult` 在其后还有 `paintFishIcon`。逃鱼时未缓存品种，无法稳定取图。

## 方案

```
1. escapeFish 时 chooseFish → escapedFish（仅展示，不入库）
2. drawFishEscapedDialog 圆盘后 paintFishIcon，坐标/尺寸对齐钓到了
```
