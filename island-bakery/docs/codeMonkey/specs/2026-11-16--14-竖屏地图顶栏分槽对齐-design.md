# 竖屏地图顶栏分槽对齐

## 背景

竖屏地图顶栏资源字仍走钓鱼区参数，相对 `ui-skin-map-port` 槽位偏左下；钓鱼 / 椰林 / 烤鱼已分场景标定，地图漏网。

## 调用链路

1. 进入竖屏地图 → 画 `ui-skin-map-port`  
2. `drawHUD` → `hudPortLayout` 按 `currentArea` 取槽表  
3. `area === "map"` 时表中无项 → 回落到 fishing（cx / barY=22）← 问题点  
4. [改] 为 `map` 增加独立 `cx` + `barY`

## 根因分析

### 直接根因

`hudPortByArea` 只有 fishing / coconut / shop，地图未登记。

### 根本原因

分场景槽表按「进过的玩法区」补齐，地图顶栏与玩法区皮肤槽位不同步。

## 方案设计

**旧：**

```
hudPortLayout("map") → 回落 fishing（cx 钓鱼表，barY=22）
```

**新：**

```
hudPortByArea.map:
  barY: 19（与烤鱼同向：上移，纠正偏下）
  cx:   [0.360, 0.505, 0.647, 0.791, 0.932]
        （对照 map-port 五槽浅色区 0.62 处，相对钓鱼整体右移）
```

只改 `renderer.js` 的 `hudPortByArea`；`hudPortLayout` 逻辑已支持按 area 取值。`index.html` 缓存版本号 +1。

## 预期效果

1. 竖屏地图顶栏五项字落入对应浅槽，不再明显偏左下  
2. 钓鱼 / 椰林 / 烤鱼参数不变  
3. 横屏不变  

若仍偏，只改 `map` 的 `cx` / `barY` ±1。
