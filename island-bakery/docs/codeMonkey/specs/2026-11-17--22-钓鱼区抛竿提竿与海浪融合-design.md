# 钓鱼区：抛竿/提竿动画 + 海浪与鱼海融合（最小改造）

## 背景

钓鱼区兔子仍是静帧 `hero_rabbit_fish`，按住抛竿/提竿拉锯只有竿尖微旋；海域与小船画在静帧底板 JPG 里不会动；游动鱼用实心 `fish_raw_*` 叠在海面上，像贴纸不在水里。目标：补抛竿/提竿动态、海浪与船感、鱼溶进海里，且尽量少改架构。

## 调用链路（现状）

1. `draw` → 画 `ui-skin-fish-*` / `scene-fish-*` 静帧底板（船+海一体）
2. `drawFishing` → `drawArtFishingMotion`
3. 先画 school 游鱼 `paintSwimFish`（不透明）← **鱼像浮层**
4. 再画静帧兔子 `paintFishingRabbit` + 鱼线/浮标；提竿仅 `rot` 抖动 ← **无抛竿/提竿帧动画**
5. 拉锯时整屏 `artShiftX` 微抖 ← **不是海浪，船也不会独立起伏**

## 根因分析

- **直接根因**：无钓鱼 clip/sheet；海与船烘焙在同一张 JPG；游鱼无透明度/水色染色/浪层遮罩。
- **根本原因**：钓鱼原画层只接了「座位 + 竿尖 UV」，没有像烤鱼店那样的 AnimDriver 片表驱动；海面未做程序化覆盖层。

## 方案设计（推荐：程序浪 + 片表兔 + 鱼溶水）

### A. 兔子抛竿 / 提竿（复用烤鱼店 GIF→8×256 sheet 管线）

| 产出 | 用途 | 触发相位 |
|------|------|----------|
| `rabbit_fish_cast.gif` + `_sheet.png` | 蓄力抛竿 | `charging`（按住抛竿～松开） |
| `rabbit_fish_reel.gif` + `_sheet.png` | 提竿/拉扯 | `bite` 起势 + `reeling`（按住收线时循环/加强） |

- 以现有 `hero_rabbit_fish.png` 为角色一致性参考，**透明底、只含兔+竿**（船仍用底板）
- 运行时：扩展 `AnimDriver` 或轻量 `FishingAnims`，`paintFishingRabbit` 改为读 sheet 帧；**竿尖 UV 按首帧标定，各帧保持竿尖大致同位**（或每帧表驱动 tip，优先固定 tip 降低复杂度）
- 待机 / waiting 仍用静帧；松开抛出瞬间可播完 cast 末段再进 waiting

```
旧: charging/reeling → 静帧 + rot
新: charging → cast sheet
    bite/reeling(+reelHeld) → reel sheet
    其余 → 静帧 hero_rabbit_fish
```

### B. 动态海浪 + 船随浪（最小、不重切整张海）

船与海在 JPG 里绑死，**本轮不做整海视频/重绘底板**。

| 手段 | 做法 | 成本 |
|------|------|------|
| 海浪覆盖层 | 在海域矩形上画半透明正弦波纹/泡沫带（多条相位差），随 `Date.now` 滚动 | 低 |
| 船感起伏 | 兔子座位 `seatY` + 鱼线浮标与浪同相位上下浮；可选极弱 `artShiftY`（仅钓鱼区 ±2～4px）让船舱相对感一起晃 | 低 |
| 真船切图 V2（可选） | 从底板抠小船独立精灵再 bob | 高，**本轮不做**，除非你确认要切图 |

预期观感：水在动、兔（与浮标）随浪点头；船壳略有连带感。若验收仍要「船体明显颠簸」，再开 V2 切船。

### C. 游鱼与海融合

```
旧: 场景 → 不透明游鱼 → 兔子
新: 场景 → 游鱼(降透明+海色染色+轻压扁) → 浪纹/泡沫盖一层 → 兔子/线/浮标
```

- `paintSwimFish`：alpha ≈ 0.55～0.7；乘海色 tint；`scaleY` 略压；Y 跟浪相位微浮
- 浅水区鱼上方再叠一条更淡的浪高光，做出「水盖在鱼上」
- 咬钩/出水鱼（`fishCaught` 跳出）保持更实、更高 alpha，与水下鱼区分

### 改动文件（确认后）

1. **生图**：抛竿/提竿 GIF → `docs/anim-preview/` + sheet → `res/Image/sprites/anim/`
2. **`shop-anims.js` 或新建 `fishing-anims.js`**：cast/reel clips
3. **`anim-driver.js` / `renderer.js`**：钓鱼相位播 sheet；海浪层；`paintSwimFish` 溶水
4. **`index.html`**：脚本与资源 `?v=` bump

不改钓鱼状态机相位名（仍用 `charging` / `reeling` 等），只换表现。

## 预期效果

- 按住抛竿：兔子有明显抛竿动作；松开后过渡到等待
- 咬钩/拉锯：有提竿拉扯动作，按住收线时更明显
- 海域持续有浪纹滚动；兔子（及浮标）随浪轻晃
- 水下鱼半透、染色、被浪盖住，不再像贴在海面上的另一层
