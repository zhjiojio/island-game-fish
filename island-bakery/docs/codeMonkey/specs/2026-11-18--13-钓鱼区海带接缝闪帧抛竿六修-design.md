# 钓鱼区：海带接缝 / 闪帧 / 抛竿六修

## 背景

验收图仍见：上下海硬切线、上深下浅反差过大、船兔周围闪帧、左上角浪层方块盖住沙滩栅栏、抛竿动画过快、拍岸缺白沫碎浪。

## 根因

| # | 现象 | 直接根因 |
|---|------|----------|
| 1 | 中间分割线 | swell/crash 矩形硬接，重叠羽化不够，交界无浪形过渡 |
| 2 | 上深下浅 | swell 片偏深蓝高不透明、crash 偏青绿，色差未做中间调色带 |
| 3 | 船兔闪帧 | 船/兔叠在高速交叉淡入的浪层上；浪双帧 alpha 在船体后跳动；船精灵边缘透明区透出浪闪 |
| 4 | 左上方块海 | 上带全宽矩形，盖住左岸沙滩/栅栏；无岸线 mask |
| 5 | 抛竿过快 | `rabbit_fish_cast` durationMs 偏短（约 800ms）且 charging 跟帧快 |
| 6 | 缺碎浪白沫 | crash sheet 拍岸端白沫弱，岸线未加碎浪点缀层 |

## 方案

```
约束：天空/远山静帧；只动海水。

1+2 接缝与颜色
  - 加大交界重叠（≥22% nearH）
  - 交界带用「浪形锯齿/多段水平条」渐变 alpha，不是直线羽化
  - swell 略提亮/降不透明；crash 略压暗，中间带混色更接近 seabase

3 闪帧
  - 船+兔绘制前，用 seabase 局部（或静止水色）在船体包围盒垫一层不闪底
  - 或：浪层在船体区域降低交叉幅度（船体后只用单帧/更高稳定 alpha）
  - 船兔仍跟同一 surfPhase，但浪交叉不要在船脚下剧烈变

4 左上不规则切割
  - land：左上多边形/多段梯形 mask——从沙滩栅栏岸线内缩，露出底板
  - 用若干 clip 矩形近似不规则岸线（或 stencil 多边形）
  - port 同步做左/岸侧切割

5 抛竿变慢
  - FishingAnims.rabbit_fish_cast.durationMs：800 → 1400~1600
  - collection cast_anim lockMs 同步加长
  - charging 跟帧不要 restart 刷爆

6 碎浪白沫
  - 近岸底缘加白色小浪花层（跟 surfPhase）：短弧/小点泡沫，沿沙滩线疏密变化
  - crash 底缘 alpha 略提高白沫可见度
```

### 改动文件

- `package/gameplay/render/renderer.js`（接缝、mask、闪帧垫底、碎浪）
- `package/gameplay/data/shop-anims.js`（cast duration）
- `package/gameplay/play/collection.js`（lockMs）
- `package/index.html`（?v=）

### 预期

1. 分割线变成有浪的自然过渡  
2. 上下海颜色接近，不再两块色板  
3. 船兔周围不闪  
4. 左上沙滩/栅栏露底板，海缘不规则  
5. 按住抛竿动作明显变慢  
6. 拍岸有白色碎浪花  

## 不做

- 物理流体
