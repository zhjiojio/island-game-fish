# 原画槽位接上顾客走动、翻烤和榨汁

## 背景

原画层已经把烤架、兔子、顾客脚底和成品桌锚点画出来了，但顾客是钉在槽位上的，烤架上的鱼和火仍相对旧底板，榨汁槽仍在调用矢量椰子和杯子。玩家看到的动作和槽位对不上。

## 调用链路

1. 店铺每帧先铺原画底板，再按槽位画烤架、兔子、顾客
2. 顾客队列里的 arrival / leaving 已经在推进 ← 原画层没读这段位移
3. 烤制状态 stoke / cooking / flip 已经在推进 ← 鱼和火仍相对旧烤架面
4. 敲椰子的 taps / hitTimer 已经在推进 ← 原画层仍画矢量椰子和杯子
5. 出餐飞行从旧烤制区飞向底部导航条上方 ← 应落到成品桌该鱼种的锚点

## 方案设计

不改队列、烤制阶段和点击热区，只改原画层怎么读这些状态。

1. 顾客：用现有 arrival、leaveTimer，从该槽右侧画面外滑到脚底锚点，离开时反向滑出；气泡底边挂在头锚点，跟着同一位移走；队列下一位仍占原来的槽
2. 翻烤：烤网中心是烤架精灵宽度 50%、自顶向下 28%；stoke 时火苗在烤架精灵下沿；cooking 时把当前鱼种的烤鱼成品图贴在烤网中心；flip 时这张图 scaleY 从 1 收到 0 再放到 1，横向仍用现有 flipSlide；兔子留在兔子槽，翻面时整只小幅旋转
3. 榨汁：crack 画青椰，点击抖动沿用 hitTimer；taps 满 3 次换成青椰榨汁图，插吸管继续用这张图；原画层不再调用矢量椰子和杯子
4. 出餐：烤鱼从烤网中心飞到成品桌对应鱼种锚点

## 预期效果

- 顾客从右侧滑入槽位，订单文字留在气泡内，人走气泡跟着走
- 翻面发生在烤架精灵上，兔子不离开兔子槽
- 成品落到延长桌上该鱼种的锚点
- 敲满三下后，榨汁槽的椰子换成带吸管的榨汁图
