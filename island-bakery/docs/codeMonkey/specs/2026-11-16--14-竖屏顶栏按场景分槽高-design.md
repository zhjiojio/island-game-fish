# 竖屏顶栏按场景分槽位（椰林偏左 / 烤鱼偏左下）

## 背景

钓鱼区顶栏字与图标已齐平后，椰林字仍偏左，烤鱼字偏左下。三套竖屏皮肤槽位水平锚点不同，烤鱼槽带还整体偏高；共用同一套 `cx` + `hudBarYPort` 无法同时对齐。

## 调用链路

1. 进入竖屏某区域 → 画对应 `ui-skin-*-port`（槽与图标在皮肤上）  
2. `drawHUD` → `drawHudMetric` 用全局竖屏 `cx` 与 `barY=22` 叠字  
3. 钓鱼槽心与当前 `cx` 一致 ← 已齐  
4. 椰林槽心整体偏右约 20～24px ← 字显得偏左  
5. 烤鱼槽心偏右约 10～15px，且槽带更高 ← 字显得偏左下  
6. [改] 按 `currentArea` 选用各自的竖屏 `cx` 与 `barY`

## 根因分析

### 直接根因

`hudSlotCenters`（算五个槽水平中心）与 `hudBarYPort` 不区分场景，椰林/烤鱼仍跟钓鱼同一套数。

### 根本原因

顶栏叠字按单套锚点表设计，皮肤分场景后未分开标定。

## 方案设计

**旧：**

```
drawHudMetric
  → cx = 共用 [0.319, 0.446, 0.575, 0.705, 0.829]
  → barY = 22（竖屏一律）
```

**新：**

```
drawHudMetric
  → [改] 按区域取竖屏参数（对照各皮肤浅槽实测）：
       fishing: cx 保持现网；barY=22
       coconut: cx ≈ [0.363, 0.491, 0.613, 0.742, 0.872]（整体右移）；barY=22
       shop:    cx ≈ [0.345, 0.475, 0.590, 0.732, 0.861]（略右移）；barY=19（上移约 3）
       其它竖屏: 同 fishing
  → 横屏 cx / barY 不动
```

改动文件：`renderer.js`（分场景槽表 + 日志带 area）；`index.html` 缓存版本号 +1。

## 预期效果

1. 竖屏钓鱼顶栏保持现状  
2. 竖屏椰林：字右移落入槽内，与图标水平对齐  
3. 竖屏烤鱼：字右移并上移，与图标齐平  
4. 横屏不变  

若某一区仍偏，只改该区 `cx` 或 `barY` ±1，互不影响。
