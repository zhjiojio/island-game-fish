# v1.1 七步钓鱼与专项流程升级设计

## 背景

玩家按 v1.1 准则选择浅滩、蚯蚓并等待咬钩时，当前原型没有这些入口，仍然直接进入蓄力收竿。现状只能覆盖旧版基础循环，不能宣称 FISH1～17、COCO1～6、SHOP1～9 已通过。

本轮以在线 Rubrics v1.1 为唯一验收准则，并结合刚读取的设计文档 v0.6 核对玩法。保留采集→制作→售卖→金币→升级、横屏 16:9、简体中文、双商品、体力和离线收益。

## 现状与差距

### 当前调用链路

1. 进入钓鱼区
   └── 按住任意位置蓄力 → 松开抛竿 → 短暂等待 → 按住收线 → 结算 ← 缺少七步流程
2. 进入椰林
   └── 点击椰树 → 接普通椰子 → 回合结算 ← 缺少金椰子与摔裂表现
3. 回店制作
   └── 连续添柴四次 → 翻面 → 装盘 ← 生火没有时机判定与完美火势
4. 加载中文
   └── 字图失败 → 整局无文字 ← 已复现的 P0 阻断

### 专项差距

- 钓鱼：FISH1、2、4～12、17 缺对应入口或机制；FISH3、13、14、16 只有相近旧逻辑，仍需按新流程重验。
- 鱼种：当前是沙丁鱼、青花鱼、金鲷鱼；v0.6 是小海鱼、三文鱼、金枪鱼、金色传说。FISH15 的三文鱼与重量转换必须按新版处理。
- 转换：当前是重量×2 后四舍五入；v0.6 与 FISH15 要求向上取整，小鱼保底两份。
- 椰林：普通接住与离开保留已有基础；COCO3～5 需要补齐摔裂、金椰子库存和金色边框。
- 烤鱼：基础制作、交付、缺货置灰已有；SHOP2～5 需要把生火改为时机操作，完美火势加速 20%，完美翻面改为「外焦里嫩」且售价×2。
- 字体：首次加载失败后不会重试，是需要最先修复的阻断问题。

## 修改边界与需要确认的范围

### 钓鱼七步流程

我准备把旧「蓄力后直接收线」改为「选点→观察气泡→选饵→抛竿→等待咬钩→提竿→拉锯战」。

影响规则：v1.1「修改钓鱼七步流程的任何一步必须先问人」。

风险：中。涉及钓鱼输入、状态、画面、引导和专项测试，但不改变核心经营循环。

### 广告复活与鱼种

FISH9 明确要求鱼跑后可广告复活，设计文档 v0.6 也明确列出该广告点。本轮只使用现有原型广告占位回调，不接真实 SDK、不增加其他广告点；提供「复活重钓」和「放弃」两个选择，不强制广告。

鱼种按 v0.6 换成小海鱼、三文鱼、金枪鱼、金色传说。首日浅滩默认只能稳定钓小海鱼；三文鱼需礁石或完美提竿，金枪鱼与金色传说按解锁条件保留入口，不提前放开高级区域。

重量转换统一改为「重量×2，向上取整，小鱼至少两份」，因此 3kg 三文鱼为 6 份。Rubrics 的 FISH15 写 5 份，与同一文档的 1kg≈2 份及设计文档 v0.6 的 2～4kg→4～6 份不一致，需要确认以哪一个为准；建议以可重复计算的向上取整规则为准，并将 FISH15 记录为文档例题错误。

## 方案设计

### 1. 先恢复文字

修改前：首次字图失败 → 永久跳过文字。

修改后：首次失败 → 间隔自动重试 → 成功后无需刷新恢复中文；持续失败不逐帧请求。

### 2. 七步钓鱼

1. [新增] 选择浅滩，高亮钓点并显示普通气泡；未解锁钓点明确置灰。
2. [新增] 观察气泡位置，作为抛竿落点参照。
3. [新增] 选择蚯蚓，高亮当前鱼饵。
4. [调整] 独立抛竿按钮按住蓄力，绿色 40～70 落入气泡中心；红色落点偏移并多等两秒。
5. [新增] 正常等待 3～5 秒，浮标下沉并播放咬钩反馈。
6. [新增] 独立提竿：太早只提示并可继续等；下沉超过一秒鱼跑，可选择广告复活或放弃。
7. [新增] 拉锯战：左侧松手放线、绿色按住收线、右侧强收增加张力，超红线断线；进度满后显示鱼种和重量。
8. 结算按重量向上取整转为鱼肉，连续三次状态独立；离开不消耗鱼饵并可重新开始。

保留既有体力规则：每次正式开始抛竿消耗一格，提前离开不重复扣；鱼饵首日选择不消耗库存。

### 3. 椰林补全

修改前：普通椰子接住或落地后直接消失。

修改后：普通/金椰子分别生成与入库；未接住的椰子播放摔裂动画；金椰子在背包显示金色边框；离开时只清理未落地动画，已接库存不丢。保留二十秒回合、三颗起手、每八秒加速和每日体力规则。

### 4. 生火与翻面

修改前：添柴四次 → 翻面 → 完美售价×1.5。

修改后：生火时机条 → 完美点击则后续烤制速度+20% → 翻面时机条 → 完美为「外焦里嫩」售价×2，错过为「一般」售价正常 → 自动摆盘交付。三次制作分别保存品质和售价，不串数据。

### 5. 重验与交付

按 P0→P1→P2 顺序修复；先完成专项，再回归 AC1～AC12、体验标准、字体故障恢复、存档、官方整包预检和 ZIP 完整性。每项保留真实结果，不把旧版通过记录沿用到 v1.1。

## 涉及文件

- `package/gameplay/play/collection.js`：钓鱼与椰林状态。
- `package/gameplay/play/input.js`：选点、选饵、抛竿、提竿、拉锯与离开输入。
- `package/gameplay/play/baking.js`：生火时机、烤制速度、品质和售价。
- `package/gameplay/data/recipes.js`：鱼种、重量与基础价格。
- `package/gameplay/core/game-state.js`：金椰子与新版存档兼容。
- `package/gameplay/core/game.js`：区域切换与必要状态衔接。
- `package/gameplay/render/renderer.js`：新流程画面、动画和字体恢复。
- `package/gameplay/render/font-atlas.js` 与字图：仅补充新增简体字。
- 必要的音效调用、验证记录、项目说明和交付目录同步。

不修改广告 SDK、横竖屏、核心循环、离线门槛和真实广告配置。

## 预期效果

- 玩家能按 v1.1 完整走完七步钓鱼，不再从蓄力直接跳到收线。
- 椰子和金椰子有明确反馈，离开不丢已接库存。
- 生火与翻面是两个清晰的时机操作，品质和售价符合专项。
- 字体偶发加载失败可自动恢复。
- FISH1～17、COCO1～6、SHOP1～9、AC1～12 全部有逐项新证据后才交付。
