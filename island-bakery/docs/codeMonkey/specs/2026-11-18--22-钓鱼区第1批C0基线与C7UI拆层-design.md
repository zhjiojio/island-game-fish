## 背景

上一轮动态海只做到「蒙版 + 全屏着色器能跑」，但顶部木条与底部地图/背包仍烤在 `seaflat` 里；收线时底板整体平移，烤进图的 UI 会在重画 HUD 下滑动。第 1 批先把「能不能测」和「UI 永远在最上层」两件事做完，不改波场、不洗蒙版、不动船兔/鱼群。

## 调用链路

```
1. 进入钓鱼区 draw()
2. paintScene(seaflat)          ← 当前含顶部木条 + 底部地图/背包
3. drawFishing → drawArtFishingMotion
4.   drawDynamicSea()           ← 海面可盖到 UI 区域
5.   鱼 / 礁石 / 船兔 / 鱼线
6. paintSharedHudChromePort()   ← 竖屏仅叠顶栏透明条
7. drawHUD / drawNav            ← 叠字与矢量兜底；热区仍读固定坐标
8. 弹窗 / 按钮
```

问题点：
- 步骤 2 的底板含 UI → 收线 `artShiftX` 时 UI 跟着晃（根因八）
- 步骤 4 的海面可能盖住烤进底板的 UI（F6 未满足）
- 无固定截图/断言 → 无法证明本批「像素应不变」

## 根因分析

**直接根因**
1. `ui-skin-fish-*-seaflat` 仍含顶部木条与底部地图/背包木质区。
2. `draw()` 在 `reeling` 时对整张 seaflat 施加 `artShiftX`。
3. 缺少 `?seaDebug` 与 `verify_fishing_sea.py`，无法产出可重复基线。

**根本原因**
UI 与场景底板共用一张图、同一位移通道，层序无法保证「功能区永远最上且静态」。

## 方案设计

### 新旧对比

```
旧：
  seaflat(含 UI) → 动态海 → 船兔 → 顶栏叠字/底栏叠字

新：
  seaflat(仅天空/山/沙滩，UI 区已补底) → 动态海 → 船兔
  → [新增] paintFishingUiChrome(ui-chrome) → HUD 叠字 / 弹窗
```

### C0｜验收基线（不改正式视觉）

1. `renderer.js` 增加只读调试（默认关闭）：
   - `?seaDebug=1`：冻结海面时间，可读 `&seaT=`
   - `?seaDebug=mask`：叠加蒙版边界、UI 矩形、船/鱼标记
   - `?ui=off`：隐藏 UI chrome（验收补底）
   - `?ui=baked`：回退「不画 chrome 层」（预案开关，本批先挂上）
2. 新建 `scripts/verify_fishing_sea.py`：
   - 固定 1280×720 / 720×1280
   - 4 组：横屏浅滩、竖屏浅滩、横屏深海、竖屏深海
   - `t0 / t0+800 / t0+1600` → 共 12 张图到 `docs/_sea-verify/`
   - 输出 JSON：UI 跨帧 diff、海域 diff、横向梯度峰值、鱼越界次数（本批可先占位 0）
3. 本批实施前后各跑一遍：`baseline/`（改前）与 `batch1/`（改后）

> 说明：若本机无法稳定起浏览器截图，至少完成「静态资产 diff + 调试参数接入 + 报告骨架」；浏览器 12 帧标「未实测」并给用户硬刷新验收步骤。禁止伪造截图。

### C7｜UI 拆独立透明层

1. 新建脚本 `scripts/split_fishing_ui_chrome.py`（或并入现有生成脚本）：
   - 源图：横屏 `ui-skin-fish-land.png`；竖屏优先一体皮/现有顶栏权威 `ui-hud-chrome-port` + 底栏木牌区
   - 输出：
     - `ui-chrome-land.png` / `ui-chrome-port.png`（透明底，仅顶栏+底栏功能区）
     - 同步改写 `ui-skin-fish-*-seaflat/deepflat`：UI 区域用邻域天空/沙滩/海水补底，禁止黑洞与旧 UI 残影
   - 输出调试图：`chrome-diff.png`、`seaflat-ui-fill-diff.png`
2. `renderer.js`：
   - 目录加载 `ui-chrome-land/port?v=1`
   - 新增 `paintFishingUiChrome()`：与 seaflat 同一 letterbox/aspect，在船兔之后、HUD 之前绘制
   - 钓鱼区收线：**取消对 seaflat 的 `artShiftX`**；位移只留给船/兔/鱼线等动态层
   - 热区继续用 `input.js` 现有 `navY=H-72` 坐标，不从图片反推
3. 缓存 bump：`renderer.js` → v88；seaflat/chrome 资源 `?v=11` / `?v=1`

### 本批明确不做

- 不改波场 shader（C3）
- 不洗蒙版 RGB（C2）
- 不统一 `seaMaskAt` 几何（C1）
- 不改船兔刚体 / 鱼群（C5/C6）
- 不改商店/椰林

## 预期效果

1. 顶部木条、底部地图/背包永远盖在动态海和船兔之上。
2. 收线时底图与 UI 不再左右滑动重影。
3. UI 隐藏时，原 UI 位置是自然天空/沙滩补底，无黑洞、无双层木牌。
4. 地图/背包点击位置不变。
5. 能产出（或明确标未实测的）12 张基线与 JSON 报告骨架。

## 验收（用户）

1. 硬刷新横屏钓鱼区：顶栏/底栏位置与拆前一致。
2. `?ui=off`：看不见木条与地图背包，下方是补底，无黑块。
3. 收线：底图与 UI 不晃。
4. 点地图/背包仍可用。
5. 竖屏同样验一遍顶栏与底栏。
