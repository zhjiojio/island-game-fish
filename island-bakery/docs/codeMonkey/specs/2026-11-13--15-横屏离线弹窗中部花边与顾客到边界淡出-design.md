# 横屏离线弹窗中部花边与顾客到边界淡出

## 背景

横屏「离线自动采集」弹窗标题与两块长框之间中部留空；弹窗打开时烤鱼店顾客/订单气泡会画出设计画布右边界。根因是中部槽未填字，且 `customerSlidePoint`（算顾客脚底滑动位置）用「画面宽 + 40」把人滑到画外且全程不透明。

## 调用链路

### 问题 1 · 离线解锁弹窗

1. 累计在线到门槛 → 游戏把「正在显示离线解锁弹窗」设为真
2. 每帧绘制若该状态为真 → 调用「画离线解锁弹窗」
3. 画共用结算壳（干净底图 + 顶部木牌标题「离线自动采集」）
4. 中部标题与长框之间的空白目前不画任何框 ← 问题点：中部空一块
5. 画两块长框原文 + 两个短按钮（热区仍读短框矩形）

### 问题 2 · 烤鱼店顾客离场 / 进场裁切

1. 交付成功 → 顾客进入离场，离场计时累加
2. 原画层画顾客时先算滑动脚底坐标 `customerSlidePoint`
3. 现公式：`跨度 = 画面宽 + 40 - 槽位x`，离场进度直接乘跨度 ← 问题点：脚底滑到画外仍不透明
4. 人与头顶气泡按该坐标整块绘制，无画布裁切 ← 问题点：进场在画外的一段、离场出界的一段都会画出来
5. 离场计时满约 1.1 秒后换新顾客入队

## 根因分析

- **直接根因（弹窗）**：离线解锁弹窗复用结算壳后，中部槽按旧设计「暂空」，标题与长框之间无说明框。
- **直接根因（离场）**：滑动终点故意设在「画面宽 + 40」，人带着气泡移出右边界；绘制层无透明度、无按设计画布裁切。
- **根本原因**：离场只做「平移出屏」，没有「到设计右边界后原地淡出」；精灵绘制未约束在设计坐标 `width×height`（横屏 960×540，竖屏同逻辑用当前设计宽高）内。

## 方案设计

### 问题 1 · 离线弹窗中部小花边框

**不改**：共用干净底图、顶部木牌、两块长框原文、两个短按钮文案与短框热区；不新做整张带字弹窗图。

**改**：仅在「画离线解锁弹窗」里，于标题木牌底边与第一块长框顶边之间的空白正中，用现有**长框贴图缩小**摆一块小花边框（与厨房缺鱼弹窗把鱼图标摆在中部空白同思路）。

- 框内文案：`离线看广告实现自动采集食材`
- 字在框内水平垂直居中；颜色深棕（沿用厨房缺鱼标题墨色一类，非纯黑）
- 字过长时略降字号以落在框内
- **尺寸迭代（2026-11-13）**：中部花边框加宽至约长框 98% 宽、高度约长框 1.65 倍（并受标题～长框间隙限制）；基准字号 18（下限 14），框与字同步放大

### 问题 2 · 到边界再淡出 + 画布内裁切

**只改烤鱼店顾客离场/进场绘制与滑动计算**（`customerSlidePoint` + 原画层画人/气泡；必要时离场总时长与淡出对齐）。竖屏与横屏同一套规则，终点用当前设计画面宽度，不写死 960。

#### 旧流程

1. 离场进度 0→1 → 脚底 = 槽位 + (画面宽+40−槽位) × 进度
2. 人与气泡全程不透明画在该坐标（可画出右边界）
3. 计时满 → 出队换人

#### 新流程

1. 离场时人还在画面内 → 照常向右走
2. [新增] 脚底到达设计右边界（`x = 当前设计画面宽`）后**不再继续往外移**，钉在右边界
3. [新增] 从钉住起，人 + 头顶气泡一起按透明度淡出，直到看不见
4. [新增] 完全看不见后再从队列去掉并换新顾客（淡出结束与出队对齐）
5. 进场仍从右侧边界外走进槽位
6. [新增] 画人/气泡时按设计画布矩形裁切：未进入画面的那一段不画；弹窗打开时也不会在画布外再露一截

透明度走现有顶点色 alpha（着色器已支持贴图 alpha × 顶点 alpha），不强行上 DOM。

### 修改范围

- `island-bakery/package/gameplay/render/renderer.js`：离线解锁弹窗中部小框；`customerSlidePoint` 到边界钉住 + alpha；画顾客/气泡支持 alpha 与画布裁切
- `island-bakery/package/gameplay/play/selling.js`：仅当出队时长需与「走到边界 + 淡出」对齐时微调离场总时长阈值
- 本设计文档

不改：短框热区逻辑、长框两句原文、其它结算弹窗、进场方向（仍从右侧）、槽位坐标表。

## 预期效果

1. 横屏打开「离线自动采集」：顶牌标题不变；中部小花边框有深棕说明句；下方两长框、两短按钮与热区不变。
2. 该弹窗打开时，烤鱼店顾客与订单气泡不会画到设计画面外。
3. 顾客离场：画面内向右走 → 脚底到右边界停下 → 人与气泡淡出 → 消失后再换人；竖屏同一规则。
4. 进场：仍从右侧外走进槽位，画外部分不绘制。
