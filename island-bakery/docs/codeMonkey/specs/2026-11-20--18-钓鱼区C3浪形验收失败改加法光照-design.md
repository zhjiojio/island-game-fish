## 背景

R0016 按「乘性 shade + 暗谷/亮坡」加强体积后，你反馈：**没有浪形，又渐变闪**。

## 根因

**直接根因**  
海水底色本身是「远深蓝 → 近青绿」竖向渐变。R0016 用 `col = m.rgb * (1 + 0.2*h)`，而 `h` 又主要随 `v_uv.y` 起伏。结果是整条深浅渐变在呼吸，读成「渐变闪」，读不成一垄一垄的浪。

**根本原因**  
在强竖向色阶上做**乘性**明暗，等于拿浪去拧渐变；体积感被渐变脉冲盖掉。

亮线方案（R0015）至少能看见动，但没有形体；体积乘性方案（R0016）形体被渐变闪吃掉。两条路都没碰到「浪形」。

## 方案（仍只改 C3 一个变量：光照合成方式）

```
旧 R0016：col = 底色 × (1 + k·h)     ← 拧渐变 → 闪
新：
  底色几乎原样保留（渐变不再被放大）
  浪高 h 改为「加法/减法」叠在表面：底色 ± 固定幅度的冷暗/暖亮
  再用浪高的左右差做一点假法线坡面光（亮坡/暗背）
  crest 仍只作弱辅助
  泡沫代码本轮仍不动
```

预期：

1. 深浅渐变本身稳住，不再整片闪  
2. 海面上能看出随浪推进的明暗垄（浪形）  
3. 不是细亮线，也不是色带左右扫
