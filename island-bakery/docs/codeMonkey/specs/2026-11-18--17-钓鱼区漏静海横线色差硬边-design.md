# 钓鱼区：漏静海 / 横线 / 色差 / 左缘硬边（R0003）

## 背景

R0002 验收未过：左缘像素硬切；静海底板仍从动画层下透出；动起来有横线；上深蓝下青绿色块分明。红框水域仍是静底板。

## 调用链路

1. 画 seabase（含静态海水）  
2. `drawFishingUnifiedSea` ← 问题点  
   - 32 条细条 + 薄片 UV → 横线  
   - alpha≈0.9 半透明 → 静海透出  
   - `fishingSeaDrawSpans` 硬切 x → 左缘锯齿  
3. 船兔 / UI

## 根因

- 直接：细条薄片 UV + 半透明叠静海 + 左缘硬切。  
- 根本：用「半透明条带盖静海」掩盖底板，而不是先不透明盖住再画浪。

## 方案

1. 海区先铺不透明青绿底（盖死静海）。  
2. 弃薄片细条：两大层 swell/crash，连续 UV，中段软混，统一 tint。  
3. 左岸只微收 + 水平羽化，去掉逐条锯齿。  
4. 仍 clip 在画布内；UI 后画。

## 预期

无漏静海、无横线、色差自然、左缘丝滑；红框为动态海。
