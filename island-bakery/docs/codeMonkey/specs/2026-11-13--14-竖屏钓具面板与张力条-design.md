# 竖屏钓具入口上移与张力条配色

## 背景

横屏钓鱼已经把钓具收到左下「地图」木牌上方，展开后是两行木牌。竖屏仍在右上角画「钓具 / 收起钓具」，拉锯时的张力条仍用浅蜂蜜色填充，没有先画深棕底槽。

## 调用链路

1. 进入钓鱼且处于待机 → 画面绘制竖屏钓具（`drawFishingGear` 的竖屏分支）
2. 点击左下入口 → 展开或收回面板
3. 点击木牌 → 已解锁就换钓点或鱼饵；未解锁只提示
4. 点击面板和「收回」以外 → 面板收起
5. 进入拉锯 → 先画张力底槽，再按张力填色

## 方案设计

竖屏单独用一套布局，横屏入口、三列木牌和抛竿按钮的坐标保持原样。

1. 入口贴在「地图」木牌正上方，宽度与横屏入口相同。竖屏待机和蓄力的「按住抛竿」右移到入口旁边，避免挡住这句话
2. 收起时写「选取钓鱼区和鱼饵」，展开后入口改成「收回」，正上方写「当前：钓点 鱼饵」
3. 面板向上展开，两行沿用现有木牌：浅滩·木竿 / 礁石·铁竿 / 深海·金竿，蚯蚓 / 虾米 / 秘制
4. 未解锁木牌去饱和；点击仍走原来的提示：礁石要铁竿，深海要金竿，虾米要完成 10 次钓鱼，秘制要 5 级
5. 竖屏张力条先画深棕底槽，再用深橙填充，超过 0.8 改红色。位置和长度不变

## 预期效果

- 竖屏待机时，左下地图木牌上方出现钓具入口，右上角不再有「钓具」
- 展开后能看到当前钓点和鱼饵，以及两行木牌；点空白处收起
- 拉锯时张力条是深棕槽加深橙，快断线时变红
- 横屏按钮位置与改前一致
