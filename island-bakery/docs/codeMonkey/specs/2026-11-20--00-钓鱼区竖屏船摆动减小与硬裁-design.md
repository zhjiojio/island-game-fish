# 竖屏船：减小摆动 + 画布硬裁（修角露沙/探底）

> 状态：用户授权「摆动小一点」后实施（待验收）  
> 轮次：R0010 补丁8  
> 横屏：bob 幅度/旋转不改

## 背景

补丁7「先裁后转」仍无法约束旋转后的左右下角：左下/右下会探出屏底；右上抬时仍露沙。用户同意可减小摆动。

## 根因

轴对齐裁剪在旋转后失效；微转使底角相对脚点上下偏约 ±半宽·sin(rot)。

## 方案

```
1. [改·仅竖屏] fishingSurfMotion：amp 8→3；bobRot 约降为 1/4
2. [改·仅竖屏船兔绘制] 开启 WebGL scissor 裁到设计画布 540×960
   → 任何探出底边的像素硬裁掉（含旋转角）
3. 保持脚点 y=1000、clipToCanvas；横屏不动
4. renderer ?v=102；日志 patch8
```

## 预期

- 下晃：左右下角不探出沙滩底边  
- 上晃：右下角不露沙缝（摆动幅度已缩小）  
- 船仍有轻微晃动

## 验收

硬刷新竖屏看数秒；下不探底、上不露沙；地图/背包可点；横屏无变化。
