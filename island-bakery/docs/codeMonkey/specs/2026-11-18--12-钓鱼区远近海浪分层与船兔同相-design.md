# 钓鱼区：远海缓涌 + 近岸冲击浪 + 船兔同相

## 背景

横屏验收截图上：浪帧硬切一卡一卡；上半海面像静图、下半才有冲击浪，中间一道缝；船和兔各自用独立 `sin` 晃，不像坐在浪上。根因是「整片海只盖一张冲击浪 sheet + 船兔另开频率」。

## 调用链路（现状）

```
1. 画 seabase 底板（上半远海静止露出）
2. drawFishingSeaWaveSheet：整片海域盖同一张 8 帧冲击浪 ← 硬切帧；上半仍露静底板/与浪图接缝
3. 游鱼
4. 船：waveY = sin(phase)*7 ← 独立频率
5. 兔：同一 waveY，但视觉上像另一层在晃
```

## 根因分析

- **直接根因**
  1. 帧用 `Math.floor` 硬切 8 格，无帧间过渡 → 卡顿
  2. 只叠一层「近岸冲击」sheet，且盖不全/风格与远海底板接不上 → 上静下动割裂
  3. 船/兔 bob 是程序 `sin`，不跟浪帧相位采样 → 像自己在抖
- **根本原因**：把「远海涌动」和「近岸拍岸」当成同一层资源；「坐在浪上」没做成同一变换父节点。

## 方案设计

按截图红框拆成两带，共用一个 `surfPhase`：

```
1. seabase / deepbase
2. [新增] 上带远海缓涌（红框上）
   - 浅海：对底板海域 UV 做缓慢水平/微垂偏移 + 极淡双帧交叉（或复用 deep 浪 sheet 上半 UV）
   - 深海：整片用深海浪 sheet 双帧交叉（本就无岸）
3. [改] 下带近岸冲击浪（红框下）
   - 只画下半海域；8 帧双帧交叉淡入淡出，去硬切
   - 与上带交界 8%~12% 高度半透明羽化，消接缝
4. 游鱼（可带一点同相 bob）
5. [改] 船+兔同一 surfBob
   - bobY / 微倾从 surfPhase 采样（跟近岸浪同一相位、同一周期）
   - 兔座位 = 船甲板槽位 + 固定相对偏移，不再各算各的
6. 鱼线/浮标：浮标跟浪相位，幅度略小于船
```

### 卡顿怎么消

- 帧进度 `t ∈ [0,8)`，画 `floor(t)` 与 `ceil(t)` 两帧，alpha 按小数交叉
- 周期拉到约 2.4~3.2s 一圈（约 12~15fps 等效），交叉后观感连续

### 船兔同相 + 与浪同频（已确认）

- **唯一时钟** `surfPhase`：同时驱动上带缓涌、下带冲击帧进度、船、兔
- `surfBobY / surfBobRot` 从同一 `surfPhase` 采样（可加二次谐波，但仍是该相位的函数），禁止船另开周期
- 横屏/竖屏：兔座位 = 船甲板槽 + 固定相对偏移；船兔一体变换
- 验收：浪峰抬起时船兔一起抬，浪落一起落；肉眼同一频率

### 资源

- **本轮优先代码分层**：上带缓涌用底板 UV 微动 + 下带现有 shallow sheet 裁下半；不强制新出图
- 若上带仍嫌弱：再补 `sea_swell_*_sheet`（远海缓涌 8 帧）
