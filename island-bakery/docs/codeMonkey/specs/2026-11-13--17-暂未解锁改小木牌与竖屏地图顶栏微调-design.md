# 暂未解锁改小木牌 + 竖屏地图同改 + 竖屏顶栏微调

## 背景

横屏点未解锁区域后弹出整张结算大底板，中间大片空白，短按钮「知道了」还被裁成半个字；玩家希望改成小木牌提示。竖屏地图同样要能点带锁区弹出同一套提示；竖屏顶栏字偏大，需略缩小并整体稍右移。

## 调用链路

### 1 · 未解锁提示形态

1. 点带锁区 → `mapLockedPrompt = true`  
2. 现：`drawMapLockedPrompt` 画整张结算壳 + 短按钮 ← 问题点（太大、太空、按钮裁字）  
3. [改] 只画居中小木牌（复用 `dialog-settlement-title`）+ 文案「暂未解锁」；轻蒙层；点任意处关闭（不再单独短按钮）

### 2 · 竖屏地图

1. 竖屏点地图 → `hitPortrait`  
2. 现：只认钓鱼 / 椰林 / 已建店 / 离线；未建店与底段带锁区无反馈 ← 问题点  
3. [新增] 未建烤鱼店 → `locked`；底段菜园 / 面包房 / 仓库热区 → `locked`；弹同一小木牌

### 3 · 竖屏顶栏

1. `drawHUD` 竖屏字号 14、`cx` 已按槽心  
2. [改] 竖屏字号再小一档；五个 `cx` 整体略右移；横屏与「孤岛烤鱼店」不动

## 根因分析

- **直接根因**：未解锁提示误复用结算大壳；竖屏 `hitPortrait` 未接带锁区；顶栏竖屏字号/水平位置未按「图标在左、字在右」再收一档。  
- **根本原因**：短提示与完整结算共用同一套壳，缺少「一句提示」的轻量形态。

## 方案设计

### 小木牌提示（横竖屏共用）

**旧：** 蒙层 + 结算底图 + 顶牌标题 + 短按钮「知道了」  
**新：** 轻蒙层 + 居中小木牌（`dialog-settlement-title`，约宽 280～320）+ 居中「暂未解锁」；点击任意处关闭

改：`renderer.drawMapLockedPrompt`、`input` 关闭逻辑（任意点关闭，不再找短框）。

### 竖屏地图热区（设计 540×960）

| 区域 | x,y,w,h | 说明 |
|------|---------|------|
| 菜园 | 50,560,160×140 | 带锁路牌 |
| 面包房 | 250,620,130×130 | 带锁路牌 |
| 仓库 | 380,600,140×140 | 带锁路牌 |
| 烤鱼店未建 | 复用 shop 矩形 | 返回 locked |

钓鱼 / 椰林 / 已建店 / 离线不变。横屏带锁热区沿用上一版。

改：`map-zones.js` 的 `port` + `hitPortrait`。

### 竖屏顶栏

- 字号：`14` → `12`  
- `cx`：在现有 `0.299/0.426/0.555/0.685/0.809` 上整体 `+0.02` → `0.319/0.446/0.575/0.705/0.829`  
- 垂直参数与横屏槽位不动

改：仅 `renderer.js` 的竖屏 `hudSlotCenters` 与 `drawHUD` 竖屏字号。

## 预期效果

1. 横/竖屏点未解锁区：屏幕中央出现小木牌「暂未解锁」，不出现大结算空壳；点一下即关。  
2. 竖屏点菜园 / 面包房 / 仓库 / 未建烤鱼店同样弹出；已解锁入口行为不变。  
3. 竖屏顶栏五槽文字更小、略偏右，更易落在图标右侧空位内。
