# 竖屏船：下晃裁掉溢出、上晃不露沙

> 状态：已确认并实施（待用户验收）  
> 轮次：R0010 补丁7  
> 横屏：禁止修改船脚点/船图；裁剪逻辑对「先裁后转」做通用小修，顾客等已有 clip 路径受益

## 背景

补丁6 只把脚点下移到 972。用户反馈：  
1. **往下晃**时船底会越过沙滩底边（设计画布底 y=960），多出来的部分应消失；  
2. **往上晃**到最高点仍会露出一点点底部沙滩。

## 调用链路

```
1. fishingSurfMotion → bobY（约 ±8.5）+ bobRot（微旋转）
2. boatY = foot.y + bobY
3. paintFishingBoatSprite → paintFootSprite(..., rot)
4. paintTexturedQuad：仅当 clipToCanvas 且无旋转时才裁画布
   ← 问题：船有 bobRot，裁剪被跳过；下晃溢出仍画出画外/盖错层
5. 上晃：脚点余量不足 → 船底离开 y=960 → 露沙滩
```

## 根因

- **直接（下晃）**：船启用了微旋转，现有 `clipToCanvas && !rot` 导致底边裁剪从不生效。  
- **直接（上晃）**：脚点 + 上抬峰值后，船底仍会短时高于画布底，露出底板沙。  
- **根本**：晃动应「可贴出屏底但画出时裁掉」；静帧脚点须按 `bobY` 峰值预留，而不是只靠一次性下移猜。

## 方案

```
旧：
  脚点 y=972；船绘制不裁；有 rot 时无法裁底

新：
  1. [改·通用小修] paintTexturedQuad：clipToCanvas 时改为「先按画布裁 UV/矩形，再旋转」
     （去掉 !rot 限制；微旋转下底边溢出可裁）
  2. [改·仅竖屏船] paintFishingBoatSprite：portrait 时 clipToCanvas=true
  3. [改·仅竖屏脚点] y: 972 → 980
     （上抬约 8.5 + 底边微转抬角约 11 的余量，最高点仍压住屏底）
  4. 兔相对偏移不变（随船一体）；日志标 patch7；renderer ?v=100

不改：
  - bob 幅度公式本身
  - 船精灵图 / seaflat / 横屏脚点
```

### 预期行为（对应你的描述）

| 动作 | 效果 |
|------|------|
| 船往下晃，底边越过沙滩底（画布底） | 越过部分被裁掉，不再画出来 |
| 船往上晃到最高点 | 船底仍贴住/压住画布底，不闪沙滩缝 |

## 影响与回滚

- 影响：竖屏船观感；所有 `clipToCanvas + 小旋转` 的绘制改为先裁后转（顾客进离场若带 rot，裁切会真正生效，属同向修复）。  
- 回滚：还原三处改动与版本号。

## 验收

1. 硬刷新竖屏，看船连续晃动数秒。  
2. 下晃：屏底外无船木纹「探出」。  
3. 上晃：船底与屏底之间无周期性沙滩缝。  
4. 兔仍在甲板；地图/背包可点；横屏快速对比无差别。
