# 新人引导改为地图起手与分区解锁

> 本文只做方案设计，不包含代码实施。文末「已确认决策」记录 2026-11-22 18:47 用户拍板结果。

## 一、背景

新玩家首次进入游戏时直接落在钓鱼区，椰林区与烤鱼店只是地图上用灰色方块盖住的占位，既看不懂「为什么不能去」，也不知道「下一步该去哪」。整个首日闭环缺少一条连续的引导线：

先行现状：新存档先钓鱼 → 钓满 3 条才提示去椰林 → 椰林结算里点「搭建烤鱼店」直接建房 → 首次烤鱼后无收尾提示。

本次要改成：**先看地图建立世界认知 → 去钓鱼 → 第一条鱼解锁椰林 → 第一轮椰子解锁烤鱼店 → 首次烤鱼完成，引导结束**，全程每一步只有一个红色闪烁箭头指向当前目标。

## 二、现状与问题

### 2.1 当前链路

1. 启动 → `Game.init` 按存档决定落点  
   无进度时直接进入钓鱼区 ← 问题点（玩家还没理解地图就进入复杂七步钓鱼）
2. 地图椰林区/烤鱼店  
   用半透明灰色方块压暗 ← 问题点（像素材缺失，和其余带锁路牌不一致）
3. 椰林区点击  
   `navigate("coconut")` 在未钓到鱼时拦截并 toast「先完成钓鱼」← 问题点（只有文字，没有位置指引）
4. 钓到第 3 条鱼  
   `drawFishResult` 才出现「三条鱼已备好 去地图选椰林」← 问题点（门槛高、跳出突兀）
5. 椰子首轮结算  
   「搭建烤鱼店」按钮直接进入建房，不经过地图 ← 问题点（没有形成「地图解锁区域」的认知）
6. 首次烤鱼完成  
   只有成品提示，没有新手结束反馈 ← 问题点（缺少收尾仪式感）
7. 全游戏弹窗字色  
   多数用 `C.ink`（约 `#3D3026`），与引导图里的深棕字不一致；字体使用统一字帖 ← 问题点（视觉不统一）

## 三、产品思路与优化点

### 3.1 设计原则

- **一步一目标**：任何时刻只有一个红色闪烁箭头，玩家不需要做路线决策。
- **先地图后玩法**：第一屏让玩家看到「岛上有哪些区域、哪些还没开」，再进入具体玩法。
- **用状态表达进度**：锁 = 未解锁，锁消失 = 已解锁，灰块不再出现。
- **单局可跳过、跨局不重播**：引导进度落存档；老玩家和已完成玩家完全走原链路。
- **不打断既有玩法**：教程只加在关键节点，完成第一条鱼/第一轮椰子/第一次烤鱼，不新增额外操作步骤。

### 3.2 对玩家体验的优化

1. 首屏从「钓鱼教学」变为「岛屿地图」，降低第一眼信息量。
2. 第一条鱼就解锁椰林（原为 3 条），把首个闭环从约 5 分钟压到 1～2 分钟。
3. 椰林和烤鱼店改用与森林/仓库一致的锁牌，不再有灰色脏块。
4. 每次解锁都用「锁消失 + 红色闪烁箭头」表达，玩家能直接看到变化。
5. 首轮椰子结束给「去烤鱼店 / 留在椰子林」二选一，尊重玩家想继续采集的节奏。
6. 选择去烤鱼店后自动回地图并指向店铺，点击即开始搭建，不要求玩家自己找入口。
7. 首次烤鱼完成弹出结束弹窗，明确「教程结束、正式经营开始」。

## 四、目标链路

```
新存档启动
  └─ 地图（首屏）
       ├─ [弹窗] 引导弹窗.png + 按钮「去钓鱼」
       │    └─ 点击 → 关闭弹窗，地图钓鱼区右上角红色箭头闪烁
       ├─ 点击钓鱼区 → 箭头消失 → 进入钓鱼
       │    └─ 钓到第一条鱼 → 鱼获结算
       │         └─ 点「收进鱼篓」→ [弹窗] 椰子林引导弹窗.png + 按钮「去椰子林」
       ├─ [弹窗] 点「去椰子林」→ 回地图，椰林锁消失，椰林右上角红色箭头闪烁
       ├─ 点击椰林 → 箭头消失 → 进入椰林
       │    └─ 完成第一轮采集 → 结算弹窗
       │         ├─ 点「去烤鱼店」→ 回地图，烤鱼店锁消失，店右上角红色箭头闪烁
       │         │    └─ 点击烤鱼店 → 箭头消失 → 直接进入搭建
       │         └─ 点「留在椰子林」→ 再采一轮（烤鱼店保持锁定，后续轮次仍可去）
       ├─ 搭建完成 → 进入烤鱼店
       │    └─ 完成第一次烤鱼 → [弹窗] 新人引导结束弹窗.png
       │         └─ 关闭 → 引导完成，后续完全沿用现有链路
       └─ 老玩家 / 引导已完成 → 直接沿用现有落点与流程
```

## 五、方案设计

### 5.1 引导状态机（唯一真相）

新增 `AIGCUtils.Onboarding`，状态写入存档 `GameState.onboarding`：

```
stage:
  "intro"       首屏地图 + 引导弹窗
  "mapFishing"  已点「去钓鱼」，地图箭头指向钓鱼区
  "coconutGuide" 第一条鱼结算后，等待点「去椰子林」
  "mapCoconut"  已点「去椰子林」，地图箭头指向椰林
  "coconutRound" 首轮椰林中 / 等待结算
  "mapShop"     已选「去烤鱼店」，地图箭头指向店铺
  "shopBuild"   已点店铺，正在搭建
  "grill"       店铺建好，等待第一次烤鱼
  "done"        引导结束
```

- 新存档：`{ done: false, stage: "intro" }`
- 旧存档兼容：读档时若缺少 `onboarding`，且已有 `fishCaught > 0` 或 `shopBuilt` 或 `stats.totalBaked > 0`，直接视为 `done`，不重播引导；完全零进度旧存档仍走新引导。
- 每个 stage 只在触发时写一次存档，避免重复弹窗。

### 5.2 首屏落点

`Game.init` 现状按进度选择 `currentArea`。改为：

- `onboarding.stage === "intro"` → `currentArea = "map"`，同时打开引导弹窗。
- 其他老逻辑不变（已建店进店、已备料进椰林、已钓鱼进椰林、否则钓鱼）。

### 5.3 地图锁与解锁

#### 视觉

- 删除现在压在椰林/烤鱼店上的半透明灰色矩形（`drawMap` 里的两处 `rect(..., [0.35, 0.32, 0.28, 0.45])`）。
- 新增 `drawMapPadlock(x, y, size)`：用圆角锁体 + 锁梁的画法，尺寸和位置对齐地图里已烤死的锁（路牌右上角），保证「和其余未解锁区域一样」。
- 锁定条件：
  - 椰林：`!GameState.tasks.fish`（第一条鱼后自动解除）
  - 烤鱼店：`!GameState.shopBuilt && onboarding.stage !== "mapShop" && onboarding.stage !== "shopBuild" && onboarding.stage !== "grill"`
- 点击已锁定区域仍走现有 `mapLockedPrompt`，文案沿用（椰林为「先完成钓鱼」类引导）。

#### 热区

- `MapZones.hitLandscape/hitPortrait`：椰林/烤鱼店在「教程已解锁」时返回可点击 key，不再返回 `locked_*`。
- `Game.navigate("coconut")` 的 `!tasks.fish` 拦截保留；完成第一条鱼后 `tasks.fish` 已为 true，无需额外分支。
- 烤鱼店教程态点击不走 `navigate("shop")`，而是直接 `Game.beginBuild()`；`beginBuild` 既有「鱼肉 + 椰子齐备」校验作为兜底。

### 5.4 红色闪烁箭头

新增 `Renderer.drawMapGuideArrow(zoneRect)`：

- 位置：目标路牌右上角外侧，锚点 `x + w - 8, y + 2`，不遮住路牌文字。
- 形态：红色实心箭头（向下/向右指向路牌），用 `C.red` 的亮色版本。
- 闪烁：`alpha = 0.45 + 0.55 * (0.5 + 0.5 * sin(now / 260))`，约 1.6 秒一个周期。
- 数据来源：`Onboarding.arrowZone`（`"fishing" | "coconut" | "shop" | null`），绘制在 `drawMap` 之后。
- 消失时机：点击对应区域时先清空 `arrowZone` 再导航，确保首帧即消失。

### 5.5 引导弹窗

新增 `Renderer.drawOnboardingDialog()`，统一弹窗绘制：

1. 全屏轻蒙层（复用 `C.overlay`）。
2. 按 `getSettlementLayout` 的宽高比例绘制引导图。引导图比例 1471×1069 ≈ 现有弹窗底图 1626×1182，可复用同一套 `dlgW/dlgH`。
3. 三种弹窗：
   - `intro`：`引导弹窗.png`，下方空白处画按钮 `按钮.png` + 文字「去钓鱼」。
   - `coconutGuide`：`椰子林引导弹窗.png`，下方空白处画按钮 + 文字「去椰子林」。
   - `end`：`新人引导结束弹窗.png`，**不画按钮**，点击任意处关闭；底部需显示一行提示文字「点击任意处关闭」，颜色与所有弹窗文字一致（`#5E3314`）。
4. 按钮尺寸：宽约弹窗宽的 40%，高按 `按钮.png` 的 2016:864 比例；纵向放在图内文字下方空白区（约弹窗高度 70%～92%）。
5. 按钮文字用统一字帖绘制，颜色 `#5E3314`，居中；不把文字烤进按钮图。
6. 输入优先级：引导弹窗高于地图点击和所有旧弹窗，弹窗打开时只响应按钮热区，避免误触穿透。

### 5.7 旧「三条鱼去椰林」逻辑

- 保留代码不删，但触发条件加上 `onboarding.done`。
- 新玩家第一条鱼后 `tasks.fish=true`，从 `fishResult` 进入椰林引导；不会再出现「三条鱼」提示。
- 已完成引导的玩家不会再看到旧提示，避免与正式链路重复。

### 5.8 弹窗字色与字体统一

- 新增语义色 `C.dialogInk = [94/255, 51/255, 20/255, 1]`（约 `#5E3314`）。
- 以下弹窗文字全部改用 `C.dialogInk`：

  - `paintSettlementLongs` / `paintSettlementShorts`（正文、按钮）

  - 新手引导三弹窗按钮文字
- `paintLabeledUiFrame` 的默认墨色同步改为 `C.dialogInk`，避免漏改。
- 字体：继续使用现有 `ui-font-atlas` 字帖。**无法做到与引导图里的手写体完全一致**；如需一致，需要字体文件并重新生成字帖（新增字也必须回填字帖）。用户已确认接受该限制，本轮不处理字体文件。

## 七、预期效果

1. **首次进入**：先看到地图，弹窗出现兔子木牌与「去钓鱼」，不会直接落入钓鱼界面。
2. **钓鱼引导**：点击去钓鱼后，地图钓鱼区右上角红色箭头闪烁；点击钓鱼区后箭头消失。
3. **第一条鱼**：结算后出现椰林引导图，点「去椰子林」回地图；椰林锁变成无锁，右上角红箭头闪烁。
4. **首轮椰子**：结算出现「去烤鱼店 / 留在椰子林」。选去烤鱼店 → 回地图，店锁消失，红箭头指向店铺；点店直接开始搭建。
5. **首次烤鱼**：搭建完成、烤完第一条鱼后，出现「新人引导结束」弹窗，底部有「点击任意处关闭」提示；点击任意处关闭后不再出现任何新手引导。
6. **老玩家**：进度已存在时直接走原链路，不受新引导影响。
7. **视觉统一**：所有弹窗文字统一为 `#5E3314`；字体沿用统一字帖（手写体需补字体文件才能完全一致）。

## 八、验收清单

1. 清空存档进入：首屏必须是地图，且引导弹窗正常显示，按钮可点。
2. 点「去钓鱼」：弹窗关闭；地图钓鱼区右上角红箭头闪烁；点钓鱼区后箭头消失并进入钓鱼。
3. 钓到第一条鱼，点「收进鱼篓」：出现椰林引导图；点「去椰子林」回地图，椰林锁消失并出现红箭头。
4. 点椰林进入并完成第一轮：结算出现「去烤鱼店 / 留在椰子林」。
5. 选「留在椰子林」：直接开始下一轮，店铺仍为锁；下一轮结算仍可去店铺。
6. 选「去烤鱼店」：回地图，店锁消失、红箭头闪烁；点店后箭头消失并进入搭建。
7. 搭建完成进入店铺，完成第一次烤鱼：出现结束弹窗，且能看到「点击任意处关闭」提示；点击任意处关闭后不再出现引导。
8. 退出重进：已完成的引导步骤不重播；老存档不触发新引导。
