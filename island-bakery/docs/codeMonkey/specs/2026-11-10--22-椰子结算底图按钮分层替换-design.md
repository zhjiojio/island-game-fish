# 椰子结算底图与按钮分层替换

## 背景

椰子区结算弹窗原先用「底图+按钮一体」的 `dialog-coconut-summary.png`（与旧 `dialog-inventory.png` 同源），程序再往图上写字，文字对不齐画在图里的框。现已拆成干净底图、顶部木牌、长框、短框四类素材，需要运行时分层叠放并居中填字。

## 调用链路

1. 椰林回合结束 → `Collection` 进入 `coconutSummary`
2. 每帧 `Renderer.drawCoconutSummary`（画结算弹窗）
   1. 拉伸整张一体底图 ← 问题点：框在图里，字在代码坐标上
   2. 直接 `text` / `button`（木牌通用按钮）画文案与热区外观
3. 点击 → `input.js` 用写死的 `hw/hh` 矩形命中建店/再采

## 根因分析

- **直接根因**：结算文案与点击热区按屏幕中心偏移硬编码，与一体底图里烤死的框位置不是同一套布局。
- **根本原因**：可交互框没有独立素材与共享布局函数，绘制与命中各算各的。

## 方案设计

旧流程：

1. 画一体底图
2. 裸文字 + 通用木按钮

新流程：

1. 同步素材到 `assets/ui` 与 `package/res/Image/ui`
2. `uiAssetCatalog` 注册干净底图 / 木牌 / 长框 / 短框
3. [新增] `getCoconutSummaryLayout`（统一算底图与四框矩形，绘制与点击共用）
4. [新增] `paintLabeledUiFrame`（先画框图，再框内垂直水平居中填字）
5. `drawCoconutSummary`：干净底图 → 顶部木牌标题 → 两长框文案 → 两短框操作
6. `input.js` 短框热区改为读同一套 layout

### 文案约定

| 槽位 | 文案 |
|------|------|
| 顶部木牌 | 本轮采摘结束 |
| 长框1 | 框里还有 N 个椰子 |
| 长框2 | 按是否已建店 / 是否完成椰子任务切换提示句 |
| 短框左/右 | 搭建烤鱼店 / 再采一轮（及其他已有分支） |

### 修改范围

- `assets/ui/`（同步英文名 png）
- `island-bakery/package/res/Image/ui/`
- `island-bakery/package/gameplay/render/renderer.js`
- `island-bakery/package/gameplay/play/input.js`
- `island-bakery/scripts/sync_sprite_assets.sh`（可选同步入口）

不改背包 `dialog-inventory.png` 用途。

## 预期效果

- 结算弹窗底图不再自带可点框；框与字始终同框居中。
- 建店 / 再采一轮等点击热区与短框图重合。
- 素材缺失时仍回退到旧奶油矩形 + 通用按钮，避免白屏。

## 补充（无顶牌底图比例）

干净底图更新为真正无顶牌，尺寸 `1620x1438`。`getCoconutSummaryLayout` 按该比例设弹窗高（宽约 480 时高约 426），顶部木牌仍运行时叠放；绘制与点击继续共用同一 layout。
