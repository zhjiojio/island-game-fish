# 手绘像素字导致中文难辨认修复设计

## 背景

首日原型中的「孤岛烤鱼店」等简体汉字难以辨认，根因是界面使用手工绘制的低分辨率像素字，而不是正常中文字体。

## 调用链路

1. 游戏界面请求绘制一段中文。
2. 渲染器逐字查询手工像素点阵。 ← 字形信息不足，笔画粘连。
3. 渲染器把每个点绘制成矩形。
4. 玩家看到难以辨认的中文。

## 根因分析

- 直接根因：`renderer.js` 的文字入口使用 `pixel-font.js` 中有限的手工点阵。
- 根本原因：把需要丰富笔画的中文字当成低分辨率图标绘制，缺少正常字体提供的完整字形和抗锯齿。

## 方案设计

旧流程：界面文字 → 手工像素点阵 → 矩形拼字 → 难辨认的中文。

新流程：界面文字 → [新增] 苹方简体中文字帖 → [新增] WebGL 纹理字形 → 清晰的中文。

1. [新增] 使用本机苹方简体中文字体生成字帖和字符坐标。
2. [修改] 渲染器通过 `KwaiMedia.Image` 加载字帖，继续使用 WebGL 1.0 绘制。
3. [修改] 保留原有文字字号、颜色、对齐方式及图形绘制顺序。
4. [移除] 游戏入口不再加载手工像素字。

## 预期效果

- 钓鱼、椰林、建店、烤鱼店和背包界面的中文均可直接阅读。
- 数字、标点、按钮文字与动态提示保持正常显示。
- 不改变首日玩法，不引入 DOM、Canvas 2D 或网络字体。
