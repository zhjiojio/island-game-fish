# 音效 P0 接线实现

## 背景

首日玩法几乎无声；设计文档 `2026-11-22--15-全局音效系统与资源清单-design.md` 已确认。本轮只做 **P0**：全局查表组件 + 分区 BGM + 主流程埋点；无成品素材时用短 WAV 占位便于验收。

## 调用链路（目标）

```
1. 首次触摸 → SoundManager.noteUserGesture（解锁音频）
2. Game.init / navigate / beginBuild / finishBuild
   → SoundManager.setArea(area) → KwaiMedia.Audio.playBgm
3. 玩法事件（抛竿/咬钩/接椰/建店/烤鱼/交付…）
   → SoundManager.play(id) → 查表 → KwaiMedia.Audio.playSfx
4. 收线按住 / 烤制 cooking
   → playLoop / stopLoop
5. 钓鱼结果 / 椰林结算 / 离线领取弹窗打开
   → 一律 play("ui.settle_open")
```

## 改动文件（范围）

| 文件 | 改动 |

**不改**：renderer 绘制、玩法规则、P1/P2 ID 埋点（表内可预登记，触发可后补）。

## 方案要点

- 语义 ID → `res/audio/...` 路径；缺文件由底层失败吞掉，打 `[Sound]` 日志。
- `setArea`：`map|fishing|coconut|build|shop` 五轨；同曲不重切。
- 建店：按 `buildStage` 播 `build.hit_chop|saw|assemble|fire`；步进 `step_done`；完工 `done`。
- 循环：收线 `fish.reel`、烤制 `shop.grill_loop`；松手/离 stage 即 stop。
- 占位音不同频率，便于听感区分触发点；正式 MP3 到位后只改路径/替换文件。

## 预期效果

进区换 BGM；按钮有 click；钓/椰/建/烤/卖主节点有声；三类结算同 `ui.settle_open`。
