# 钓鱼按钮锚点 / 椰林去底 / 结算门闸（R0039）

## 背景

1. 横屏钓鱼各阶段主按钮坐标不一致（按住抛竿在 520，后续跑到 360/330）。  
2. 椰林提示奶油渐隐底过亮。  
3. 刷新后「欢迎回来」在结算壳图未加载时走 cream 方块兜底，一片白。

## 根因

1. `drawFishing` 横屏各 phase 写死不同 `button(x,…)`；`input` 热区跟着分叉。  
2. 椰林仍传 `backdrop: true`。  
3. R0037 必需包未含 `dialog-settlement-*`；`paintSettlementShell` 缺图时 `rect(..., C.cream)`。

## 方案

```
1. 横屏主按钮统一 (520,405,240,50)；input 热区同步
2. 椰林 drawGuideTip 去掉 backdrop
3. pendingOffline/offlinePrompt 时 boot 含结算壳；未就绪不画欢迎回来/离线窗
```

## 预期

横屏钓鱼按钮不跳位；椰林无亮底；欢迎回来只在壳图就绪后出现。
