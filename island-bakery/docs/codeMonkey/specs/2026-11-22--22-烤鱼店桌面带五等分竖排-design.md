# 烤鱼店桌面带五等分竖排布局（R0045）

## 背景

R0044 已按「物体+同宽木牌」五等分，但均分基准是**整屏宽**，五个单体铺到桌面以外的沙滩/顾客区。用户反馈桌面大约只有画面一半宽，应在桌面宽度内均匀分布。根因是 `landShopTrayMetrics` 用 `W - margin*2` 当可用宽，而不是桌面带。

另：图标与木牌横向并排时单体约 139 宽，五格不重叠至少约 700，塞不进半桌（约 480）且不压窄。已确认方案 **A**：半桌宽均分 + **物体在上、木牌在下**。

## 调用链路

1. 横屏 `drawShop` → `drawLandShopTray` 画五格
2. `landShopTrayMetrics` 算格位 ← **问题点：可用宽 = 整屏宽**
3. 格 0–3 生鱼；格 4 椰子汁木牌；`landJuiceStackPoint` 跟格 4
4. `input` 热区跟格 0–3

## 根因分析

- **直接根因**：`landShopTrayMetrics` 里 `usable = W - margin * 2`，五等分相对整画布。
- **根本原因**：R0044 只解决了「别按椰汁反推挤窄牌宽」，未把分布域约束到柜台桌面；且横排单体宽大于半桌格宽，半桌域下无法同时满足「不遮盖 + 不压窄」。

## 方案设计

### 旧流程

1. 可用宽 ≈ 整屏 − 边距
2. 五等宽格；格内 **图标 | 木牌** 横排居中
3. 椰汁脚点 / 热区跟格走

### 新流程

1. [改] 可用宽 = **桌面带** `land.trayBand { left: 36, right: 546 }`（宽 510 ≈ 半屏略宽，保证 5×101 不重叠）
2. [改] 五等宽格；格内 **图标在上、木牌在下** 竖排居中；木牌仍 101×54，不压窄
3. [改] `hit` 包住图标+木牌竖向整体；椰汁脚点跟格 4 的 `iconX` / `iconFootY`
4. 热区 / `landJuiceStackPoint` / 引导箭头继续读同一套 metrics

### 改动文件

- `package/gameplay/data/shop-layout.js`：`land.trayBand`
- `package/gameplay/render/renderer.js`：`landShopTrayMetrics` / `drawLandShopTray` / `landJuiceStackPoint`
- `package/gameplay/play/input.js`：热区改用 `hitY`/`hitH`
- `package/index.html`：`shop-layout?v=16`、`renderer?v=153`、`input?v=22`

不改竖屏布局、不改烤架/兔子/顾客锚点。

## 预期效果

- 五个「物体+木牌」只落在左半桌面带内，间距一致
- 木牌同宽 101，不挤窄、格间不遮盖
- 点生鱼热区与绘制一致；有椰汁时堆与第 5 格对齐
