# 钓鱼区：兔子下绿色阴影（R0007）

## 背景

用户反馈兔子下面有绿色阴影区域，要求去掉；并要求本对话后续全程 PdeMonster 监工。

## 调用链路

1. `fishingBaseKey` → `ui-skin-fish-*-noboat`  
2. `paintScene` 画底板 ← 问题点：noboat 像素含绿色蒙版  
3. 跳过船精灵（R0006）+ 画兔

## 根因

- 直接：`ui-skin-fish-land-noboat.png` 去船处理失败，船位留下大块灰绿蒙版（非代码画的阴影）。  
- 根本：R0005 切 noboat 未做像素验收（与 R0006 同类）。

## 方案

浅滩底板改回**一体皮** `ui-skin-fish-land` / `ui-skin-fish-port`（完整海 + 烤船、无绿罩）；继续 R0006 规则：已烤船不叠船精灵。

## 预期

兔下无绿色块；仍一艘船；右下海完整。
