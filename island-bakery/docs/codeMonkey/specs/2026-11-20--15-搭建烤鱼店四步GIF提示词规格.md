# 搭建烤鱼店四步 GIF 提示词规格

玩法：砍树 → 锯木 → 搭建 → 生火（每步点一下播一次短动画）。本文件只定素材规格，**接线等 #2/#4/#3 完成后再做**。

## 通用规格（四段共用）

| 项 | 建议 |
|----|------|
| 画幅 | **960×540**（横屏设计坐标；竖屏可同素材居中缩放） |
| 时长 | 每段 **0.8～1.2 秒**（点一下播完一轮） |
| 帧率 | 12～15 fps（约 10～18 帧） |
| 格式 | 优先 **透明底 RGBA GIF**；或 PNG 序列 / 横向 sprite sheet（与钓鱼兔子 sheet 管线兼容更好） |
| 风格 | 与孤岛烤鱼店一致：暖色木作、手绘感、主角为 **烤鱼店同款白兔** |
| 循环 | **不循环**：播完停在最后一帧（或回到可再点的待机帧由程序控制） |
| 背景 | 主体外透明；可带极简地面阴影贴在兔脚，不要画完整场景（场景用现有 `scene-build-land`） |

## 抠图 / 透明底（强制引用）

凡涉及**去背、抠图、白底转透明、修白边、按帧抠图再拼 GIF/sheet**，不要另写一套透明规则，一律调用项目根目录：

[`透明背景素材生成提示词.md`](../../../../透明背景素材生成提示词.md)

用法：

1. **直接生透明素材**：用该文件「通用提示模板」，把【主体】换成下方各步的主体描述；输出可为 GIF 或逐帧 PNG（仍须真实 Alpha=0，不要用白色/棋盘格代替透明）。
2. **已有图/帧需要抠图**：用该文件「示例：已有图片抠图」全文；「主体组成」写清本步要保留的物件（见下表）。
3. **负面提示**：优先用该文件「负面提示词」及抠图专用负面句；下方各步只补充玩法相关负面（血腥、完整岛屿风景等）。

组合主体保留清单（抠图时写进「主体组成」，避免被当成背景删掉）：

| 步骤 | 必须保留 |
|------|----------|
| chop | 白兔、斧头、树干、砍痕/碎屑；可选贴脚接触阴影（须声明属于主体） |
| saw | 白兔、锯子、横放树干、木屑；可选贴脚接触阴影 |
| assemble | 白兔、立柱、三角屋顶构件；可选贴脚接触阴影 |
| fire | 白兔、摊架局部、石圈、柴火、火焰；可选贴脚接触阴影 |

## 第一步：砍树 `build_chop`

**动作/构图（生图或分镜用）：**

```text
生成一段可直接用于休闲小游戏的短动画（约 1 秒）。
横构图 960×540，居中。一只穿围裙的卡通白兔站在画面偏左，双手挥斧砍画面中央一棵棕榈/椰树树干。动作：举手→挥下→斧刃触树→树干出现一道浅砍痕。只保留兔子、斧头、树干与少量碎屑；地面可有贴脚小阴影（阴影属于主体）。不要文字、水印、完整风景。风格：暖色手绘游戏立绘，线条清晰。
```

**透明底 / 抠图：** 按上文「抠图 / 透明底」调用 `透明背景素材生成提示词.md`；主体组成填 chop 一行。

## 第二步：锯木 `build_saw`

**动作/构图：**

```text

横构图 960×540，居中。同一只卡通白兔站在偏左，面前横放 2～3 根树干，双手推拉锯子横向锯木。动作：锯子左右来回 1～2 个来回，锯口处可有少量木屑。只保留兔子、锯子、树干。不要文字、水印、完整工坊场景。风格与上一段白兔一致。
```

**透明底 / 抠图：** 同上，主体组成填 saw 一行。

## 第三步：搭建 `build_assemble`

**动作/构图：**

```text

横构图 960×540，居中。同一只卡通白兔在画面偏左，把木柱和三角屋顶构件搭成简易烤鱼摊骨架（两根立柱 + 屋顶）。动作：搬起木件→放到位→轻敲固定。最终帧呈现未生火的空摊架。只保留兔子与木构。不要文字、招牌字、完整岛屿风景。风格与前两段一致。
```

**透明底 / 抠图：** 同上，主体组成填 assemble 一行。

## 第四步：生火 `build_fire`

**动作/构图：**

```text
生成一段可直接用于休闲小游戏的短动画（约 1 秒）。
横构图 960×540，居中。同一只卡通白兔蹲/站在已搭好的简易摊架前，整理石圈篝火并点燃。动作：添柴→点火→火苗从小到中。最终帧有稳定小火苗。只保留兔子、摊架局部、石圈与火焰。不要文字、水印。风格与前三段一致。
```

**透明底 / 抠图：** 同上，主体组成填 fire 一行（火焰、石圈、柴火均属主体，勿当背景删除）。

## 交付命名建议

放入 `package/res/Image/sprites/`（或另定 sheet 目录）时建议：

- `build_chop.gif`（或 `anim_build_chop.png` sheet）
- `build_saw.gif` / `anim_build_saw.png`
- `build_assemble.gif` / `anim_build_assemble.png`
- `build_fire.gif` / `anim_build_fire.png`

若出 sheet：单帧建议 **256×256** 内容区、横向拼 8～12 帧，脚底对齐帧底，方便复用现有 `paintSheetFoot` 管线。逐帧若先非透明再抠，仍按 `透明背景素材生成提示词.md` 处理后再拼表。

## 程序接线约定（留给下一轮）

- 阶段仍为 `chop` / `saw` / `assemble` / `fire`
- **点一下播一次**：`buildAction` 成功时重置并播放对应 clip，播完停末帧；次数门槛不变（3/3/4/2）
- 未到素材前继续用现有矢量原型
