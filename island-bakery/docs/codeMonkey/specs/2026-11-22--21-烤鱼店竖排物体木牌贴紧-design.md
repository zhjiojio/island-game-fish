# 烤鱼店竖排物体与木牌贴紧（R0045b）

## 背景

R0045 竖排「物体上、木牌下」方向正确，但物体与木牌上下空隙偏大，用户要求紧挨。

## 调用链路

1. `landShopTrayMetrics` 算 `iconFootY = plaqueY - gapV`、`iconY` ← 问题点：`gapV=4` 且未抵消素材底透明边
2. `drawLandShopTray` / `landJuiceStackPoint` 跟上述锚点画物体与木牌

## 根因分析

- **直接根因**：`gapV = 4` 在包围盒上留空，鱼/椰汁素材底边还有透明像素，视觉缝更大。
- **根本原因**：竖排锚点只按逻辑框贴齐，未按「可视内容贴木牌顶」收紧。

## 方案设计

1. [改] `gapV` 改为负下沉（约 `-8`）：物体底边压进木牌顶少许，抵消透明边，视觉紧挨
2. 木牌位置/宽度、桌面带五等分不变；热区随 `iconY` 自动下移

## 预期效果

物体与木牌上下紧挨，无大块空白；横向五等分与牌宽不变。
