# 竖屏船下移：摆动时不露底板沙滩

> 状态：已确认并实施（待用户验收）  
> 轮次：R0010 补丁6  
> 横屏：禁止修改

## 背景

补丁5 新船脚点 `y=952`（画布高 960）。竖屏晃动 `amp=8`，`bobY` 最大上抬约 10px，船底离开屏底，底板沙滩从船下/边缘闪出来。

## 调用链路

```
1. fishingBoatFoot → 静帧脚点 y
2. boatY = foot.y + surf.bobY（摆动）← 问题：y 偏高时上抬露沙
3. paintFishingBoatSprite / 兔相对脚点绘制（随船一体）
```

## 根因

- **直接**：静帧脚点离屏底只有 8px，小于上抬幅度，摆动露沙。
- **根本**：新船贴底余量未按 `bobY` 峰值留足。

## 方案

```
旧：竖屏脚点 y=952
新：竖屏脚点 y=972（下移 20px ≈ 2×amp + 余量）
    静帧船底超出屏底约 12px；上抬 10px 后仍压住屏底
不改：bob 公式、船图、横屏、seaflat、兔相对偏移（随脚下移）
缓存：renderer.js ?v=99；日志标 patch6
```

预览：`docs/_sea-verify/boat-fix/bob_shift_cur_up.png`（现况上抬露底）vs `bob_shift_new_up.png`（下移后上抬仍贴底）。

## 预期

- 竖屏船轻晃时，船下不再闪出沙滩条。
- 兔仍在甲板上、随船晃。
- 横屏无变化。

## 验收

1. 硬刷新竖屏，看船上下晃几秒。
2. 船底/边缘不周期性露出大块沙滩。
3. 地图/背包可点；横屏无差别。
