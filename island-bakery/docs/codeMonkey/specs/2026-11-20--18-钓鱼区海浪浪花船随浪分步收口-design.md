# 钓鱼区收口：本轮只做 C3「浪形」（一次一个变量）

> 状态：**已确认并实施，待用户验收**  
> 轮次：**R0016**（索引内重复 R0015 另理）  
> 父方案：`--21` 的 C3；PdeMonster：单变量、先确认再改  
> 用户裁定：亮线不够浪形 → 必须先改浪形；泡沫/船随浪本轮不动

---

## 背景

目标仍是：有海浪、近岸浪花、船随浪。  
但当前卡点是：**亮色浪脊在动，却读不成「浪的形体」**。没有浪形，后面加浪花也站不住。

本轮**只解决浪形**。浪花（C4）、船随浪（C5）等本轮验收通过后再单独立项。

---

## 根因

**直接根因**  
现片元把能量放在「细亮 crest 线」上，本体明暗几乎压死（约 ±6%）。眼睛看到的是扫过的亮线，不是有高低的水面。

**根本原因**  
把「避免渐变闪烁」做成了「去掉体积感」。浪形需要的是**可见的峰谷体积**（宽软的暗谷 + 亮坡），不是描边式高光。

---

## 方案设计（仅 C3）

### 改什么

```
旧（当前）：细亮 crest 线为主，本体几乎不变 → 像亮线
新：
  低频向岸涌浪保留（UV，非 sin(y*高频)）           [保留结构]
  加回可见峰谷体积：暗谷略压、亮坡略提             [改]
  crest 降为辅助，不再是唯一信号                   [改]
  本轮可用 ?foam=0 验收浪形（泡沫不作为本轮目标） [验收约定]
```

风格仍遵守：日落水彩；不做镜面/菲涅尔；禁止恢复高频细横线与远海白光扫边。

### 不改什么（硬边界）

- 不改 C4 泡沫逻辑 / 不重导 sea-meta（本轮验收可用 `?foam=0` 关掉干扰）  
- 不改船脚、船兔刚体、鱼群  
- 不改 UI chrome / 蒙版 alpha / seaflat  
- 不顺手开 C5  

### 改动文件（预估）

| 文件 | 动作 |
|------|------|
| `package/gameplay/render/renderer.js` | 只改海面片元「体积感」相关项；版本 bump |
| `package/index.html` | `renderer.js?v=` bump |
| `docs/PdeMonster/*` | R0016 归档 |

### 预期效果

1. 静帧也能看出「一垄一垄」的起伏，不只是一条亮线  
2. 动起来是涌浪推进感，不是灯带横移、不是整片渐变闪  
3. 顶栏/地图背包、船位规则与改前一致  

### 验收（说人话）

1. 硬刷新浅滩（建议加 `?foam=0` 先只看浪形）  
2. 问自己：像不像水面在鼓？还是还在看亮线？  
3. 横屏看完再扫一眼竖屏
