# 钓鱼区海浪五问题修裁

## 背景

验收图 1–4：地平线下一带远海仍静；上带浪层把落日/山带进来；右下沙滩压着一块静海；浪层左右/顶边多出半透明方块；游鱼像贴在海面上。

## 调用链路与问题点

```
1. seabase 全屏
2. drawFishingFarSeaSwell
   - 用 sheet v=0~0.48 ← 图2：把落日山带进上带
   - seaTop 偏下 ← 图1：地平线红框仍露静底板
3. drawFishingNearShoreCrash
   - 画到靠近底边 + 负 pad 外扩 ← 图3 静海压沙滩；图4 多出一块
4. 游鱼画在浪层之上且 alpha 偏高 ← 图5 不在水里
5. 船兔（同频已做，本轮不动逻辑）
```

## 根因

| # | 直接根因 | 根本原因 |
|---|----------|----------|
| 1 | 上带起始偏下，地平线海带没进缓涌 | 分带只按 seaTop=150，未对齐「山脚以下」 |
| 2 | 上带复用了 sheet 顶部 UV（含天空山） | 把「远海涌」误做成「整帧上半」 |
| 3 | 下带/底板浅水画进沙滩区 | 近岸带未裁掉沙滩，静水残留 |
| 4 | `x=-pad`、宽 `width+pad*2`、yBob 位移 | 浪层越出画布/内容区，露出方块边 |
| 5 | 鱼在浪后画、偏亮 | 缺少「水下」层序与水色罩 |

## 方案

```
1. seabase
2. [改] 上带：仅 seabase「山脚~中海」UV 缓移（加强位移可见）
         禁止 sheet 含天空/山的 UV；可选 sheet 中段纯水面 UV（约 0.32~0.55）
         seaTop 上提到地平线海带（横屏约更贴山脚）
3. [改] 下带：冲击浪只画到沙滩线以上；底边 inset，不盖干沙
         若沙滩仍有静浅水：用 seabase 干沙 UV 盖住该角
4. [改] 浪层严格裁进画布：x=0..width，无负 pad；y 不整体漂移出界
5. [改] 层序：上带 → 游鱼（降 alpha + 蓝绿 tint）→ 下带碎浪半透明盖住鱼身下半
         或鱼后加一层极淡水色 wash
```
