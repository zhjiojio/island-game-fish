# 烤鱼店兔子放大与绿区指引可读性（R0015 本批）

## 背景

横屏烤鱼店兔子脚底与烤架同高，看起来站在桌上；钓鱼/烤鱼共用进度条绿区透明度过低、阶段文字发灰；原画层烤鱼空闲无「选生鱼」提示，也无首次点鱼引导。本批先做兔子放大与指引可读性；椰子只告知素材路径；搭建 GIF 本批只出提示词规格，接线等素材与 2/4/3 完成后另开。

## 调用链路

### 兔子站位
1. `ShopLayout.land.rabbit` 提供脚底锚点（原 y=388，与烤架同高）← 脚下移
2. `drawShopCast` 用横屏 `rabbitH=124` 画兔子 ← 放大约 1.4 倍
3. 榨汁走位 `homeH` 同源 ← 同步放大，避免走位高度跳变

### 绿区 / 文字 / 首次箭头
1. `progress()` 皮肤模式绿区 α=0.35 ← 加深
2. 钓鱼区 `instr` / `instruction` 灰色字 ← 改深色并略加大
3. `drawShop` 烤鱼阶段字在 `artOn` 空闲被关掉 ← 空闲与阶段均显示
4. 底部生鱼按钮循环 ← 未看过引导时对「库存第一只可烤鱼」画箭头
5. `startRecipe(fish_grilled)` 成功后写 `grillFishGuideSeen` 并存档

## 根因分析

- **直接根因**：横屏脚底钉在台面高度且身高偏小；绿区半透明；原画层关掉空闲提示；无首次引导字段。
- **根本原因**：原画接入时优先「脚对齐烤架槽」，未做「站地面、手够台」的视觉校准；指引依赖矢量层文案，皮肤层未补齐。

## 方案设计

### #2 横屏兔子（约 1.4×）
- [改] `rabbitH` / `homeH` 横屏：124 → 174（≈1.4×）
- [改] `ShopLayout.land.rabbit.y`：388 → 416（脚下移，使手高大致仍在操作台：ΔH×0.55）
- 竖屏不动；烤架/顾客槽不动

### #4 绿区、文字、首次箭头
- [改] `progress` 皮肤绿区：加深且提高不透明度（约 α 0.82）
- [改] 钓鱼阶段字：深墨色 + 字号 15→17；文案沿用现有阶段
- [改] 烤鱼店：空闲「点击生鱼开始烤」；生火/烤制中/翻面文案在原画层也显示（字色用深墨，避免发灰）
- [新增] 存档字段 `grillFishGuideSeen`；未看过且有可烤鱼时，箭头指向 `FishSpecies` 顺序中第一只「已解锁且库存>0」；成功开始烤该流程后置 true 并 save

### 本批不做
- 椰子 `nutH` / 换图接线（等你给新路径）
- 搭建 GIF 接入（本批只给四步提示词规格）

## 预期效果

1. 横屏烤鱼店：兔子更大，脚落在地面一侧，手仍够到操作台附近。
2. 钓鱼蓄力/拉锯绿区、烤鱼生火/翻面绿区明显可辨，红游标易找。
3. 钓鱼阶段字清晰；烤鱼有空闲与阶段提示。
4. 首次进店有鱼可烤时箭头指第一只可点的生鱼；点过并开烤后存档不再出现。
