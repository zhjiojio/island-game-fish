# 首日节奏与店铺参与感修正设计

## 背景

钓鱼指针过快且鱼获后自动跳转，椰林初始掉落和筐内反馈不足，建店只看进度，店铺缺少厨房分区和摆盘交付表现，需要继续调整首日节奏与参与感。

## 调用链路

1. 钓鱼 → 快速指针与较长收竿 → 自动进入椰林。 ← 节奏难、剥夺路线选择。
2. 椰林开始 → 持续单颗掉落 → 数字增加。 ← 缺少波浪节奏和实物入筐反馈。
3. 确认建店 → 自动进度结束。 ← 玩家没有参与建造。
4. 制作完成 → 强弹窗确认 → 点击顾客收钱。 ← 打断连续经营。

## 方案设计

### 钓鱼与路线引导

- 指针摆动降速，有效收竿缩短到约两秒，单次咬钩流程控制在十秒内。
- 钓到鱼后留在钓鱼区；新用户累计三条鱼时出现椰林引导，通过地图自行进入。

### 椰林与建店

- 每轮初始掉落三颗，每八秒增加一波的掉落数量与速度。
- 椰子接取后飞入筐内，筐中实际摆放椰子，最多展示十个，超出部分用数字表示。
- 建店改为砍树、锯木、搭店、整理篝火四个点击参与阶段；首个烤鱼工具始终是一处篝火，后续可扩展数量和工具升级。

### 厨房、送餐口与订单

- 烤鱼区、椰子汁区和送餐口分区；生鱼按品种选择，熟鱼与饮品摆盘展示中文名。
- 三种鱼使用不同颜色与花纹；顾客订单只展示商品图和数量。
- 制作完成播放摆盘动作，不出现强弹窗；交付后在顾客头顶显示逐渐上浮消失的金币。
- 顾客状态只写「等餐中」，订单鱼种概率与钓鱼鱼种概率一致。

## 预期效果

首日操作更轻松，路线由玩家选择；采集、建造、制作、摆盘和交付都有连续可见的反馈，店铺具备后续分区扩展基础。
