# 烤鱼进度条加深 + 椰林掉落碎裂与摇树修正

## 背景

烤鱼店生火/烤制/翻面横向进度填充是浅蜂蜜色，对比不足看不清；椰林未捡椰子在半空就消失且原画层无碎裂裂痕，摇树每次只掉 1 颗、下落被二次加速，点中椰子时同点树可能继续/重开摇晃。

## 调用链路

### 问题 1 · 烤鱼进度条

1. 进入烤鱼店烤鱼流程（生火 / 烤制 / 翻面）
2. 渲染层画厨房进度：
   - 生火、翻面 → 共用 `progress`（画进度条：高亮区 + 游标 + 可选填充）
   - 烤制 → 直接用蜂蜜色矩形画已烤比例 ← **问题点：填充色为浅蜂蜜 `C.honey`**
3. 横屏、竖屏厨房各调一次，但颜色常量同源，会一起变
4. 钓鱼区张力条是另画的橙色/红色矩形，不走上述蜂蜜填充 ← 本次不改

### 问题 2 · 椰林掉落（横竖屏同一套 `collection.js`）

1. 点击椰树 → `shakeTree`（摇树掉椰子）→ 当前固定 `spawnCoconut` 1 次 ← **问题点：最左树总是 1 颗**
2. 每帧 `updateCoconuts`（更新椰子下落）：
   - `vy += 240 * dt/1000` 再位移 ← **问题点：额外加速导致掉太快**
   - 落到 `getGroundY()` 后标 `cracked`，约 500ms 后移除
3. `getGroundY` 用沙滩比例算出的 Y（横屏约 343、竖屏约 677），低于原画树根线（横屏 432 / 竖屏 730）← **问题点：半空/树根以上就判落地消失**
4. 原画层画椰子时 cracked 仍只画整果精灵，不画裂痕 ← **问题点：看不见碎裂**
5. 点击：先 `catchCoconut`（点中椰子进筐），成功则 return；否则 `treeAt` → `shakeTree`
   - 点中椰子时未清掉该树 `treeShakes`，树可能继续晃；需保证同一次点击不会再设回摇晃

## 根因分析

### 直接根因

1. **进度条**：烤制阶段 `rect(..., C.honey)`；`progress` 在有填充值时也用 `C.honey`，浅亮难辨。
2. **落地线**：`getGroundY` 未对齐 `coconutArtLayout().rootY`（树根那一条地面）。
3. **碎裂表现**：原画分支 early return，跳过旧矢量裂痕两笔。
4. **掉落速度**：自由落体改造时加了 `vy += 240`，相对旧匀速版过快。
5. **掉落数量**：`shakeTree` 每次只 `spawnCoconut` 一次。
6. **点椰与摇树**：接住后未立刻把对应树的摇晃清零；需守住「先接椰、成功则不再 shakeTree」。

### 根本原因

落地判定绑在通用沙滩比例上，而原画树槽改用固定 `rootY` 后两套坐标系未统一；进度色复用全局蜂蜜强调色，未按可读性单独给烤鱼进度定深橙语义色。

## 方案设计

### 问题 1 · 烤鱼进度填充

旧：

1. `progress` 填充 → `C.honey`
2. 烤制比例条 → `C.honey`
3. 钓鱼张力条 → 橙/红（保持）

新：

1. `progress` 增加可选语义：填充默认深橙（接近现有 `C.orange`）；当「进度值/游标」超出高亮区时用更深橙红 [修改]
2. 烤制比例条改为同一深橙（烤制无高亮区，只用深橙）[修改]
3. 钓鱼张力条绘制不动 [不变]
4. 横竖屏仍共用上述绘制，两处一起变深 [不变结构]

说明：生火/翻面若当前 `value=null` 几乎看不到填充，将改为把游标位置同时作为填充长度（0→游标），这样三阶段都有深橙填充可读；超出高亮区则填充改更深橙红。

### 问题 2 · 椰林掉落

旧：

1. `shakeTree` → 掉 1 颗
2. 下落 `vy += 240` 再匀速位移感被破坏
3. 落地 Y = 沙滩比例 + 20
4. 原画 cracked 无裂痕
5. 接住椰子不清理 `treeShakes`

新：

1. `shakeTree` 每次随机掉 **1～3** 颗，均从该树树冠生成 [修改]
2. 去掉 `vy += 240`；初速仍 `约 82 + 波次*9 + 小随机`，只按该速下落；点中仍滑入筐 [修改]
3. `getGroundY` 对齐该布局树根线 `coconutArtLayout().rootY`（横竖屏同一套函数）[修改]
4. 原画 cracked：精灵上补画两道裂痕（恢复旧矢量碎裂观感），约半秒后再移除 [修改]
5. `catchCoconut` 成功时立刻将该椰子所属树（及点击所在树，若可判定）`treeShakes` 置 0；`input` 保持先接椰成功则 return，同一次点击不再 `shakeTree` [修改]

**改动文件**：

- `island-bakery/package/gameplay/render/renderer.js`（进度色、原画椰子裂痕）
- `island-bakery/package/gameplay/play/collection.js`（落地线、匀速、随机颗数、接住停晃）
- `island-bakery/package/gameplay/play/input.js`（仅当需加固「接住后停晃 / 不二次摇树」时微调）

不改钓鱼张力条逻辑；不拆横竖屏两套椰子速度。

## 预期效果

- 烤鱼店生火/烤制/翻面横向进度填充为深橙，超出高亮区时更深橙红；钓鱼张力条外观不变
- 未捡椰子落到树根地面后出现碎裂（裂痕），约半秒再消失，不会半空消失
- 点中椰子：树立刻停晃，同一次点击不会再摇树；只点树仍摇树掉椰
- 每棵树每次摇晃掉 1～3 颗（随机），从树冠落下，下落匀速不再额外加速
