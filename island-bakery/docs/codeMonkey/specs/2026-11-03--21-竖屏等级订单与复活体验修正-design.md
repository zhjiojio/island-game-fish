# 竖屏、等级、订单与复活体验修正设计

## 背景

本轮合并处理五个已确认问题：竖屏游戏被挤压、离线弹窗暴露二十分钟策略、等级永远为 1、稀有鱼订单永久占位，以及广告复活后反复进入失败弹窗。

## 现状与根因

### 1. 竖屏布局

1. 打开平台预览
   └── 固定横屏画布与平台铺满样式同时生效 ← 尺寸规则冲突
2. 竖屏尺寸直接交给横屏游戏
   └── 字和按钮被挤小

直接根因在 `package/index.html`。竖屏被错误地当成正常游戏容器，而不是显示旋转提示。

### 2. 离线弹窗文案

`package/gameplay/render/renderer.js` 直接显示「你已经玩了20分钟」。这属于内部解锁策略，不需要向玩家解释。保留功能与解锁阈值，只删除该句。

### 3. 等级不增长

1. 玩家钓鱼、采集、烤制、售卖
   └── 正常增加食材、商品和金币
2. 游戏保存等级
   └── 固定写入 1 级 ← 没有经验累计与升级判断

直接根因在 `package/gameplay/core/game-state.js`。设计文档已有经验来源，但原型没有实现经验字段、加经验和升级逻辑。

### 4. 稀有鱼订单占位

1. 浅滩钓鱼
   └── 当前只能获得小海鱼，完美提竿有机会获得三文鱼
2. 顾客随机点餐
   └── 使用包含金枪鱼和金色传说的全局随机池 ← 订单超出当前产出能力
3. 顾客等待
   └── 永不离开 → 取餐位永久被无法完成的订单占用

直接根因在 `package/gameplay/play/selling.js`。订单生成没有按当前钓点和工具能力过滤鱼种。

### 5. 复活反复失败

1. 鱼跑后点击看广告复活
   └── 广告成功
2. 游戏重新进入一秒提竿窗口
   └── 用户还未完成下一次点击 → 再次超时 ← 重复进入同一失败弹窗

实测状态为「失败后→复活至咬钩→1.1 秒后再次失败→再次复活」。直接根因在 `package/gameplay/play/collection.js`，复活重复设置了一个短时机门槛。

## 方案设计

### 1. 竖屏与横屏

修改前：竖屏直接挤压游戏。

修改后：竖屏全屏显示「请横屏游玩」并隐藏游戏；旋转后自动恢复完整横屏 16:9，居中不变形。只修改预览布局，不改变横屏设定。

### 2. 离线弹窗

修改前：离线自动采集／你已经玩了20分钟／下线也能收鱼肉和椰子。

修改后：离线自动采集／下线也能收鱼肉和椰子／看1次广告永久解锁。删除策略文案，其余不变。

### 3. 经验与升级

按设计文档增加经验：

| 行为 | 经验 |
|------|------|
| 钓到鱼 | +5 |
| 接到普通或金椰子 | +3 |
| 成功烤鱼 | +10 |
| 每卖出一份食物 | +5 |

建议累计门槛：Lv.2＝50、Lv.3＝150、Lv.4＝300、Lv.5＝500。之后每级所需增量再增加 50，例如 Lv.6＝750。达到门槛自动升级，用轻提示告知，不弹强制窗口；经验与等级都写入存档，旧存档从已有等级开始兼容。

### 4. 顾客可完成订单

修改前：顾客从全部鱼种随机，可能要求当前无法钓到的稀有鱼。

修改后：顾客只从当前可获得的鱼种点餐。首日浅滩订单只包含小海鱼和三文鱼；金枪鱼与金色传说等对应钓点和工具真正解锁后，才进入订单池。保留随机数量、双商品和最多两位顾客。

### 5. 广告复活

修改前：广告成功→重新一秒提竿→可能再次失败。

修改后：广告成功→直接回到拉锯战，玩家继续收放线，不再重复提竿时机。放弃仍可重新钓鱼，真实广告 SDK 不改。

## 涉及文件

- `package/index.html`：竖屏提示与横屏容器。
- `package/gameplay/render/renderer.js`：离线弹窗文案和必要等级显示。
- `package/gameplay/core/game-state.js`：经验、等级与存档兼容。
- `package/gameplay/play/collection.js`：钓鱼与采集经验、复活状态。
- `package/gameplay/play/baking.js`：烤鱼经验。
- `package/gameplay/play/selling.js`：可完成订单与售卖经验。
- 新增中文字帖、验证记录、项目说明和交付目录同步。

## 验证方案

1. 竖屏只显示旋转提示，横屏自动恢复且不变形。
2. 离线弹窗不再出现二十分钟策略文案，解锁和收益不变。
3. 分别验证钓鱼 +5、采集 +3、烤鱼 +10、每份售卖 +5；到 50 经验升 Lv.2，重开保留。
4. 生成多位顾客，不出现当前无法产出的金枪鱼或金色传说订单，原有订单可以交付。
5. 广告复活后直接进入拉锯战，不再自动回到失败弹窗。
6. 完整回归 FISH、COCO、SHOP、AC、字体与官方整包预检，重新打包。

## 预期效果

- 玩家知道何时该旋转手机，横屏后画面正常。
- 界面不暴露内部时长策略。
- 每次有效经营行为都能积累成长，等级不再固定为 1。
- 每个出现的订单理论上都能通过当前玩法完成，不再永久堵位。
- 看广告复活能真正继续钓鱼，不形成反复失败循环。
