# 竖屏半边船晃动与沙滩误进船层

> 状态：已实施（用户确认后落地；仅竖屏）
> 轮次：R0010 补丁3
> 关联：用户纠正「横屏没问题、竖屏半边船在动/沙滩应静止」；补丁2已回滚

## 背景

竖屏钓鱼区：随浪晃的只有半边船（用户红框），周围沙滩静止。期望整艘船一起晃，沙滩仍静止（绿框为完整船体）。

补丁2误判为「切图残缺就整张重抽」，把沙滩卷进船精灵，导致左侧沙滩也跟着晃；并改了本无问题的横屏船图。已回滚横屏船图、竖屏错误切图与错误摆放。

## 调用链路

```
1. 底板 ui-skin-fish-port-seaflat（静态）
   ← 船位有抹痕填充 + 右侧残留木船碎片（静止层）
2. 精灵 boat_fish_port + bobY（动态）
   ← 切图本身左右/底边残缺 → 只有半边船在晃
3. 补丁2错误：重抽时把左侧沙滩打进精灵 → 沙滩也跟着晃
```

## 根因分析

- **直接根因（竖屏观感）**：动态层是残缺船精灵；静态 seaflat 船位还有抹痕/船渣。两者叠在一起 =「半边船在动、周围沙不动」。
- **补丁2失误**：用 noboat 绿洞当船范围，洞里含沙滩 → 沙滩进动态层；横屏无此 bug 却被改了 `boat_fish_land`。
- **根本原因**：去船底板与真船切图不是同一套完整蒙版；缺「只含船体、不含沙滩」的验收。

## 方案设计（仅竖屏）

```
旧/现状（回滚后）：残缺 port 精灵 + 脏 seaflat 船位；land 已恢复
新：
  1. [改·仅 port] 重抽 boat_fish_port：只含木船/灯笼/坐垫，严禁沙滩/海星/海水
  2. [改·仅 port-seaflat/deepflat] 船位重填为干净静态沙滩（去掉船渣与明显抹痕）
  3. [改·仅竖屏摆放] 完整船对齐甲板槽（不改横屏脚点/水线逻辑）
  4. [不改] boat_fish_land、横屏 seaflat、横屏脚点
```

## 预期效果

- 竖屏：整艘船（近绿框）一起随浪轻晃；沙滩/海星静止。
- 横屏：与改前一致，无回归。

## 影响与回滚

- 影响面：仅竖屏船精灵 + 竖屏 seaflat/deepflat 船位填充 + 竖屏脚点。
- 回滚：还原上述 port 资源与 `fishingBoatFoot` 竖屏分支。

## 验收

1. 硬刷新竖屏：整船晃、沙滩不晃。
2. 左侧沙滩/海星不跟着船抖。
3. 横屏对比：船与改前无差别。
4. 地图/背包仍可点。
