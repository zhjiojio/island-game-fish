# 结算弹窗共用底图分层重构

## 背景

各结算/提示弹窗仍依赖「一体底图」（椰子结算、鱼获、背包、缺鱼、离线等各自一张完整 PNG），文案与按钮坐标和画在图里的框对不齐。现已提供全弹窗共用的干净底图 `结算_无按钮底图.png`，以及可复用的顶部木牌、长短按钮框，和部分中部要素（椰子簇、鱼获圆盘）。需要抽一层共用弹窗壳，按「底图 + 顶牌 + 中部槽 + 长短框」拼接，去掉对旧一体底图的依赖。

## 调用链路（现状）

1. 游戏状态进入某弹窗（如 `coconutSummary` / `fishResult` / `showInventory` …）
2. `Renderer.draw*` 各自：
   1. 蒙层
   2. `paintUiStretch(dialog-xxx)` 拉一整张一体底图 ← 问题点：框烤在图里
   3. 裸 `text` / 通用 `button` 按硬编码偏移填字
3. `input.js` 另写一套硬编码热区 ← 问题点：与绘制不同源

## 根因分析

- **直接根因**：每个弹窗绑定独立一体 PNG，程序字/热区无法与图内框对齐。
- **根本原因**：缺少「共用壳 + 槽位 layout」抽象，绘制与点击没有单一布局源。

## 方案设计（已确认：方案 A）

### 旧流程

1. 各 `draw*` 拉自己的一体底图
2. 各自算字与按钮坐标
3. `input.js` 再写死矩形

### 新流程

1. 同步素材到 `assets/ui` 与 `package/res/Image/ui`
2. [新增] `getSettlementLayout(hw, hh)`：按共用底图像素比 `1626×1182` 算弹窗矩形，以及 title / mid / long1 / long2 / shortL / shortR 槽位
3. [新增] `paintSettlementShell(layout, titleText)`：蒙层 + 共用底图 + 顶牌填标题
4. [新增] `paintSettlementButtons(layout, longs, shorts)`：长框文案 + 短框操作（缺图回退通用木按钮）
5. 各 `draw*` 只负责：调壳 → 画中部槽 → 传入文案；`input.js` 短框热区读同一 layout
6. 停止依赖旧一体 key（`dialog-coconut-summary` 专用无按钮图、`dialog-fish-result`、`dialog-inventory`、`dialog-go-fishing`、`dialog-offline` 作为结算壳）；资源可保留文件但不在结算路径引用

### 各弹窗内容约定

| 弹窗 | 顶牌标题（示例） | 中部槽 | 长框 | 短框 |
|------|------------------|--------|------|------|
| 椰子结算 | 本轮采摘结束 | `椰子结算_椰子.png` | 数量 + 提示句 | 建店/再采等（已有分支） |
| 鱼获结果 | 钓到鱼了 | 圆盘 + 盘上叠鱼图标 | 鱼名重量等说明 | 收进鱼篓 / 去地图等 |
| 跑鱼 | 太晚了 鱼跑了 | 圆盘（可空鱼）或留空 | 提示句 | 复活 / 放弃 |
| 背包 | 背包 | **暂空**（文字列表程序绘） | 可选材料摘要进长框，或纯文字 | 无短框，点空白关闭（保持现状） |
| 厨房缺鱼 | 厨房缺鱼 | **暂空**（可用现有 `paintFishIcon` 占中部，不算新素材） | 缺料说明 | 去钓鱼 / 先取消 |
| 离线解锁 | 离线自动采集 | **暂空** | 说明句 | 看广告解锁 / 稍后再说 |
| 离线领取 | 欢迎回来 | **暂空** | 收益摘要 | 领取 / 双倍 / 稍后（三按钮：中/左右短框或两短+一长，实现时用短框槽位扩展） |
| 体力耗尽 | 钓鱼/采摘体力耗尽 | **暂空** | 恢复说明 | 看广告 / 等待或放弃 |

### 明确不做 / 暂缓

- 不叠 `椰子结算_箩筐.png`（场景箩筐保持原样，与弹窗无关）
- 不再使用 `椰子结算_无按钮底图.png` 作为椰子弹窗底
- 缺中部精细化素材的弹窗：中部留空，见下方待补清单

### 待补中部素材清单（实现后仍空着的槽）

2. 离线解锁 / 领取中部插画（鱼+椰组合图等）——当前中部留空

### 实现状态（2026-11-11）

已落地：`getSettlementLayout` / `paintSettlementShell` / longs / shorts；椰子、鱼获、跑鱼、背包、缺鱼、离线、体力均走共用壳；`input.js` 短框热区同源。

## 预期效果

- 所有列出的弹窗视觉骨架统一：共用底图 + 顶牌 +（可选）中部 + 长短框。
- 椰子：顶牌 + 椰子图 + 按钮；鱼获：顶牌 + 圆盘上叠鱼 + 按钮。
- 文字始终相对框居中；短框点击与绘制同 layout。
- 缺中部素材时不报错、不挡流程，只留空白羊皮纸区，便于后续补图。

## 验收 Case（假定输入 → 预期）

1. 椰林回合结束且未建店、椰子任务完成 → 共用底图；顶牌「本轮采摘结束」；中部有椰子簇；长框有数量与「现在建店 还是继续采摘」；短框「搭建烤鱼店」「再采一轮」可点。
2. 钓到鱼收进鱼篓路径 → 共用底图；顶牌「钓到鱼了」；圆盘上可见对应鱼种；短框操作与原先逻辑一致。
3. 打开背包 → 共用底图 + 顶牌「背包」；中部无新插画但鱼种/材料文字可读；点空白可关。
