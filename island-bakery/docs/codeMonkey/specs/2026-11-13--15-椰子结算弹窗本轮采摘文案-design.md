# 椰子结算弹窗「本轮采摘了」文案修正

## 背景

椰子采摘结束弹窗里，数量说明写的是「框里还有 x 个椰子」，语义像「筐里还剩多少」，与本轮结算的「采摘结果」不符；需改为「本轮采摘了 x 个椰子」。

## 调用链路

1. 玩家完成一轮椰子采摘 → 进入结算态
2. 渲染层 `drawCoconutSummary`（画椰子结算弹窗）读取本轮接住数量 `caughtThisRound`
3. 拼出长框文案 `countLabel` ← **问题点：文案写「框里还有」**
4. 弹窗展示「本轮采摘结束」+ 数量说明 + 操作按钮

## 方案设计

旧：

1. `countLabel = "框里还有 " + caughtThisRound + " 个椰子"`

新：

1. `countLabel = "本轮采摘了 " + caughtThisRound + " 个椰子"` [修改]

**改动范围**：仅 `island-bakery/package/gameplay/render/renderer.js` 中 `drawCoconutSummary` 的这一处文案字符串；不改数量来源、按钮逻辑与其它结算弹窗。

## 预期效果

- 采摘结束弹窗数量行显示为「本轮采摘了 x 个椰子」（x 仍为本轮 `caughtThisRound`）
- 其它场景文案与交互不变
