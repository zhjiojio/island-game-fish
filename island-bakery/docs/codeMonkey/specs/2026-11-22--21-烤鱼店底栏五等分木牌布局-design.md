# 烤鱼店底栏五等分木牌布局（R0044）

## 背景

R0043e/f 为避开椰汁反复压缩底栏步距与牌宽，导致小海鱼、三文鱼木牌变窄、间距不匀。根因是「四鱼挤在椰汁左侧」的临时算法，而非单独锚点微调。

## 调用链路

1. 横屏 `drawShop` 画底栏 → [改] 改调 `drawLandShopTray`
2. `landShopTrayMetrics` 算 5 等宽格（图标+101×54 木牌居中）← 原 `landFishBarMetrics` 按椰汁 X 反推压缩 ← 问题点
3. 格 0–3 画生鱼；格 4 画「椰子汁 N」；`landJuiceStackPoint` 跟格 4 图标 X
4. `input` 热区跟格 0–3 的 hit 矩形

## 方案设计

横屏底栏从左到右 **5 个等宽格子**：小海鱼、三文鱼、金枪鱼、金色传说、椰子汁。

每个格子内一个单体：`图标/物体 + 同宽木牌(101×54)`，单体在格内水平居中；格宽 = `(画布宽 - 左右边距) / 5`，间距天然均匀。

- 格 0–3：生鱼图标 +「鱼名 N」木牌（点击开烤）
- 格 4：椰汁脚点对齐该格图标 X；「椰子汁 N」木牌同格右侧（有成品时桌上堆由 `drawJuiceStack` 画）
- `landFishBarMetrics` 仅转调 tray，不再按椰汁压缩

## 预期效果

五列均匀；木牌同宽不挤窄；物体+木牌互不遮盖；点击热区与绘制对齐。
