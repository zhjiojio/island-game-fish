# 椰汁木牌避开右侧鱼标（R0043）

## 背景

椰汁右侧木牌被一条鱼素材挡住。该鱼实际是底部选鱼栏最右侧鱼标，与木牌同高重叠；用户要求鱼在椰汁左边，勿挡木牌。

## 根因

`landJuiceStackPoint` 的 `y = last.y + 36` 把椰汁/木牌拽到底栏（y≈402）高度；木牌左移放大后盖住 `bx=20+3*150` 的金色传说鱼标。

## 方案

```
1. 椰汁脚点 Y 回到成品鱼同排；X 拉到底栏鱼牌右侧之外
2. 木牌立在柜台行，底边不压选鱼栏
3. 底栏四条鱼步距收紧，全部落在椰汁左侧；input 热区同步
```

## 预期

成品鱼与底栏鱼标都在椰汁左边；椰子汁木牌不被鱼挡住。
